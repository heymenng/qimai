## 第二步：文件名检查（10秒）

### 正确格式
```
PT-[出生年月]-[年份]-[序号]_[姓名]_[主诉关键词]_可打印完整档案.md
```

### 检查清单
- [ ] 编号格式正确（PT/TS/GD + 8位数字）
- [ ] 年份为档案建立年份（非初诊年份）
- [ ] 序号3位，不重复
- [ ] 姓名与登记表一致
- [ ] 主诉关键词简洁（2-4字）
- [ ] 包含"可打印完整档案"标识
- [ ] 扩展名为 `.md`

### 错误示例
```
❌ 01-初诊待分类/         ← 旧目录，已废弃
❌ 多个文件分散存放        ← 必须一个患者一个文件
❌ .html/.js 可视化文件    ← 必须可打印的.md
❌ 无版本标识              ← 需含V4.3
```
