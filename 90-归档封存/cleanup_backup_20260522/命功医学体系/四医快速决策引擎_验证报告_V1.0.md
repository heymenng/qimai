## 二、决策引擎推演（模拟30秒决策）

### Step 1: 急症排雷（目标：5秒）

```
【检查清单】
□ 胸痛+大汗+放射痛？ → 否
□ 雷击样头痛？ → 否
□ FAST症状（面歪/臂无力/言语不清）？ → 否
□ 血压≥180/120？ → 158/74，否
□ 大咯血/呕血/黑便？ → 大便潜血阳性，但非急性大出血
□ 板状腹+反跳痛？ → 否
□ 意识障碍+高热？ → 否

【决策】非急症，继续第二层
【耗时】✅ 5秒（符合目标）
```

**验证结果**：✅ 通过。虽然大便潜血阳性需要警惕，但不属于需要立即转诊的急症。

### Step 2: 病种定位（目标：10秒）

```
【患者主诉分析】
主诉是"多系统疑难重症"，需要分解定位：

子病症1：高血压
  → 查ACC/AHA指南
  → 分级：1级（140-159/90-99）
  → 目标：老年患者<150/90
  → 中医：邓铁涛（石决牡蛎汤/赭决九味汤）

子病症2：肿瘤标志物偏高（CEA↑、SCC↑）+ 大便潜血阳性
  → 查NCCN思路（虽然不是确诊肿瘤，但需警惕）
  → 关键红线：需定期复查排除肿瘤
  → 中医：朱良春（扶正消癥思路，扶正为主）

子病症3：白癜风 + 双足皮肤病 + 高尿酸
  → 湿毒内蕴
  → 中医：路志正（调理脾胃基础方，芳香化湿）

子病症4：中风高危
  → 查AHA/ASA
  → ABCD2评分（如适用）
  → 中医：张学文（清脑通络汤，预防性）

子病症5：慢性肾功能不全
  → 关键红线：避免肾毒性药物
  → 用药需极谨慎

子病症6：96岁高龄 + 多器官功能衰退
  → 炁虚至极
  → 治疗以扶正为主，攻伐为辅

【综合判断】
  这不是单一病种，是老年多系统功能障碍
  需要多大师方思路融合
  核心矛盾：炁衰（9级）+ 毒滞（8级）+ 邪损（8级）

【耗时】⚠️ 15秒（超出10秒目标，因多系统复杂）
```

**验证结果**：🟡 部分通过。单一病种可在10秒内定位，但多系统复杂案例需要15-20秒。引擎需要增加"多系统疾病"的快速处理路径。

### Step 3: 五维快速定级（目标：10秒）

```
【用快速定级卡评估】

炁维（能不能动）：
  - 96岁高龄，多器官术后/功能不全
  - 能活动但极度虚弱
  - 快速定级卡："卧床为主→≥9级"
  - 实际：非完全卧床，但极度虚弱
  - 判定：8-9级 ✅

毒维（排出好不好）：
  - 高尿酸466↑、白癜风、双足皮肤病
  - 背部灰黑毒油（痧象）
  - 快速定级卡："长期便秘+皮肤病→≥8级"
  - 判定：8级 ✅

脉维（痛不痛僵不僵）：
  - 胆经阳陵泉6分疼痛
  - 多经络3分疼痛
  - 快速定级卡："肩颈僵硬→≥6级"
  - 判定：6级 ✅

邪维（指标异常）：
  - 肾功能不全（肌酐133↑）
  - 肿瘤标志物高（CEA、SCC）
  - 白内障、嗅觉失敏
  - 快速定级卡："严重指标异常→≥8级"
  - 判定：8级 ✅

瘾维（习惯好不好）：
  - 喜食水果多，食后腹凉
  - 多年习惯难改
  - 快速定级卡："偶发情绪波动/晚睡→5-6级"
  - 判定：5级 ✅

【定级结果】炁8-9/毒8/脉6/邪8/瘾5
【与实际对比】炁9/毒8/脉6/邪8/瘾5 → 基本一致
【耗时】✅ 10秒（符合目标）
```

**验证结果**：✅ 通过。快速定级卡能准确评估五维级别。

### Step 4: 54牌速选（目标：5秒）

```
【选牌流程】

Step 1: 找最严重的2个维度
  - 炁9（极度衰损）
  - 毒8（重度滞积）
  - 邪8（重度损伤）
  → 三个维度都很严重

Step 2: 对应花色
  炁9 → ♥K（强力补气）
  毒8 → ♠K（强力排毒）
  邪8 → ♦Q（通脉祛邪，因为邪维涉及多器官损伤，需要通脉）
  脉6 → 已在♦Q中覆盖
  瘾5 → ♣J（调习惯）

Step 3: 检查平衡
  攻伐牌：♠K + ♦Q = 2张
  补益牌：♥K = 1张
  2 ≤ 1+1？ → 2 ≤ 2 ✅（刚好平衡）
  瘾维5级≥6级？ → 否，但临界，加♣J稳妥

Step 4: 最终组合
  ♥K + ♠K + ♦Q + ♣J
  = 强力补气 + 强力排毒 + 强力通脉 + 调习惯

【与实际方案对比】
  引擎输出：♥K + ♠K + ♦Q + ♣J
  实际方案：♠️8 + ♥️8 + ♦️6-7
  
  对比分析：
  - 补气：♥K vs ♥️8 → 基本一致（都是强力补气）
  - 排毒：♠K vs ♠️8 → 基本一致（都是强力排毒）
  - 通脉：♦Q vs ♦️6-7 → 引擎偏强（实际考虑到96岁高龄，未用最强通脉）
  - 瘾维：♣J vs 无 → 引擎增加调习惯，实际案例确实需要（喜食水果）

【耗时】✅ 5秒（符合目标）
```

**验证结果**：✅ 通过。引擎输出与实际方案高度一致。

### Step 5: 大师方速选（目标：与Step 2同步）

```
【根据子病症匹配大师方】

  - 预防性 → 清脑通络汤（减毒版）

【综合处方思路】
  以邓铁涛补气方（黄芪60g+）为底

  + 朱良春扶正思路（处理肿瘤标志物）
  + 张学文通脉思路（预防中风）
  
  但96岁高龄+肾功能不全 → 内服中药风险极高
  → 实际采用外治法为主（行罐、药灸）

【引擎预判 vs 实际处理】
  引擎：推荐多方融合的内服方
  实际：因高龄+肾衰，采用外治法（行罐、药灸）
  
  差异原因：引擎未充分考虑"高龄+肾功能不全"的用药禁忌
```

**验证结果**：🟡 部分通过。引擎在复杂病例的用药安全性判断上需要加强。

## 四、引擎优化建议

### 4.1 增加多系统疾病快速路径

```
【新增】Step 2B：多系统疾病判定

条件：
  - 同时存在≥3个系统疾病（心血管+消化+神经+皮肤等）
  - 或年龄>85岁 + ≥2个慢性病

处理：
  → 跳过单一病种定位
  → 直接进入五维定级
  → 判定为"老年多系统功能障碍"
  → 治疗原则：扶正为主，温和排毒，长期维护

耗时：从15秒缩短至5秒
```

### 4.2 增加用药安全筛查层

```
【新增】Step 1.5：安全筛查（在急症排雷之后）

自动检查：
  □ 年龄 > 85岁？ → 提醒：考虑外治法为主
  □ 肾功能不全（肌酐>133或eGFR<30）？ → 提醒：避免肾毒性药物
  □ 肝功能不全（ALT/AST>3倍）？ → 提醒：避免肝毒性药物
  □ 凝血功能异常？ → 提醒：慎用活血药
  □ 正在服用抗凝药？ → 提醒：注意药物相互作用

如触发≥2项 → 建议方案自动偏向外治法
```

### 4.3 强制瘾维干预

```
【修改】Step 5：瘾维干预强制化

原规则：瘾维≥6级 → 必须有♣牌
新规则：瘾维≥5级 → 必须有♣牌 + 具体干预方案

干预方案模板：
  瘾5级（临界）：
    - 饮食日记（3天）
    - 23点前入睡提醒
  
  瘾6级（轻度）：
    - 正念呼吸（每日10分钟）
    - 作息调整方案
  
  瘾7级（中度）：
    - 正念减压（每周3次，每次20分钟）
    - 情绪日记
    - 社会支持评估
  
  瘾8级（重度）：
    - 心理咨询 referral
    - 成瘾行为干预
    - 家庭支持系统激活
```
