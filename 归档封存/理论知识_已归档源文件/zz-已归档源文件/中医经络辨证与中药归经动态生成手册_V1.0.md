### 2.2 复合证型组合规则

**常见复合证型（自动生成逻辑）**：

```
输入：炁6 + 毒7 + 脉8 + 邪5 + 瘾0
处理：
  ├─ 炁6 → 气虚 + 可能血虚
  ├─ 毒7 → 血瘀（深紫痧）+ 可能湿毒（黄绿毒油）
  ├─ 脉8 → 多经络严重瘀堵（头部+躯干+四肢）
  ├─ 邪5 → 湿困 或 风邪
  └─ 瘾0 → 无特殊情志因素
输出：
  主证：气虚血瘀，湿毒内盛，经络瘀阻
  病位经络：
    - 气虚 → 手太阴肺经、足太阴脾经
    - 血瘀 → 足厥阴肝经、手厥阴心包经
    - 湿毒 → 足太阴脾经、足阳明胃经
    - 头部瘀堵 → 督脉、足太阳膀胱经
    - 四肢瘀堵 → 手足三阳经
```

## 三、经络库（动态匹配）

### 3.1 十二正经+奇经八脉辨证表

#### 【手太阴肺经】
- **主病**：咳嗽、气喘、气短、胸闷、咽喉痛、感冒
- **病候**：气虚、肺燥、皮毛干燥
- **关键穴位**：中府LU1、太渊LU9、尺泽LU5、列缺LU7
- **触诊反应**：太渊弱→肺气虚弱；尺泽结节→肺热/痰热
- **脏腑归属**：肺主气、司呼吸、主皮毛、开窍于鼻

#### 【手阳明大肠经】
- **主病**：便秘、腹泻、牙痛、面肿、肩臂痛
- **病候**：肠燥、肠毒、热毒
- **关键穴位**：合谷LI4、曲池LI11、手三里LI10、迎香LI20
- **触诊反应**：合谷疼痛→头面疾病/感冒；曲池结节→大肠热毒
- **脏腑归属**：大肠主传导糟粕、与肺相表里

#### 【足阳明胃经】
- **主病**：胃胀、胃痛、纳少、呕吐、面肿、下肢痿痹
- **病候**：胃热、胃寒、胃虚、肠毒
- **关键穴位**：足三里ST36、中脘CV12（交会）、天枢ST25、丰隆ST40
- **触诊反应**：足三里虚陷→脾胃虚弱；丰隆结节→痰湿内盛；天枢压痛→肠道疾病
- **脏腑归属**：胃主受纳腐熟、为多气多血之海

#### 【足太阴脾经】
- **主病**：腹胀、便溏、乏力、面色萎黄、水肿、带下
- **病候**：脾虚、湿困、气血不足
- **关键穴位**：三阴交SP6、阴陵泉SP9、血海SP10、太白SP3
- **触诊反应**：三阴交空虚→气血亏虚；阴陵泉水肿→水湿内停；血海瘀堵→血虚血瘀
- **脏腑归属**：脾主运化、主升清、主统血、主肌肉四肢

#### 【手少阴心经】
- **主病**：心悸、失眠、多梦、健忘、胸闷、手小指麻木
- **病候**：心血虚、心火旺、心气虚
- **关键穴位**：神门HT7、内关PC6（心包经）、少海HT3、极泉HT1
- **触诊反应**：神门弱→心血不足；内关紧张→心气郁结；极泉压痛→心经瘀堵
- **脏腑归属**：心主血脉、主神志、开窍于舌

#### 【手太阳小肠经】
- **主病**：肩背疼痛、耳聋、面颊肿、手小指麻木
- **病候**：小肠热、津液不足
- **关键穴位**：肩贞SI9、天宗SI11、后溪SI3、听宫SI19
- **触诊反应**：肩贞天宗酸痛→肩颈疾病；后溪压痛→头项强痛
- **脏腑归属**：小肠主受盛化物、分清泌浊、与心相表里

#### 【足太阳膀胱经】
- **主病**：腰背疼痛、头痛、感冒、小便不利、痔疮
- **病候**：表证、排毒、经络瘀堵
- **关键穴位**：大杼BL11、肺俞BL13、心俞BL15、肝俞BL18、脾俞BL20、肾俞BL23、委中BL40、承山BL57
- **触诊反应**：背俞穴压痛→对应脏腑疾病；委中僵硬→腰背疼痛；承山结节→痔疮/便秘
- **脏腑归属**：膀胱主贮尿排尿；膀胱经为排毒通道、总督一身之表

#### 【足少阴肾经】
- **主病**：腰痛、耳鸣、遗精、月经不调、水肿、畏寒
- **病候**：肾虚、阳虚、阴虚
- **关键穴位**：涌泉KI1、太溪KI3、肾俞BL23（交会）、三阴交SP6（交会）
- **触诊反应**：太溪弱→肾气亏虚；涌泉冷→肾阳虚；太溪弦→肾阴虚
- **脏腑归属**：肾藏精、主水、主纳气、主骨生髓、开窍于耳及二阴

#### 【手厥阴心包经】
- **主病**：心悸、胸闷、癫狂、肘臂挛痛、手心热
- **病候**：心包瘀堵、情志不畅
- **关键穴位**：内关PC6、劳宫PC8、曲泽PC3、天池PC1
- **触诊反应**：内关紧张→心气郁结；劳宫热→心火亢盛；曲泽瘀堵→心包经不通
- **脏腑归属**：心包代心受邪、主神明、保护心脏

#### 【手少阳三焦经】
- **主病**：偏头痛、耳聋、咽喉痛、肩臂痛、胁痛
- **病候**：三焦不通、气机不畅、水道不利
- **关键穴位**：中渚TE3、外关TE5、肩髎TE14、翳风TE17、角孙TE20
- **触诊反应**：外关紧张→三焦不通；肩髎酸痛→肩周疾病；翳风压痛→耳疾
- **脏腑归属**：三焦主气机升降、水道运行、通行元气

#### 【足少阳胆经】
- **主病**：偏头痛、胁痛、口苦、目眩、下肢外侧痛
- **病候**：胆热、胆虚、肝郁（肝胆相表里）
- **关键穴位**：风池GB20、肩井GB21、环跳GB30、风市GB31、阳陵泉GB34、悬钟GB39
- **触诊反应**：风池僵硬→头风/感冒；阳陵泉压痛→胆病/筋病；环跳疼痛→腰腿痛
- **脏腑归属**：胆主决断、贮藏胆汁、与肝相表里、主筋

#### 【足厥阴肝经】
- **主病**：头痛、眩晕、胁痛、月经不调、疝气、下肢内侧痛
- **病候**：肝郁、肝阳上亢、肝风内动、肝血虚
- **关键穴位**：太冲LR3、行间LR2、期门LR14、章门LR13、曲泉LR8
- **触诊反应**：太冲弦紧→肝阳上亢；行间热→肝火旺；期门压痛→肝郁气滞
- **脏腑归属**：肝主疏泄、主藏血、主筋、开窍于目

### 3.2 奇经八脉辨证表

#### 【督脉】
- **循行**：起于胞中，下出会阴，沿脊柱上行，入脑，上巅顶
- **主病**：中风、癫狂、脊柱强痛、头痛、眩晕
- **关键穴位**：长强GV1、腰阳关GV3、命门GV4、至阳GV9、大椎GV14、风府GV16、百会GV20
- **触诊反应**：大椎瘀堵→感冒/头项强痛；命门弱→肾阳虚；百会沉→清阳不升
- **功能**：总督一身之阳脉、入属于脑、统摄全身阳气
- **特殊意义**：**中风必通督脉**（脑为髓海、督脉入脑）

#### 【任脉】
- **循行**：起于胞中，下出会阴，沿腹部正中线上行
- **主病**：月经不调、带下、不孕、遗精、疝气、腹部疾病
- **关键穴位**：中极CV3、关元CV4、气海CV6、中脘CV12、膻中CV17
- **触诊反应**：关元空虚→元气不足；中脘松软→脾胃虚弱；膻中紧张→胸闷气郁
- **功能**：总任一身之阴脉、调节阴经气血

#### 【冲脉】
- **循行**：起于胞中，挟脐上行，散布于胸中
- **主病**：月经不调、不孕、气上冲心、腹痛
- **功能**：十二经之海、血海

#### 【带脉】
- **循行**：环绕腰部一周
- **主病**：腰胁痛、带下、月经不调、下肢痿弱
- **关键穴位**：带脉GB26、五枢GB27
- **功能**：约束纵行诸经、主司妇女带下

## 八、使用说明

### 8.1 操作流程

1. **完成模块一（五维诊断）**
2. **查阅本手册**：根据五维结果，匹配对应证型、经络、穴位、方剂
3. **动态生成模块四**：将匹配结果填入模块四各表格
4. **个性化调整**：根据患者具体症状（如左侧偏瘫、胃胀等）微调

### 8.2 注意事项

- **剂量调整**：本手册只提供药物和归经，具体剂量需由中医师根据患者体质调整

- **循序渐进**：中风、癌症等重症，中药调理需循序渐进，不可峻补猛攻
