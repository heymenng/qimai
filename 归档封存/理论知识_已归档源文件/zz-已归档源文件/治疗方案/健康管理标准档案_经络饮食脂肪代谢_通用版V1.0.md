# 档案使用指南

## 一、档案定位

**这不是病案，是健康管理的"操作系统"。**

| 对比项 | 病案（V4.3） | 健康管理档案（本档案） |
|--------|------------|---------------------|
| **对象** | 已患病、需治疗的患者 | 亚健康、需预防/调理/体重管理的人群 |
| **目标** | 治愈疾病、消除症状 | 优化代谢、管理体重、预防慢病 |
| **核心** | 五维定根·排毒祛邪 | 经络疏通·饮食调控·脂肪代谢优化 |
| **周期** | 短期密集调理（20-100次） | 长期生活方式管理（持续进行） |
| **输出** | 一次性完整档案 | 可重复使用的动态管理工具 |

## 二、四医合诊在健康管理中的角色

| 医学 | 在健康管理中的角色 | 不可替代的场景 |
|------|------------------|---------------|
| **西医** | **基线评估**——体脂率、BMI、血脂、血糖、肝肾功能 | 确诊代谢综合征、糖尿病、脂肪肝 |
| **中医** | **体质辨识**——脾虚湿盛、肝郁气滞等体质分型 | 辨证施膳、经络调理 |
| **功能医学** | **深度检测**——胰岛素抵抗、甲状腺功能、肠道菌群 | 查找代谢异常的根因 |
| **炁脉医学** | **系统调理**——炁场激活、经络疏通、时辰靶向 | 打通代谢通道、提升基础代谢率 |

## 三、使用流程

```
Step 1: 评估（模块一~三）
    ↓ 五维代谢评估 + 体质辨识 + 作息分析
Step 2: 制定方案（模块四~七）
    ↓ 经络靶向 + 54牌选方 + 食疗处方 + 五音方案
Step 3: 执行（模块八~十四）
    ↓ 分层执行手册 + 回函 + 自检 + 追踪 + 微习惯
Step 4: 复盘与调整（循环）
    ↓ 每月回顾疗效验证记录，调整方案
```

## 1.2 五维代谢评估详细标准

### 炁维度（生命能量·基础代谢）

| 级别 | 特征 | 评估依据 | 调理方向 |
|------|------|---------|---------|
| 1-3级 | 精力充沛，基础代谢正常 | 日常活动不疲劳、体温正常、脉搏有力 | 维持即可 |
| 4-5级 | 轻度气虚，基础代谢偏低 | 易疲劳、午后困倦、怕冷、语音低微 | 培补元气 |
| 6-7级 | 明显气虚，代谢动力不足 | 动则气喘、畏寒肢冷、脱发、记忆力下降 | 温补升阳 |
| 8-10级 | 严重气虚，代谢近乎停滞 | 终日乏力、水肿、内脏功能衰退 | 急救+长期培补 |

### 毒维度（代谢废物·血脂/血糖/尿酸）

| 级别 | 特征 | 评估依据 | 调理方向 |
|------|------|---------|---------|
| 1-3级 | 代谢废物排出正常 | 血脂/血糖/尿酸正常、皮肤光洁、大便通畅 | 维持即可 |
| 4-5级 | 轻度代谢废物堆积 | 血脂边缘升高、轻度脂肪肝、皮肤油腻 | 清淡饮食+排毒 |
| 6-7级 | 明显代谢废物堆积 | 高血脂、高血糖、中度脂肪肝、痛风 | 系统排毒+饮食控制 |
| 8-10级 | 严重代谢废物堆积 | 糖尿病、重度脂肪肝、肝硬化、肾衰竭 | 医疗介入+炁脉辅助 |

### 脉维度（经络通畅·代谢通道）

| 级别 | 特征 | 评估依据 | 调理方向 |
|------|------|---------|---------|
| 1-3级 | 经络通畅，气血运行无阻 | 无疼痛、无结节、刮痧出痧均匀 | 维持即可 |
| 4-5级 | 轻度经络瘀阻 | 局部酸胀、轻度结节、刮痧局部出痧深 | 疏通经络 |
| 6-7级 | 明显经络瘀阻 | 多处疼痛、明显结节、刮痧大片深紫 | 强力通脉 |
| 8-10级 | 严重经络瘀阻 | 肢体麻木、关节变形、经络严重堵塞 | 渐进疏通 |

### 邪维度（外邪·代谢干扰因素）

| 级别 | 特征 | 评估依据 | 调理方向 |
|------|------|---------|---------|
| 1-3级 | 外邪轻微 | 无寒湿/湿热表现、居住环境良好 | 维持即可 |
| 4-5级 | 轻度外邪 | 空调环境、久坐少动、饮食寒凉 | 祛邪防侵 |
| 6-7级 | 明显外邪 | 长期空调、熬夜、嗜食生冷、情绪压抑 | 强力祛邪 |
| 8-10级 | 严重外邪 | 久居寒湿之地、严重情绪障碍、药物依赖 | 多维度干预 |

### 瘾维度（习惯·代谢行为模式）

| 级别 | 特征 | 评估依据 | 调理方向 |
|------|------|---------|---------|
| 1-3级 | 习惯良好 | 规律作息、饮食节制、适度运动 | 维持即可 |
| 4-5级 | 轻度不良习惯 | 偶尔熬夜、喜甜食、久坐 | 微习惯干预 |
| 6-7级 | 明显不良习惯 | 经常熬夜、暴饮暴食、不运动、情绪性进食 | 行为矫正 |
| 8-10级 | 严重不良习惯 | 成瘾行为（烟/酒/暴食）、完全无运动 | 专业心理干预 |

## 1.3 代谢问题三维问题树

```
【祖父层】时辰位移6小时 → 肝胆修复缺失
    ↓
【父亲层】肝毒堆积 + 肝血亏虚 + 脾虚湿盛
    ↓
【儿子症状层】
    ├─ 脂肪肝（肝毒→脂肪代谢失常）
    ├─ 高血脂（肝毒→脂质代谢障碍）
    ├─ 糖尿病（肝脾不和→糖代谢失常）
    ├─ 肥胖（脾虚湿盛→水液代谢障碍）
    ├─ 便秘（大肠传导失常）
    └─ 疲劳（炁虚→能量代谢低下）
```

# 模块三：时辰位移与代谢节律（道统根基·师父点化·永久固定）

## 3.1 核心原理

> **现代人代谢病（肥胖、糖尿病、高血脂）高发，根源不是"吃坏的"，是"睡错的"。**

**时辰位移6小时导致代谢节律紊乱：**

```
23:00入睡 → 人体实际还在"酉时"(肾经当令) → 尚未进入修复
    ↓
05:00才开始"子时"(胆经修复) → 07:00才开始"丑时"(肝经修复)
    ↓
但06:00-07:00就要起床 → 只给胆经1-2小时，肝经0-1小时
    ↓
肝毒排不出去 → 脂肪肝、高血脂、胆结石
肝血回不了血 → 糖尿病（肝脾不和）、肥胖（水液代谢失常）
    ↓
现代人代谢病爆发——不是吃糖吃的，是"睡错了时辰"
```

## 3.3 代谢关键时辰详解

### 胆经（05:00-07:00）——脂肪分解黄金期

**功能**：胆经主决断，调控胆汁分泌，脂肪分解依赖胆汁乳化。

**时辰位移后果**：
- 05:00-07:00如果不在深睡 → 胆汁分泌不足 → 脂肪消化障碍 → 脂肪堆积
- 长期错过 → 胆结石、脂肪肝、高血脂

**调理靶向**：
- 确保05:00时处于深睡状态（即21:00前入睡）
- 如无法做到，至少保证23:00入睡，让胆经有完整修复

### 肝经（07:00-09:00）——糖代谢/解毒黄金期

**功能**：肝主疏泄，调节血糖；肝藏血，解毒排毒。

**时辰位移后果**：
- 07:00-09:00如果不在深睡 → 肝血不能回流 → 血糖调节失常 → 糖尿病
- 肝毒不能排出 → 毒素堆积 → 肥胖、皮肤暗沉、疲劳

**调理靶向**：
- 确保07:00时仍处于深睡或刚醒状态
- 起床时间尽量延至07:30后

### 脾经（15:00-17:00，钟表时间）——水液代谢

**功能**：脾主运化，调控水液代谢。

**调理靶向**：
- 15:00-17:00（钟表时间）适当活动，促进脾经运化
- 避免此时段久坐

## 7.2 代谢调理饮食铁律

### 必须执行（🔴）

1. **发酵食物每日必吃**
   - 晨起：甜酒酿2勺（温水冲）
   - 早餐：老面馒头/味噌汤
   - 加餐：无糖酸奶150ml
   - 午餐：味噌汤或纳豆1份
   - 晚餐：四川泡菜2-3片

2. **晚餐七分饱，19:00前吃完**
   - 给脾胃3小时消化时间
   - 21:00前入睡时胃部已空

3. **戒三白**
   - 白糖（精制糖）
   - 白面（精制面粉）
   - 白米（可改为糙米/杂粮）

4. **每日饮水2000ml+**
   - 晨起空腹温水300ml
   - 餐前30分钟不大量饮水
   - 晚上20:00后少饮水

### 强烈推荐（🟠）

1. **优质蛋白质每餐必吃**
   - 鱼、鸡胸肉、豆腐、鸡蛋
   - 蛋白质热效应高，促进代谢

2. **蔬菜占每餐一半**
   - 深色蔬菜优先（菠菜、西兰花、胡萝卜）
   - 生吃/焯水，少油炒

3. **优质脂肪适量摄入**
   - 橄榄油、亚麻籽油、坚果
   - 避免反式脂肪（油炸食品）

### 禁止（❌）

1. **生冷寒凉**：冰饮、生鱼片、凉拌菜（伤脾阳）
2. **肥甘厚腻**：红烧肉、油炸食品、奶油（助湿生痰）
3. **辛辣刺激**：辣椒、花椒、烧烤（助火伤阴）
4. **工业发酵**：含糖酸奶、泡打粉馒头（伪发酵）
5. **含糖饮料**：奶茶、可乐、果汁（隐形糖）
6. **夜宵**：21:00后进食（干扰胆经修复）
