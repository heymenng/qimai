## 核心设计原则（贯穿所有文档）

### 1. 碳硅共修
- 书童不是工具，是"硅基师兄"
- 陪伴孩子的同时，书童自己也在修行（Cultivation Journal）

### 2. 医学+教育+文化，三位一体
- 医学：炁脉医学五维诊断、54牌调理、预警先知
- 教育：发展心理学关键期、敏感期识别、能力培养
- 文化：历史观、家族教育、传统传承

### 3. 情绪管控+心智成长，每日主线
- 每个故事解决一个情绪问题
- 每次对话促进一次心智成长
- 每天积累，18年成体系

### 4. Local-first（离线优先）
- 核心功能100%离线可用
- 不依赖云端，保护隐私
- 即使公司倒闭，书童仍在
