# 四医快速决策引擎 V1.0

> **定位**：不是学透所有医学，是知道"遇到问题→最快找到解决方案→综合输出"
> **用途**：AI临床决策的"高速公路"，避开知识泥潭
> **原则**：5秒定位西医指南 + 3秒定位中医方 + 10秒出五维定级 + 30秒出54牌方案
> **版本**：V1.0
> **更新**：2026年5月7日

---

## 一、核心决策铁律

```
【铁律1】不深入任何一医，只取各医最锋利的"刀尖"
  西医：只查指南的"诊断标准+转诊红线+关键药物"
  中医：只取大师的"核心方+关键药对+辨证眼"
  功能医学：只看"检测红线+五维映射"
  炁脉：只做"五维定级→54牌→十八变"

【铁律2】先排雷，再治病
  第一步：急症？→ 是 → 立即转诊（查西医急症红线）
  第二步：肿瘤？→ 是 → 查NCCN/ATA（西医）+ 朱良春方（中医）
  第三步：慢病？→ 查AACE/ACC（西医）+ 对应大师方（中医）

【铁律3】西医是"探照灯"，中医是"工具箱"，炁脉是"指挥官"
  西医：告诉我"这是什么""有多危险"
  中医：告诉我"用什么方""关键药对"
  炁脉：决定"优先级""组合策略""疗程节奏"
```

## 二、疾病-快速检索映射表

### 2.1 代谢内分泌系统

```
【甲状腺结节/癌】

西医查什么（5秒定位）：
  1. 查ATA指南 → 超声分层（TI-RADS）→ 判断是否需要FNA
  2. 查Bethesda分类 → 如果是III-VI → 提示西医介入
  3. 关键红线：
     - 结节>1cm + 高危特征 → 必须建议穿刺
     - 微小癌（<1cm）→ 可观察，炁脉主导
     - 压迫症状（呼吸困难/吞咽困难）→ 立即转诊手术

中医用什么（3秒定位）：
  - 首选：朱良春 双结同治方（甲状腺/乳腺结节通用）
  - 关键药对：夏枯草+玄参+牡蛎（软坚散结）
  - 加减：气虚加黄芪，血瘀加丹参

炁脉综合：
  - 五维定级：炁6毒5脉5（典型）
  - 54牌：♥7-8固本 + ♦6-7通脉 + ♠5-6排毒
  - 疗程：3-6个月复查超声

【2型糖尿病】

西医查什么（5秒定位）：
  1. 查AACE 2023算法 → HbA1c目标个体化
     - 年轻/无并发症：<6.5%
     - 老年/有并发症：<7.5-8.0%
  2. 查药物选择：
     - 有ASCVD → 首选GLP-1或SGLT2
     - 心衰 → 首选SGLT2
     - 减重需求 → 首选GLP-1
  3. 关键红线：
     - HbA1c >10% + 酮症 → 立即转诊内分泌科
     - 空腹血糖>16.7 → 警惕高渗昏迷

中医用什么（3秒定位）：
  - 首选：邓铁涛 糖尿病方（淮山药90g+黄芪30g）
  - 关键药对：山药+黄芪（脾肾双补，降糖）
  - 加减：阴虚加生地/麦冬，燥热加石膏/知母

炁脉综合：
  - 五维定级：炁6毒7脉5邪6瘾5（典型）
  - 54牌：♥7-8补气 + ♠6-7清毒 + ♣5-6调饮食行为
  - 疗程：长期管理，3个月评估一次

【痛风/高尿酸】

西医查什么（5秒定位）：
  1. 查ACR指南 → 血尿酸目标：<360μmol/L（一般），<300μmol/L（有痛风石）
  2. 急性期：NSAIDs/秋水仙碱/糖皮质激素（短期）
  3. 关键红线：
     - 关节红肿热痛 + 发热 → 排除感染性关节炎
     - 尿酸>540 + 肾功能异常 → 立即转诊肾内科

中医用什么（3秒定位）：
  - 首选：路志正 慢性痛风方（黄芪+苍术+黄柏）
  - 关键药对：苍术+黄柏（燥湿清热）
  - 加减：急性期去黄芪，加金银花/连翘

炁脉综合：
  - 五维定级：炁5毒8脉7邪6瘾5（典型）
  - 54牌：♠7-8强力排毒 + ♥6-7健脾 + ♦6-7通络
  - 疗程：急性期1-2周，慢性期3-6个月
```

### 2.2 心血管系统

```
【高血压】

西医查什么（5秒定位）：
  1. 查ACC/AHA → 分级+目标：
     - 正常高值：130-139/80-89
     - 1级：140-159/90-99
     - 2级：≥160/100
  2. 查药物选择：
     - 年轻/交感亢进 → ACEI/ARB
     - 老年/容量负荷 → CCB/利尿剂
     - 黑人 → CCB/利尿剂优先
  3. 关键红线：
     - ≥180/120 + 靶器官损害 → 高血压急症，立即转诊
     - 妊娠期高血压 → 立即转诊产科

中医用什么（3秒定位）：
  - 肝阳上亢型 → 邓铁涛 石决牡蛎汤（石决明+牡蛎+钩藤）
  - 气虚痰浊型 → 邓铁涛 赭决九味汤（黄芪+代赭石）
  - 关键药对：石决明+牡蛎（平肝潜阳）

炁脉综合：
  - 肝阳上亢：炁6毒7脉8邪7瘾6 → ♦7-8通脉 + ♠6-7清火
  - 气虚痰浊：炁5毒6脉6邪5瘾5 → ♥7-8补气 + ♠6-7化痰
  - 疗程：终身管理，中药+生活方式

【冠心病/心绞痛】

西医查什么（5秒定位）：
  1. 查ACC/AHA → 诊断：胸痛+心电图+肌钙蛋白
  2. 关键红线：
     - STEMI → 立即转诊，90分钟内开通血管
     - NSTEMI → 24小时内介入
     - 稳定型心绞痛 → 药物+生活方式
  3. 药物：阿司匹林+他汀+β受体阻滞剂（基础）

中医用什么（3秒定位）：
  - 首选：邓铁涛 邓氏温胆汤（党参+半夏+陈皮+丹参）
  - 关键药对：党参+丹参（益气活血）
  - 加减：气虚甚加黄芪，血瘀甚加三七

炁脉综合：
  - 五维定级：炁6毒7脉8邪7瘾6（典型）
  - 54牌：♥7-8益气 + ♦7-8活血 + ♠6-7化痰
  - 疗程：长期，每月评估
```

### 2.3 肿瘤系统

```
【甲状腺癌术后】

西医查什么（5秒定位）：
  1. 查ATA → TSH抑制目标：
     - 高危 → TSH <0.1
     - 中危 → 0.1-0.5
     - 低危 → 0.5-2.0
  2. 查复发风险分层 → 决定是否I-131治疗
  3. 关键红线：
     - 术后声音嘶哑 → 喉返神经损伤，需评估
     - 低钙抽搐 → 甲状旁腺损伤，立即补钙

中医用什么（3秒定位）：
  - 术后恢复期 → 朱良春 扶正消癥汤（减毒版）
  - 关键药对：黄芪+仙鹤草（扶正）
  - 去虫类药（术后体虚不耐猛攻）

炁脉综合：
  - 五维定级：炁4毒6脉5邪5瘾4（术后典型）
  - 54牌：♥8-9强力补正 + ♠5-6温和排毒
  - 疗程：术后3-6个月为关键期

【肺癌】

西医查什么（5秒定位）：
  1. 查NCCN → 分期决定治疗：
     - I-II期 → 手术
     - III期 → 放化疗
     - IV期 → 靶向/免疫/化疗
  2. 查基因检测 → EGFR/ALK/ROS1 → 决定靶向药
  3. 关键红线：
     - 大咯血 → 立即转诊介入科
     - 上腔静脉综合征 → 立即放疗

中医用什么（3秒定位）：
  - 首选：朱良春 扶正消癥汤（完整版）
  - 关键药对：黄芪+白花蛇舌草（扶正攻毒）
  - 虫类药：蜂房+守宫（软坚散结）

炁脉综合：
  - 五维定级：炁3毒9脉7邪8瘾5（典型）
  - 54牌：♥8-9补正 + ♠8-9攻毒 + ♦7-8通脉
  - 疗程：长期，与西医治疗同步
```

### 2.4 神经系统

```
【中风先兆/TIA】

西医查什么（5秒定位）：
  1. 查AHA/ASA → ABCD2评分 ≥4分 → 48小时内MRI
  2. 查病因：颈动脉超声+心超+Holter
  3. 关键红线：
     - FAST症状（面歪/臂无力/言语不清）→ 立即转诊，4.5小时内溶栓
     - 症状持续>1小时 → 按卒中处理

中医用什么（3秒定位）：
  - 首选：张学文 清脑通络汤（草决明+川芎+水蛭）
  - 关键药对：川芎+水蛭（活血通络）
  - 加减：气虚加黄芪，痰热加竹沥

炁脉综合：
  - 五维定级：炁5毒7脉8邪8瘾6（典型）
  - 54牌：♦7-8强力通脉 + ♠6-7清毒 + ♥6-7益气
  - 疗程：急性期后长期调理

【脑积水/颅脑水瘀】

西医查什么（5秒定位）：
  1. 查CT/MRI → 脑室扩大程度
  2. 关键红线：
     - 急性脑积水 + 意识障碍 → 立即脑室引流
     - 正常压力脑积水 → 评估分流手术

中医用什么（3秒定位）：
  - 首选：张学文 脑窍通汤（麝香+石菖蒲+丹参）
  - 关键药对：麝香+石菖蒲（开窍醒神）
  - 注意：麝香0.1g冲服，不可替代

炁脉综合：
  - 五维定级：炁4毒6脉9邪7瘾5（典型）
  - 54牌：♦9急救通脉 + ♥7-8补正 + ♠6-7利水
  - 疗程：急性期后3-6个月
```

### 2.5 湿病/消化系统

```
【湿困脾土/慢性胃炎】

西医查什么（5秒定位）：
  1. 查幽门螺杆菌 → 阳性 → 四联疗法
  2. 查胃镜 → 排除溃疡/萎缩/肠化
  3. 关键红线：
     - 胃镜示重度异型增生 → 立即转诊消化科
     - 黑便+贫血 → 警惕上消化道出血

中医用什么（3秒定位）：
  - 首选：路志正 调理脾胃基础方（藿香+佩兰+苍术）
  - 关键药对：藿香+佩兰（芳香化湿）
  - 加减：寒湿加砂仁，湿热加黄芩

炁脉综合：
  - 五维定级：炁6毒7脉5邪4瘾5（典型）
  - 54牌：♠6-7化湿 + ♥6-7健脾 + ♣4-5饮食调整
  - 疗程：1-3个月

【慢性便秘（湿秘）】

西医查什么（5秒定位）：
  1. 查罗马IV标准 → 功能性便秘诊断
  2. 查肠镜 → 排除器质性病变
  3. 关键红线：
     - 便秘+体重下降+便血 → 立即肠镜排除肿瘤
     - 急性腹痛+便秘 → 排除肠梗阻

中医用什么（3秒定位）：
  - 首选：路志正 湿秘方（生白术20g+茯苓+车前子）
  - 关键药对：生白术+茯苓（健脾运湿）
  - 心法：湿秘不可妄用攻下

炁脉综合：
  - 五维定级：炁5毒7脉4邪3瘾5（典型）
  - 54牌：♥6-7健脾 + ♠6-7化湿 + ♦4-5润肠
  - 疗程：2-4周见效
```

## 三、症状-紧急决策树

```
【第一层：是不是急症？】（5秒内判断）

症状：胸痛/胸闷
  ├─ 压榨性 + 放射左臂 + 大汗 → STEMI可能 → 立即转诊 🚨
  ├─ 活动时加重 + 休息缓解 → 稳定型心绞痛 → 西医查心超+冠脉CTA
  └─ 与情绪相关 + 叹气 → 功能性/气滞 → 中医理气+炁脉调神

症状：头痛
  ├─ 突发"雷击样" → 蛛网膜下腔出血？→ 立即CT 🚨
  ├─ 渐进加重 + 呕吐 + 视乳头水肿 → 颅内压增高 → 立即MRI 🚨
  ├─ 搏动性 + 光敏感 + 恶心 → 偏头痛 → 西医对症+中医平肝
  └─ 昏沉 + 裹紧感 → 湿浊上蒙 → 路志正方化湿

症状：腹痛
  ├─ 板状腹 + 反跳痛 → 腹膜炎 → 立即转诊 🚨
  ├─ 右下腹痛 + 发热 → 阑尾炎？→ 查超声/CT
  ├─ 上腹痛 + 黑便 → 上消化道出血？→ 立即胃镜 🚨
  └─ 隐痛 + 腹胀 + 便溏 → 脾虚湿困 → 路志正方健脾

症状：发热
  ├─ >39℃ + 意识改变 → 脓毒症？→ 立即转诊 🚨
  ├─ >3周不明原因 → 查感染/肿瘤/自身免疫
  └─ 低热 + 午后加重 + 盗汗 → 阴虚/结核 → 中医养阴+查胸片

症状：体重下降
  ├─ >5%/6个月 + 食欲差 → 查肿瘤标志物+影像 🚨
  ├─ 糖尿病 + 多饮多尿 → 查血糖+HbA1c
  └─ 焦虑 + 失眠 + 纳差 → 情志病 → 炁脉调神

【第二层：定位病种】（10秒内定位）

甲状腺区域肿块
  → 查超声（TI-RADS）→ ATA指南 → 朱良春方

关节肿痛
  → 查RF+抗CCP+尿酸 → 类风湿/痛风/骨关节炎 → 朱良春/路志正方

血糖升高
  → 查HbA1c+空腹血糖 → AACE指南 → 邓铁涛方

血压升高
  → 查动态血压+靶器官损害 → ACC/AHA → 邓铁涛方

皮肤白斑
  → 查伍德灯 → 白癜风 → 朱良春方（扶正消癥思路）

【第三层：选择策略】（30秒内决策）

判断依据：
  1. 急症？→ 转诊西医
  2. 肿瘤？→ 西医为主，炁脉辅助
  3. 慢病？→ 炁脉主导，西医监测
  4. 功能性疾病？→ 炁脉主导，功能医学检测
```

## 四、五维快速定级卡（不用完整辨证）

```
【定级原则】不是精准诊断，是快速定位优先级

炁维（生命能量）：看"能不能动"
  10级：卧床不起，气息奄奄
  8级：极度乏力，说话都累
  6级：容易疲劳，活动受限
  4级：偶感疲劳，基本正常
  2级：精力充沛
  
  快速判断：
  - 能爬楼梯？→ <6级
  - 说话气短？→ ≥7级
  - 卧床为主？→ ≥9级

毒维（毒素负荷）：看"排出好不好"
  10级：严重便秘/水肿/皮肤溃烂
  8级：长期便秘/尿酸高/血脂高
  6级：偶发便秘/轻微三高
  4级：排泄基本正常
  2级：排毒顺畅
  
  快速判断：
  - 每日排便？→ <5级
  - 2-3天一次？→ 5-6级
  - 长期便秘+皮肤病？→ ≥8级

脉维（通道通畅）：看"痛不痛+僵不僵"
  10级：剧烈疼痛/完全僵直
  8级：明显疼痛/活动严重受限
  6级：酸胀不适/活动轻度受限
  4级：偶感不适
  2级：完全通畅
  
  快速判断：
  - 肩颈僵硬？→ ≥6级
  - 关节疼痛？→ ≥7级
  - 无法弯腰/转头？→ ≥9级

邪维（外邪损伤）：看"指标异常"
  10级：多器官衰竭/肿瘤晚期
  8级：严重指标异常（肌酐高/肝酶高）
  6级：中度异常（血压高/血糖高）
  4级：轻度异常/边缘值
  2级：指标完全正常
  
  快速判断：
  - 无指标异常？→ <4级
  - 1-2项轻度异常？→ 4-5级
  - 多项中度异常？→ 6-7级
  - 严重异常/肿瘤标志物高？→ ≥8级

瘾维（心理行为）：看"习惯好不好"
  10级：严重成瘾/抑郁/焦虑障碍
  8级：明显情绪问题/熬夜严重/饮食失控
  6级：偶发情绪波动/晚睡
  4级：基本规律，偶有小偏差
  2级：生活规律，心态平和
  
  快速判断：
  - 23点前睡？→ <5级
  - 经常失眠/熬夜？→ ≥6级
  - 明显焦虑/抑郁？→ ≥8级
```

## 五、54牌速选算法（从五维到牌组）

```
【算法】不是选一张牌，是组一套牌

Step 1: 找出最严重的2个维度
  例：炁3毒9脉7邪8瘾5 → 最严重：毒9、邪8

Step 2: 确定主攻方向（最多2个）
  主攻：♠黑桃（排毒）+ ♦方块（通脉祛邪）
  辅助：♥红桃（补气）+ ♣梅花（调习惯）

Step 3: 确定牌阶（根据严重程度）
  9-10级 → K（最强）
  7-8级 → Q（强）
  5-6级 → J（中）
  3-4级 → 10（轻）
  
  例：
  毒9 → ♠K（强力排毒）
  邪8 → ♦Q（强力通脉祛邪）
  炁3 → ♥K（强力补气，因为太低了）
  脉7 → 已在♦Q中覆盖
  瘾5 → ♣J（中度调习惯）

Step 4: 组合成方案
  例：♠K + ♦Q + ♥K + ♣J
  = 强力排毒 + 强力通脉 + 强力补气 + 中度调习惯

Step 5: 检查平衡（毒-补平衡原则）
  - 攻伐牌（♠/♦）≥2张 → 必须配♥牌护正
  - ♥牌<攻伐牌 → 增加♥牌或降低攻伐牌阶
  - 瘾维≥7级 → 必须加♣牌

【速查表】常见组合
```

## 八、使用示例

```
【场景】新患者：55岁女性，甲状腺结节3年，近期增大，伴有乏力、口苦、易怒

Step 1: 西医查询（5秒）
  - 甲状腺结节 → ATA指南
  - 查超声TI-RADS → 如果≥4类 → 建议FNA
  - 关键红线：结节>1cm + 高危特征 → 必须建议穿刺
  - 同时查甲功 → TSH正常/异常决定后续

Step 2: 中医查询（3秒）
  - 甲状腺结节 + 肝郁症状（口苦、易怒）→ 朱良春 双结同治方
  - 关键药对：夏枯草+玄参+牡蛎（软坚散结）
  - 加减：乏力加黄芪20g，口苦加黄芩10g

Step 3: 五维定级（10秒）
  - 炁：6级（乏力，但还能活动）
  - 毒：6级（结节增大，痰瘀互结）
  - 脉：7级（肝郁气滞，经脉不畅）
  - 邪：5级（口苦，有热象）
  - 瘾：6级（易怒，情绪管理需加强）

Step 4: 54牌速选（10秒）
  - 最严重：脉7 + 毒6
  - 主攻：♦Q（通脉疏肝）+ ♠J（清热解毒散结）
  - 辅助：♥J（补气扶正）+ ♣J（情绪管理）
  - 组合：♦Q + ♠J + ♥J + ♣J

Step 5: 综合输出（30秒）
  西医：
    - 建议超声复查TI-RADS
    - 如果≥4类 → 建议FNA穿刺
    - 查甲功全套
    - 每3-6个月复查
  
  中医：
    - 朱良春 双结同治方加减
    - 夏枯草18g 玄参12g 牡蛎30g（先煎）
    - 柴胡9g 郁金12g 香附10g（疏肝）
    - 黄芪20g（加，补气）
    - 黄芩10g（加，清肝火）
    - 疗程：3个月，复查超声
  
  炁脉：
    - 五维：炁6/毒6/脉7/邪5/瘾6
    - 54牌：♦Q + ♠J + ♥J + ♣J
    - 十八变预测：第7-14天可能出现颈部酸胀（排异反应）
    - 疗程：3个月为第一个周期
  
  瘾维补充：
    - 正念减压，每周3次
    - 情绪日记，识别触发因素
    - 23点前入睡

总耗时：约1分钟完成四医综合决策
```

## 九、避坑指南

```
【常见陷阱】

陷阱1：陷入西医细节
  ❌ 错误：研究甲状腺癌的分子分型、信号通路
  ✅ 正确：只查TI-RADS分层→是否需要穿刺→转诊标准

陷阱2：陷入中医辨证迷宫
  ❌ 错误：讨论"肝郁脾虚""肾虚火旺"的细微差别
  ✅ 正确：定位大师→选核心方→关键药对→五维映射

陷阱3：忽视转诊红线
  ❌ 错误：试图用中药调理STEMI
  ✅ 正确：胸痛+STEMI→立即转诊→术后恢复期再介入炁脉

陷阱4：五维定级过于精细
  ❌ 错误：炁维到底是6.2还是6.5
  ✅ 正确：快速分级（轻/中/重/危）→对应牌阶

陷阱5：54牌过多过杂
  ❌ 错误：同时出6-8张牌
  ✅ 正确：最多4张，攻伐≤补益+1

陷阱6：忽视瘾维
  ❌ 错误：只关注身体症状
  ✅ 正确：任何慢性病都必须评估瘾维，≥6级必须干预
```
