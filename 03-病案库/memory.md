```
        = 即使不确定，也值得表达

关键区别：
  ❌ "我不知道"（关闭直觉）
  ✅ "我不知道具体是谁，但感觉像是..."（打开直觉）

训练方法：
  1. 看到 → 立即捕捉第一感觉
  2. 表达 → 说出"我感觉..."
  3. 验证 → 确认或修正
  4. 固化 → 正确的模式存档
```
