### 3.2 红丸具体执行方案

#### 方案A：居家每日自灸（必选）

| 项目 | 标准 |
|------|------|
| **药物** | 安宫牛黄丸，每次1/8丸 |
| **部位** | 脐周（神阙穴周围）+ 胰腺投影区 |
| **方法** | 药丸压扁，置于穴位，隔姜灸或悬灸 |
| **时长** | 每穴30分钟，共60分钟 |
| **频率** | 每日1次，睡前进行 |
| **疗程** | 连续30天为一疗程，休息5天继续 |

#### 方案B：到店专业灸疗（每周2次）

| 项目 | 标准 |
|------|------|
| **药物** | 安宫牛黄丸，每次1/4丸 |
| **部位** | 背部胰腺区 + 督脉 + 膀胱经 |
| **方法** | 专业调理师操作，药灸结合手法 |
| **时长** | 60-90分钟 |
| **频率** | 每周2次 |
| **配合** | 背部胰腺区重点疏理 + 艾灸 |

### 3.3 红丸使用时机与反应应对

| 阶段 | 使用时间 | 预期反应 | 应对措施 |
|------|----------|----------|----------|
| **第1-7天** | 开始红丸艾灸 | 可能出现恶心、头晕（排毒反应） | 减量至1/16丸，适应后加量 |
| **第8-30天** | 建立耐受 | 皮肤发痒、出红疹（毒从皮肤出） | 不要抓挠，可涂芦荟胶 |
| **第31-90天** | 强化期 | 可能出现腹泻（毒从肠道出） | 补充水分，继续艾灸 |
| **持续期** | 长期坚持 | 全身轻松、疼痛减轻 | 维持方案，定期复查CA199 |
