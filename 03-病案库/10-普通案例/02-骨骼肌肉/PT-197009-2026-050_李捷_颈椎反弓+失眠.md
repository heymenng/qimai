## 7.2 动态食疗决策框架

```
【动态食疗方案 · 李捷专用】

核心原则：不是"今天周一所以吃A"，是"今天身体状态X所以吃Y"

每日基础（不变）：
├─ 晨起：温水200ml + 少量蜂蜜（润肠，防便稀加重）
├─ 早餐：小米粥/山药粥 + 蒸南瓜 → 健脾养胃，保护GIST术后肠道
├─ 午餐：清淡荤素搭配，必有绿色蔬菜 → 疏肝
├─ 下午茶：枸杞菊花茶（清肝明目，降肝阳）
├─ 晚餐：清淡为主，七分饱 → 防夜食生湿
└─ 睡前2小时：不进食 → 让肝胆休息

【动态调整触发条件 + 对应方案】

触发1：今日颈椎僵硬加重、手麻、头痛
→ 判定：肝风内动加重
→ 当日主攻：平肝熄风，通络止痛

   • 早餐：天麻钩藤粥（天麻5g、钩藤10g、粳米50g）

   • 晚餐：菠菜猪肝汤 + 蒸红薯（养血柔肝）
→ 茶饮：菊花枸杞决明子茶（清肝明目）
→ 忌口：羊肉、韭菜（助阳动风）

触发2：今日失眠严重、急躁易怒
→ 判定：肝阳上亢，心火偏旺
→ 当日主攻：滋水涵木，降火安神
→ 推荐食谱：
   • 早餐：酸枣仁粥（酸枣仁15g、粳米50g）

   • 晚餐：紫菜蛋花汤 + 蒸山药（滋肾健脾）
→ 茶饮：百合莲子心茶（清心火，不苦伤胃）
→ 忌口：咖啡、浓茶、辛辣（助火）

触发3：今日饮酒后/酒后次日
→ 判定：肝毒加重，湿热内蕴
→ 当日主攻：清肝解毒，护胃解酒
→ 推荐食谱：
   • 早餐：葛根粉粥（葛根30g、粳米50g，解酒毒）
   • 午餐：绿豆汤 + 清炒苦瓜（清热解毒）
   • 晚餐：山药薏米粥 + 蒸南瓜（健脾祛湿）
→ 茶饮：茵陈陈皮茶（清肝利胆，理气化湿）
→ 必须：当日不再饮酒！次日也不再饮！

触发4：今日足冷、腰酸、便稀
→ 判定：肾阳虚加重，脾阳不足
→ 当日主攻：温肾健脾，固摄止泻

触发5：今日腹胀、消化不良
→ 判定：脾虚湿困加重

## 7.3 禁忌清单

```
【绝对禁忌】
❌ 生冷寒凉：冰饮、生鱼片、凉拌菜、西瓜（伤脾阳，加重足冷/便稀）
❌ 辛辣刺激：辣椒、花椒、烧烤（助肝火，加重失眠/颈僵）
❌ 肥甘厚腻：红烧肉、油炸食品（生湿毒，加重血脂/脾虚）
❌ 过量饮酒：白酒>50ml/日，啤酒>300ml/日（肝毒累积，抵消所有调理效果）
❌ 过量海鲜：螃蟹、贝类（寒湿+高嘌呤，加重足冷/湿毒）
❌ 咖啡因过量：咖啡>1杯/日，浓茶>2杯/日（扰神，加重失眠）

【相对禁忌】
⚠️ 羊肉、韭菜：肝风内动日慎用（助阳动风）
⚠️ 甜腻食物：蛋糕、巧克力（助湿困脾）
⚠️ 糯米制品：粽子、年糕（难消化，脾虚日慎用）
⚠️ 过度滋补：人参、鹿茸（阳气过亢，助肝火）

【特殊注意（GIST术后）】
⚠️ 避免粗糙难消化食物：竹笋、芹菜梗（术后肠道敏感）
⚠️ 避免刺激性食物：过酸、过辣（保护胃肠粘膜）
⚠️ 少量多餐：一次不宜过饱（减轻胃肠负担）
```

→ 目标：建立睡前仪式

第5-8周：强化期
→ 加入习惯2（饮酒加倍泡脚）+ 习惯5（情绪急救）
→ 所有习惯全面执行
→ 目标：形成稳定routine

第9-12周：固化期
→ 无需提醒，自动执行
→ 评估疗效：睡眠、颈椎、情绪
→ 目标：瘾级从6级降至5级

【关键里程碑】
□ 第4周：平均入睡时间提前至23:30
□ 第8周：平均入睡时间提前至23:00
□ 第12周：安眠药使用减少50%
□ 第12周：饮酒频率≤2次/周
```

## 14.3  relapse（复发）应对预案

```
【复发应对预案】

场景1：某晚应酬，饮酒过量，次日症状回弹
→ 当日：加倍泡脚（2包通神露，45℃，30分钟）
→ 次日：预约加急调理（如有条件）
→ 饮食：触发3（清肝解毒日）
→ 不自责，记录原因，下次预防

场景2：连续熬夜，失眠加重，安眠药加量
→ 当日：羽调音乐40分钟 + 艾灸涌泉穴
→ 次日：必须补觉（午休30分钟）
→ 饮食：触发2（安神降火日）
→ 联系调理师，调整方案

场景3：颈椎症状突然加重（剧烈疼痛/手麻加重）
→ 立即停止颈部活动
→ 热敷颈部（非急性期）
→ 如伴头痛/眩晕/肢体无力 → 立即就医（排除中风）
→ 联系调理师，紧急评估

【心理建设】
复发是正常的，不代表失败。
关键是：复发后多久能回到轨道。
目标是让"轨道"越来越宽，让"复发"越来越少。
```
