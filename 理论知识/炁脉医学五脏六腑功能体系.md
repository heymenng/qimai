# 炁脉医学五脏六腑功能体系与动态标准

> **师父点化**：脏腑不是解剖器官，是**炁机运行的功能集群**。看功能，不看形；看炁机，不看指标。

---

## 一、五脏功能体系（藏精气而不泻）

### 1. 心（君主之官）

**炁脉功能定位**：
- **主神明**：精神、意识、思维活动的总枢
- **主血脉**：推动血液运行的动力源
- **开窍于舌**：舌为心之苗
- **其华在面**：面色反映心气盛衰

**五维对应**：
| 维度 | 心系统关联 |
|------|-----------|
| **炁** | 心气充沛 → 精神饱满，思维敏捷 |
| **毒** | 痰毒蒙蔽心神 → 失眠、健忘、痴呆 |
| **脉** | 心脉堵痹 → 胸闷、心悸、心绞痛 |
| **邪** | 热邪扰心 → 心烦、口舌生疮 |
| **瘾** | 神不守舍 → 焦虑、抑郁、精神空窗 |

**时辰位移**：
- **午时11-13点**（心经当令）：必须午休，养心
- **戌时19-21点**（心包经当令）：放松调息，护心神

**失常表现**：
- 心气虚：乏力、气短、心悸、自汗
- 心阳虚：畏寒、肢冷、心痛、水肿
- 心阴虚：心烦、失眠、盗汗、口干
- 痰迷心窍：神志不清、痴呆、抑郁

**恢复标准（年轻/本来健康态）**：
- 精神饱满，思维清晰（神明归位）
- 面色红润有光泽（其华在面）
- 睡眠深沉，梦少（神能入舍）
- 舌体淡红，苔薄白（开窍于舌）

---

### 2. 肝（将军之官）

**炁脉功能定位**：
- **主疏泄**：调畅全身气机，疏通情志
- **主藏血**：贮藏血液，调节血量
- **主筋**：筋脉的濡养与舒展
- **开窍于目**：目得血而能视
- **其华在爪**：指甲的荣枯反映肝血盛衰

**五维对应**：
| 维度 | 肝系统关联 |
|------|-----------|
| **炁** | 肝气条达 → 情志舒畅，气机通畅 |
| **毒** | 肝郁化火 → 易怒、目赤、头痛 |
| **脉** | 肝经堵痹 → 胁痛、乳房胀痛、疝气 |
| **邪** | 风邪伤肝 → 抽搐、震颤、麻木 |
| **瘾** | 郁怒成瘾 → 情绪失控，暴怒或抑郁 |

**时辰位移**：
- **丑时01-03点**（肝经当令，位移后**辰时07-09点**）：
  - 深睡养肝血
  - 早餐必吃（肝血生发需营养）

**失常表现**：
- 肝郁气滞：胸闷、胁痛、情绪抑郁、月经不调
- 肝火上炎：目赤肿痛、头痛、急躁易怒
- 肝血不足：目涩、夜盲、筋挛、指甲脆裂、肌肉萎缩（如王威南左臂细）
- 肝风内动：抽搐、震颤、中风先兆

**恢复标准（年轻/本来健康态）**：
- 情志平和，不易怒也不抑郁（疏泄正常）
- 目光明亮，不干涩（开窍于目）
- 指甲红润饱满，无横纹（其华在爪）
- 筋脉柔和，运动协调（主筋）
- 睡眠深沉，不多梦（肝血归藏）

---

### 3. 脾（仓廪之官）

**炁脉功能定位**：
- **主运化**：运化水谷精微，化生气血
- **主升清**：升发清阳，输布营养
- **主统血**：统摄血液在脉中运行
- **主肌肉**：肌肉的营养与丰满
- **开窍于口**：口味反映脾胃状态
- **其华在唇**：口唇的润泽反映脾血盛衰

**五维对应**：
| 维度 | 脾系统关联 |
|------|-----------|
| **炁** | 脾炁健运 → 食欲好，消化吸收佳 |
| **毒** | 湿毒困脾 → 腹胀、便溏、身重困倦 |
| **脉** | 脾经堵痹 → 消化不良，营养不布 |
| **邪** | 湿邪伤脾 → 腹泻、水肿、痰多 |
| **瘾** | 思虑伤脾 → 食欲不振，茶饭不思 |

**时辰位移**：
- **巳时09-11点**（脾经当令）：
  - 脾胃运化最旺时段
  - 适合学习、工作（气血充足）

**失常表现**：
- 脾气虚：食欲不振、腹胀、便溏、乏力、消瘦
- 脾阳虚：畏寒、腹痛、腹泻、水肿
- 湿困脾土：身重困倦、口黏腻、舌苔厚腻
- 脾不统血：各种出血（便血、崩漏、紫癜）

**恢复标准（年轻/本来健康态）**：
- 食欲正常，食后无腹胀（运化正常）
- 大便成形，不黏腻（湿毒已清）
- 肌肉丰满有力，不消瘦（主肌肉）
- 口唇红润饱满（其华在唇）
- 口味正常，不贪嗜异味（开窍于口）

---

### 4. 肺（相傅之官）

**炁脉功能定位**：
- **主气，司呼吸**：呼吸功能，一身之气的生成与运行
- **主宣发肃降**：宣发卫气于体表，肃降水液于下焦
- **通调水道**：调节水液代谢
- **朝百脉，主治节**：辅助心脏推动血液运行
- **开窍于鼻**：鼻的通气和嗅觉
- **其华在毛**：皮毛的润泽反映肺气盛衰

**五维对应**：
| 维度 | 肺系统关联 |
|------|-----------|
| **炁** | 肺气充足 → 呼吸深沉，声音洪亮 |
| **毒** | 痰毒壅肺 → 咳嗽、哮喘、胸闷 |
| **脉** | 肺经堵痹 → 咳嗽、气喘、肩背痛 |
| **邪** | 风寒袭肺 → 感冒、咳嗽、流涕 |
| **瘾** | 悲伤伤肺 → 易哭、气短、乏力 |

**时辰位移**：
- **寅时03-05点**（肺经当令，位移后**巳时09-11点**）：
  - 此时应深度睡眠（宣发肃降）
  - 若此时易醒、咳嗽，说明肺有邪毒

**失常表现**：
- 肺气虚：气短、声低、易感冒、自汗
- 肺阴虚：干咳、少痰、盗汗、咽干
- 痰热壅肺：咳嗽、黄痰、胸闷、发热
- 风寒束肺：恶寒、发热、无汗、咳喘

**恢复标准（年轻/本来健康态）**：
- 呼吸深沉绵长，不气短（主气）
- 声音洪亮有力（肺气足）
- 皮毛润泽，不干燥（其华在毛）
- 嗅觉灵敏，鼻通气（开窍于鼻）
- 不易感冒，卫外固（宣发正常）

---

### 5. 肾（作强之官）

**炁脉功能定位**：
- **藏精，主生长发育与生殖**：先天之本，生命原动力
- **主水**：调节水液代谢
- **主纳气**：摄纳肺气，助呼吸深沉
- **主骨生髓**：骨骼、脑髓、脊髓的生成
- **开窍于耳及二阴**：听力、大小便功能
- **其华在发**：头发的润泽与脱落反映肾精盛衰

**五维对应**：
| 维度 | 肾系统关联 |
|------|-----------|
| **炁** | 肾精充足 → 精力充沛，生殖正常 |
| **毒** | 湿毒伤肾 → 水肿、尿频、腰膝酸软 |
| **脉** | 肾经堵痹 → 腰痛、膝软、足跟痛 |
| **邪** | 寒邪伤肾 → 畏寒、肢冷、阳痿 |
| **瘾** | 纵欲伤肾 → 肾精枯竭，早衰（如王威南31岁如60岁） |

**时辰位移**：
- **酉时17-19点**（肾经当令，位移后**子时23-01点**）：
  - **23点前必须入睡**，养护肾精
  - 此时深睡，脑髓得养（主骨生髓通于脑）

**失常表现**：
- 肾精不足：发育迟缓、不孕不育、早衰、健忘
- 肾气虚：腰膝酸软、尿频、遗精、白带清稀
- 肾阴虚：潮热、盗汗、耳鸣、口干、失眠
- 肾阳虚：畏寒肢冷、阳痿、水肿、五更泄泻

**恢复标准（年轻/本来健康态）**：
- **晨勃正常**（男性）/月经正常（女性）——**这是核心指标**
- 精力充沛，不疲劳（藏精足）
- 骨骼强健，腰不酸膝不痛（主骨）
- 听力正常，不耳鸣（开窍于耳）
- 头发乌黑浓密，不早白脱落（其华在发）
- 记忆力好，思维敏捷（生髓通脑）

## 二、六腑功能体系（传化物而不藏）

### 1. 胆（中正之官）

**炁脉功能定位**：
- **贮藏和排泄胆汁**：助消化
- **主决断**：勇怯、决断力与精神胆气
- **与肝相表里**：肝的疏泄功能正常，胆汁才能正常排泄

**失常表现**：
- 胆气虚：胆怯、易惊、失眠、决断力差
- 胆火上炎：口苦、咽干、目眩、易怒
- 胆石/胆淤：右胁痛、黄疸、消化不良

**恢复标准**：
- 决断果断，不犹豫不决（主决断）
- 口苦消失，消化正常（胆汁排泄正常）

---

### 2. 胃（仓廪之官）

**炁脉功能定位**：
- **受纳腐熟水谷**：接受和初步消化食物
- **主降浊**：将食糜下传小肠
- **与脾相表里**：胃降则脾升，升降协调

**失常表现**：
- 胃气虚：食欲不振、胃脘隐痛、嗳气
- 胃阴虚：口干、胃脘灼痛、便秘
- 食滞胃脘：脘腹胀满、嗳腐吞酸、呕吐
- 胃火上炎：口臭、牙龈肿痛、便秘

**恢复标准**：
- 食欲正常，食后有满足感（受纳正常）
- 胃脘舒适，无胀痛（腐熟正常）
- 胃气下降，不嗳气、不反流（降浊正常）

---

### 3. 小肠（受盛之官）

**炁脉功能定位**：
- **受盛化物**：接受胃下传的食糜，进一步消化
- **泌别清浊**：分清别浊，清者输布，浊者下传
- **与心相表里**：心火下移小肠，小肠热盛上熏于心

**失常表现**：
- 小肠虚寒：腹痛、腹泻、消化不良
- 小肠实热：心烦、口舌生疮、小便短赤
- 清浊不分：腹泻、营养不吸收

**恢复标准**：
- 消化吸收好，大便成形（泌别清浊正常）
- 小便清长，不短赤（与心相表里协调）

---

### 4. 大肠（传导之官）

**炁脉功能定位**：
- **传化糟粕**：传导食物残渣，形成粪便
- **主津**：吸收水分，使粪便成形
- **与肺相表里**：肺气肃降，推动大肠传导

**失常表现**：
- 大肠湿热：腹痛、腹泻、里急后重、痢疾
- 大肠液亏：便秘、口干、皮肤干
- 大肠虚寒：久泻、五更泄、腹部冷痛
- 肺气不降：便秘（肺与大肠相表里失调）

**恢复标准**：
- 大便每日1-2次，成形不干燥（传导正常）
- 排便通畅，不费力（主津正常）
- **卯时05-07点**（大肠经当令，位移后**午时11-13点**）排便最佳

---

### 5. 膀胱（州都之官）

**炁脉功能定位**：
- **贮存尿液**：暂时贮存代谢产生的尿液
- **排泄尿液**：通过气化作用排出尿液
- **与肾相表里**：肾的气化功能主宰膀胱开合

**失常表现**：
- 膀胱湿热：尿频、尿急、尿痛、尿黄
- 膀胱虚寒：尿频、遗尿、夜尿多、尿清长
- 肾气虚：遗尿、尿失禁（膀胱失约）

**恢复标准**：
- 排尿通畅，不频不急（气化正常）
- 夜尿0-1次（肾与膀胱相表里协调）
- 尿液清亮，不黄不浊

**时辰位移**：
- **申时15-17点**（膀胱经当令，位移后**亥时21-23点**）：
  - 此时应准备入睡，膀胱经排毒
  - 若此时不睡，毒素无法排出

---

### 6. 三焦（决渎之官，孤腑）

**炁脉功能定位**：
- **通行诸气**：总司全身气机升降出入
- **运行水液**：水液代谢的通道
- **部位三焦**：上焦（心肺）、中焦（脾胃）、下焦（肝肾膀胱）

**三焦功能分区**：
| 部位 | 功能 | 失常表现 |
|------|------|---------|
| **上焦**（心肺） | 宣发卫气，布散精微 | 胸闷、气短、咳嗽、表虚易感冒 |
| **中焦**（脾胃） | 腐熟运化，升降清浊 | 腹胀、消化不良、升降失调 |
| **下焦**（肝肾膀胱） | 排泄糟粕，藏精生殖 | 便秘、遗尿、生殖系统问题 |

**失常表现**：
- 三焦气化不利：水肿、痰饮、气机不畅
- 上焦热：心烦、口舌生疮、失眠
- 中焦湿困：腹胀、纳呆、身重
- 下焦寒：腰膝冷痛、阳痿、宫寒

**恢复标准**：
- 气机通畅，无胸闷腹胀（通行诸气）
- 水液代谢正常，无水肿（运行水液）
- 上中下焦各司其职，协调统一

**时辰位移**：
- **亥时21-23点**（三焦经当令，位移后**寅时03-05点**）：
  - 此时应深度睡眠，三焦通行元炁
  - 此时不睡，全身气机紊乱

## 三、五脏六腑的炁机联动

### 核心规律：**相生相克，互为表里**

**相生链（母病及子）**：
```
肾（水）→ 肝（木）→ 心（火）→ 脾（土）→ 肺（金）→ 肾（水）
精血    →  疏泄   →  神明   →  运化   →  呼吸   →  纳气归元
```

**相克链（制约平衡）**：
```
肝（木）克 脾（土）
脾（土）克 肾（水）
肾（水）克 心（火）
心（火）克 肺（金）
肺（金）克 肝（木）
```

**表里关系（阴阳配对）**：
| 脏（阴） | 腑（阳） | 表里关系 |
|---------|---------|---------|
| 心 | 小肠 | 心火下移小肠，小肠热盛上熏心 |
| 肝 | 胆 | 肝疏泄正常，胆汁排泄通畅 |
| 脾 | 胃 | 脾升胃降，升降协调 |
| 肺 | 大肠 | 肺气肃降，推动大肠传导 |
| 肾 | 膀胱 | 肾气化，主宰膀胱开合 |
| 心包 | 三焦 | 保护心神，通行诸气 |

## 五、给西方的说明（范式差异）

**西方看脏腑**：解剖结构、生化指标、影像学
**炁脉看脏腑**：炁机功能、动态变化、整体联动

**关键差异**：
> 西方：肝功能 = ALT、AST指标正常
> 炁脉：肝功能 = 情志舒畅（疏泄）、睡眠深沉（藏血）、目不干涩（开窍于目）、指甲饱满（其华在爪）、筋脉柔和（主筋）

**王威南案例的脏腑视角**：
- **肾精枯竭**（炁7级）：晨勃消失，遗精频繁，早衰
- **肝血不足**（脉6级）：肌肉抽搐，左臂细，指甲横纹，目涩
- **脾虚湿困**（毒6级）：无食欲，腹胀，便黏
- **心神失养**（瘾7级）：焦虑，失眠，反应迟钝
- **肺气虚**（邪4级）：怕冷，易感冒

**恢复标志（年轻健康态）**：
- **肾**：晨勃恢复（核心指标）
- **肝**：肌肉抽动消失，指甲恢复
- **脾**：食欲恢复，腹胀消失
- **心**：焦虑减轻，睡眠改善
- **肺**：怕冷减轻，不易感冒

## 六、核心金句

1. **"脏腑不是解剖器官，是炁机运行的功能集群。"**

2. **"看功能，不看形；看炁机，不看指标。"**

3. **"晨勃恢复是肾功能恢复的核心指标——这在西方标准里不存在，但在炁脉标准里是铁证。"**

4. **"五脏藏精炁，六腑传化物——藏泻结合，炁机才能归元。"**
