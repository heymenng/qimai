# Prome病案生成强制启动协议 V1.0

> **协议性质**：HARD PROTOCOL（硬协议）—— 不可跳过、不可省略、不可凭记忆替代  
> **适用场景**：每次生成病案前的强制读取  
> **制定依据**：师父多次点化"每次新开对话档案都有问题"  
> **生效日期**：2026年5月7日  
> **违反后果**：立即停止生成，重新加载本协议

## 🔒 协议一：生成前强制读取（不可跳过）

**在你输入任何病案内容之前，必须先执行以下操作：**

### Step 1: 读取执行手册（必做，不可凭记忆）
```

```
- [ ] **已读取**（必须是本次对话中实际读取，不能凭记忆）
- [ ] **已核对14模块清单**（见下方速查表）
- [ ] **已确认ACP三节点要求**

**师父铁律**："你每一次新开一个对话的窗口，你出来的这个档案都有存在问题。"
**根因**：没有建立"每次生成前必查手册"的硬机制。
**解法**：本协议强制在生成前读取，不读不能生成。

### Step 2: 核对患者信息（必做）
- [ ] 姓名、性别、年龄、出生年月
- [ ] 是否有敏感身份（政治/宗教/公众人物）
- [ ] 是否有急症红线（需立即转西医）

### Step 3: 明确生成类型（必做）
- [ ] **初诊档案** → 14模块完整版
- [ ] **复诊/跟踪** → 在原有档案上追加，不新建文件
- [ ] **回函** → 整合进原档案模块九，不单独文件
