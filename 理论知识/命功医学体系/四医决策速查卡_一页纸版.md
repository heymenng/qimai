# 四医决策速查卡（一页纸版）

> **打印尺寸**：A4横向或A3纵向
> **使用场景**：临床快速决策、贴在办公桌前、随身携带
> **目标**：30秒内完成四医综合决策

---

## 第一层：急症排雷（5秒）

```
🚨 立即转诊（不犹豫）
├── 胸痛 + 大汗 + 放射痛 → STEMI
├── 突发头痛"雷击样" → 蛛网膜下腔出血
├── FAST症状（面歪/臂无力/言语不清）→ 卒中
├── 血压≥180/120 + 靶器官损害 → 高血压急症
├── 大咯血/呕血/黑便 → 大出血
├── 意识障碍 + 高热 → 脓毒症
└── 板状腹 + 反跳痛 → 腹膜炎

✅ 非急症 → 进入第二层
```

## 第二层：病种定位（10秒）

| 症状/主诉 | 西医查什么 | 中医用什么 | 关键红线 |
|-----------|-----------|-----------|----------|
| **甲状腺结节** | ATA→TI-RADS→FNA标准 | 朱良春 双结同治方 | >1cm+高危→穿刺 |
| **糖尿病** | AACE→HbA1c目标→药物 | 邓铁涛 糖尿病方 | >10%+酮症→转诊 |
| **高血压** | ACC/AHA→分级→目标 | 邓铁涛 石决/赭决汤 | ≥180/120→急症 |
| **冠心病** | ACC/AHA→STEMI/NSTEMI | 邓铁涛 温胆汤 | STEMI→90分钟开通 |
| **肺癌** | NCCN→分期→基因检测 | 朱良春 扶正消癥汤 | 大咯血→立即介入 |
| **中风先兆** | AHA→ABCD2→MRI | 张学文 清脑通络汤 | FAST→4.5小时溶栓 |
| **类风湿** | ACR→RF/抗CCP→关节 | 朱良春 益肾蠲痹丸 | 关节破坏→生物制剂 |
| **痛风** | ACR→尿酸目标→药物 | 路志正 慢性痛风方 | 尿酸>540+肾损→转诊 |
| **湿困脾土** | 幽门螺杆菌→胃镜 | 路志正 调理脾胃方 | 重度异型增生→转诊 |
| **脑积水** | CT/MRI→脑室扩大 | 张学文 脑窍通汤 | 意识障碍→立即引流 |

## 第三层：五维快速定级（10秒）

```
炁维（能不能动）      毒维（排出好不好）     脉维（痛不痛僵不僵）
10 卧床不起           10 严重便秘/溃烂       10 剧痛/完全僵直
 8 极度乏力            8 长期便秘/三高        8 明显疼痛/受限
 6 容易疲劳            6 偶发便秘/轻微三高    6 酸胀不适
 4 偶感疲劳            4 基本正常             4 偶感不适
 2 精力充沛            2 排毒顺畅             2 完全通畅

邪维（指标异常）       瘾维（习惯好不好）
10 多器官衰竭/肿瘤晚期  10 严重成瘾/抑郁
 8 严重指标异常         8 明显情绪问题/熬夜
 6 中度异常（三高）      6 偶发情绪波动/晚睡
 4 轻度异常             4 基本规律
 2 完全正常             2 生活规律心态平和
```

**快速口诀**：
- 能爬楼梯？炁<6 | 说话气短？炁≥7
- 每日排便？毒<5 | 长期便秘？毒≥8
- 肩颈僵硬？脉≥6 | 无法转头？脉≥9
- 指标正常？邪<4 | 肿瘤标志物高？邪≥8
- 23点前睡？瘾<5 | 明显焦虑？瘾≥8

## 第四层：54牌速选（5秒）

```
【选牌规则】

Step 1: 找最严重的2个维度
Step 2: 对应花色
  炁低 → ♥红桃（补）     毒高 → ♠黑桃（排）
  脉堵 → ♦方块（通）     瘾重 → ♣梅花（心）
Step 3: 对应等级
  9-10级 → K    7-8级 → Q    5-6级 → J    3-4级 → 10
Step 4: 检查平衡
  攻伐牌（♠♦）≤ 补益牌（♥）+ 1
  瘾维≥6级 → 必须有♣牌

【常见组合】
肿瘤：♠K + ♦Q + ♥K + ♣J
糖尿：♥Q + ♠Q + ♣J
高血压：♦K + ♠Q + ♣J
湿困：♠Q + ♥J + ♣J
中风先兆：♦K + ♠Q + ♥Q + ♣J
```

## 第五层：大师方速查

```
【朱良春】虫类药·疑难病·大剂量
├── 肿瘤/结节 → 扶正消癥汤 / 双结同治方
├── 类风湿 → 益肾蠲痹丸（丸剂，3-6个月）
├── 肝病 → 复肝丸
└── 痴呆 → 健脑散

【邓铁涛】五脏相关·调脾护心·重用黄芪
├── 冠心病 → 邓氏温胆汤
├── 重症肌无力 → 强肌健力方（黄芪60-120g）
├── 糖尿病 → 糖尿病方（山药90g+黄芪30g）
├── 高血压肝阳上亢 → 石决牡蛎汤
└── 高血压气虚痰浊 → 赭决九味汤

【路志正】湿病泰斗·调理脾胃·芳香化湿
├── 湿困脾土 → 调理脾胃基础方（藿香+佩兰+苍术）
├── 湿热蕴结 → 三仁汤加减（杏仁+白蔻仁+薏苡仁）
├── 慢性痛风 → 慢性痛风方（黄芪+苍术+黄柏）
└── 湿秘 → 湿秘方（生白术20g+茯苓）

【张学文】脑病圣手·活血化瘀·通脑活络
├── 中风先兆 → 清脑通络汤（草决明+川芎+水蛭）
├── 颅脑水瘀 → 通窍活血利水方（麝香+桃仁+红花）
├── 脑梗恢复 → 通脉舒络汤（黄芪+丹参+水蛭）
└── 脑积水 → 脑窍通汤（麝香0.1g+石菖蒲）
```

## 第七层：综合检查清单（30秒完成）

```
□ 西医部分
  □ 是否急症？→ 是→立即转诊
  □ 查哪个指南？→ ATA/AACE/ACC/NCCN
  □ 转诊红线？→ 列出
  □ 监测指标？→ 列出随访清单

□ 中医部分
  □ 哪位大师？→ 朱/邓/路/张
  □ 核心方？→ 方名
  □ 关键药对？→ 2-3个
  □ 疗程？→ 急性1-2周/慢性3-6月

□ 功能医学（如需）
  □ DUTCH？→ 激素代谢
  □ OAT？→ 有机酸
  □ 检测→五维映射？→ 确认

□ 炁脉部分
  □ 五维定级？→ 炁_/毒_/脉_/邪_/瘾_
  □ 54牌？→ ♥_+♠_+♦_+♣_
  □ 十八变预测？→ 第X次排异
  □ 瘾维补充？→ 正念/情绪/行为

□ 整合检查
  □ 毒-补平衡？→ 攻伐≤补益+1
  □ 转诊无遗漏？
  □ 患者可执行？
  □ 随访计划明确？
```

## 第八层：避坑口诀

```
不深入研究西医分子机制 → 只查指南诊断标准和红线
不陷入中医辨证迷宫 → 只取大师核心方和关键药对
不忘转诊红线 → 急症必须先排除
不做精细五维计算 → 快速分级定牌阶
不出过多牌 → 最多4张，攻伐≤补益+1
不忽视瘾维 → 慢性病必须评估心理状态
```
