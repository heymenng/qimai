## 一、映射原则

```
54牌策略（方向） → 中药功效（能力） → 具体方剂（工具）

♥ 红桃（补/培元固本） → 补气/补血/补阴/补阳 → 四君子/四物/六味/金匮
♠ 黑桃（排/清府排毒） → 祛湿/化痰/清热/泻下 → 二陈/三仁/黄连解毒/承气
♦ 方块（通/疏通脉道） → 活血/行气/通络/开窍 → 血府逐瘀/柴胡疏肝/桂枝茯苓

```

**关键区别**：
- ❌ 旧路径：辨证（脾虚）→ 立法（健脾）→ 选方（四君子）
- ✅ 新路径：五维（炁低）→ 策略（♥补）→ 匹配功效（补气）→ 选方（四君子）

## 七、使用规则

### 7.1 选方优先级

```
Step 1: 确定策略（♥/♠/♦/♣ + 级别）
Step 2: 在对应策略表中筛选
Step 3: 按五维特征匹配最适方剂
Step 4: 考虑患者具体情况调整
Step 5: 记录实际使用，入验证日志
```

### 7.2 注意事项

1. **级别对应**：
   - 维级5-6 → 常规方剂（3-6级牌）
   - 维级7-8 → 加强方剂（7-8级牌）
   - 维级9-10 → 急救/重症方剂（J-Q-K级牌）

2. **复合病症**：
   - 多维度同时高 → 多策略联用
   - 注意方剂间的配伍禁忌
   - 参考`09-西医诊断参考手册`药物协同/禁忌

3. **急症红线**：
   - 任何维级≥8 + 急症症状 → 先西医处理，炁脉辅助
   - 不可单用中药处理急腹症、大出血、心梗等

4. **疗效验证**：
   - 每个处方使用后必须记录
   - 入`verification_log.md`
   - 用于模型优化
