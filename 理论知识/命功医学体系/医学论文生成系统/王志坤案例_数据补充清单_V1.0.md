## 二、P0·必须补充项（没有这些，论文无法投稿）

### 2.1 生殖激素六项时间序列

**什么是这个**：FSH、LH、E2、PRL、P、T 在调理前、调理中、调理后的数值变化

**为什么必须**：
- FSH 37.91→4.73 是论文核心亮点
- SCI期刊要求展示**时间曲线**，不是只有两个点
- 需要证明FSH下降是"逐步的、持续的"，不是偶然波动

**需要调取的具体报告**：

| 时间点 | 需要报告 | 来源推测 |
|--------|---------|---------|
| **2014年4月·初诊前** | 激素六项报告（试管医院） | 广东省某生殖中心/试管医院 |
| **2014年6月·调理2个月** | 复查激素六项 | 王志坤自行检测？/炁脉调理点？ |
| **2014年10月·调理6个月** | 复查激素六项 | 同上 |
| **2015年中·调理1年** | 复查激素六项 | 同上 |
| **2016年初·调理2年** | 复查激素六项 | 同上 |
| **2018年·孕后** | 孕早期激素检测 | 产科医院 |

**关键数据点**（请重点寻找）：
- [ ] FSH 初诊值（确认是否为37.91 IU/L）
- [ ] FSH 30天/60天/90天值（证明下降趋势）
- [ ] LH 对应时间点数值（LH/FSH比值变化）
- [ ] E2 对应时间点数值（雌激素恢复证据）
- [ ] AMH 初诊值（卵巢储备功能基线）
- [ ] AMH 调理后值（如检测过）
- [ ] PRL（泌乳素）初诊及复查值

**如果找不到纸质报告，可请患者**：
1. 联系当年做试管的医院，申请**病历复印**（根据《医疗纠纷预防和处理条例》，患者有权复印病历）
2. 联系当年调理期间做检测的体检中心/医院，调取报告
3. 如果均无，可请患者在当前医院**重新检测**激素六项作为末次数据

### 2.2 卵巢超声/B超报告

**什么是这个**：经阴道超声或腹部超声，显示卵巢大小、卵泡数量、子宫内膜厚度

**为什么必须**：
- SCI期刊要求**影像学证据**证明卵巢功能恢复
- AFC（窦卵泡计数）是卵巢储备的金标准
- 可直观展示"卵巢从萎缩到恢复"的过程

**需要调取的具体报告**：

| 时间点 | 需要报告 | 重点指标 |
|--------|---------|---------|
| **2014年4月·初诊前** | 卵巢B超（试管医院必做） | AFC、卵巢体积、子宫内膜厚度 |
| **2015年中·调理中期** | 复查B超 | AFC变化、卵泡发育 |
| **2016-2017年·调理后期** | 监测排卵B超 | 优势卵泡、排卵证据 |
| **2018年·孕早期** | 早孕B超 | 孕囊、胎心（证明活胎） |

**关键数据点**：
- [ ] 初诊 AFC（窦卵泡计数）
- [ ] 初诊卵巢体积（mm³）
- [ ] 初诊子宫内膜厚度（mm）
- [ ] 调理后AFC变化
- [ ] 是否有优势卵泡发育记录
- [ ] 排卵监测记录（如有）

**获取建议**：
- 试管医院必做B超，病历中应该有
- 如果缺失，可在当前医院补做一次作为现状对照

## 三、P1·重要补充项（有这些，论文质量显著提升）

### 3.1 既往8次试管的完整病历

**为什么重要**：
- 证明"8次试管失败"的真实性
- 展示试管用药方案（哪些药物、剂量、周期）
- 排除其他不孕因素（输卵管、男方因素等）

**需要调取的资料**：

| 资料类型 | 内容 | 来源 |
|---------|------|------|
| 试管病历首页 | 诊断、方案、用药 | 生殖中心病历科 |
| 促排卵记录 | 用药方案（长方案/短方案/拮抗剂） | 同上 |
| 取卵记录 | 获卵数、受精数、胚胎质量 | 同上 |
| 移植记录 | 移植胚胎数、胚胎等级 | 同上 |
| 失败原因记录 | 医生分析（受精失败？着床失败？） | 同上 |
| 男方精液报告 | 排除男方因素 | 同上 |
| 输卵管造影 | 排除输卵管因素 | 同上 |

**获取建议**：
- 联系当年做试管的医院（广东省某生殖中心）
- 患者本人持身份证申请病历复印
- 可能需要支付复印费（约0.5-1元/页）
- 试管病历通常很厚（50-100页），**重点复印首页、诊断页、用药方案页**

## 九、特别提醒

### 9.1 关于FSH 37.91→4.73的证据等级

- 如果只有**两个时间点**的FSH数据（37.91和4.73），论文只能写"FSH显著下降"
- 如果有**三个以上时间点**的数据，可以写"FSH呈持续下降趋势"，证据更强
- 如果有**每月一次**的连续数据，可以绘制FSH变化曲线图，冲击力最大

**建议**：即使找不到所有中间数据，也尽量找2-3个中间时间点的报告

### 9.2 关于"8次试管失败"的证明

- 期刊可能会质疑"8次"这个数字，需要病历支持
- 如果找不到全部8次记录，至少找到**最近2-3次**的移植记录
- 如果完全找不到，论文中可写"多次试管失败（患者自述8次）"，但证据等级下降

### 9.3 关于伦理的底线

- **绝不可以**：在未经同意的情况下发表论文
- **绝不可以**：在论文中透露患者真实身份
- **绝不可以**：夸大疗效或隐瞒不良事件
- **必须**：在论文中声明"患者已签署知情同意"
