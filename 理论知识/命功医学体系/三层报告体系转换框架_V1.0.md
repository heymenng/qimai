# 三层报告体系转换框架 V1.0

> **定位**：明确区分"深度医疗/档案/居家自助"三层输出，建立转换规则
> **用途**：AI生成报告时的分层指南，防止内容混淆
> **核心原则**：同样的诊断，三层说不同的话
> **版本**：V1.0
> **更新**：2026年5月7日

---

## 一、三层体系总览

```
【三层金字塔】

        ┌─────────────┐
        │  第一层     │  ← 深度医疗报告
        │  调理师用   │     （深度专业，四医吃透+蒙藏维等）
        └──────┬──────┘
               │ 转换：提取关键信息，翻译为患者语言

        ┌─────────────┐
        │  第二层     │  ← 档案报告（V4.3标准版）
        │  患者完整版  │     （保持现有标准版，不变）
        └──────┬──────┘
               │ 转换：提取档案中居家可执行部分，补充详细解释
               ▼
        ┌─────────────┐
        │  第三层     │  ← 居家自助手册（V1.2风格）
        │  患者自助版  │     （在家用，有解释有方法有原理）

### 1.1 三层对比

| 维度 | 第一层：深度医疗 | 第二层：档案报告 | 第三层：居家自助 |
|------|-----------------|-----------------|----------------|
| **给谁看** | 调理师/医生/AI自己 | 患者（完整版） | 患者（在家自助用） |
| **用途** | 临床决策参考 | 了解全貌，建立信任 | 在家日常自助调理 |
| **语言** | 专业术语+数据 | 半专业+解释 | 通俗+解释+指令 |
| **长度** | 无限制，越全越好 | 3000-8000字 | 2000-5000字 |
| **格式** | 结构化数据+分析 | 14模块完整病案 | 章节式自助手册 |
| **包含什么** | 四医分析+处方逻辑+假设验证 | 诊断+方案+回函+疗效（14模块标准版） | 在家能做的方法+原理+步骤+打卡 |
| **不包含什么** | 无 | 不给调理师的操作细节 | 不给需要调理师操作的内容 |
| **生成时机** | **仅在明确要求时生成** | **默认生成，标准输出** | **仅在明确要求时生成** |

### 1.2 默认输出规则（重要）

```
【铁律】正常情况只出第二层（档案报告）

用户说"出档案""生成报告""写病案" → 默认生成第二层（档案报告V4.3）

用户说"出深度医疗报告""给调理师看""专业版" → 生成第一层（深度医疗）

用户说"出自助报告""居家版""贴冰箱" → 生成第三层（居家自助手册）

错误示例：
  用户："给我出一份档案"
  ❌ 错误：生成第一层（深度医疗）→ 太专业，患者看不懂
  ✅ 正确：生成第二层（档案报告V4.3）→ 患者能看懂

错误示例：
  用户："帮我写一份居家调理方案"
  ❌ 错误：生成第二层（档案报告）→ 太厚，不聚焦
  ✅ 正确：生成第三层（居家自助手册）→ 薄，聚焦可执行
```

## 二、第一层：深度医疗报告

### 2.1 定位

```
【读者】调理师、医生、AI决策引擎
【目的】提供深度专业的四医分析，帮助调理师做决策
【特点】
  - 深度专业：四医都必须吃透，展现专业深度
  - 西医：指南引用、诊断标准、转诊红线、最新进展
  - 中医：方剂加减逻辑、药理学机制、古籍出处
  - 炁脉：五维定级推理、54牌组合逻辑、十八变预测
  - 功能医学：检测解读、根源分析、营养干预
  - 扩展性：未来纳入蒙医、藏医、维医等民族医学
  - 包含假设和不确定性
```

### 2.2 内容结构

```markdown
# 深度医疗报告：患者XXX

## 一、西医分析（给调理师看）
- 指南依据：ATA/AACE/ACC/NCCN 第X章
- 诊断标准：符合/不符合
- 转诊红线：有/无，具体是什么
- 关键指标：XXX（正常值：X，患者值：X）
- 西医治疗阶段：观察/药物/手术/放化疗
- 与炁脉的衔接点：西医观察期→炁脉介入最佳

## 二、中医分析（给调理师看）
- 大师选择：朱良春/邓铁涛/路志正/张学文
- 核心方：XXX
- 选方逻辑：为什么选这个方？（3个理由）
- 关键药对：XXX+XXX（协同模式：XXX）
- 加减计划：气虚加黄芪，血瘀加丹参...
- 剂量依据：脉级X级→取剂量上限/中值/下限
- 疗程预测：急性X周/慢性X月

## 三、功能医学分析（给调理师看）
- 建议检测：DUTCH/OAT/肠道菌群
- 检测目的：验证五维定级中的XXX
- 预期结果：如果XXX高→说明毒维 underestimated
- 检测→五维映射：XXX指标→对应XXX维

## 四、炁脉分析（给调理师看）
- 五维定级推理：
  炁X级：依据是XXX（症状/体征/指标）
  毒X级：依据是XXX
  ...
- 54牌组合逻辑：
  为什么选♥K而不是♥Q？
  攻伐/补益平衡如何计算？
- 十八变预测：
  第X次可能出现XXX反应
  如何判断是排异还是恶化？
- 疗程预测：基于XXX案例，预计X次见效

## 五、综合决策（给调理师看）
- 优先级排序：1.XXX 2.XXX 3.XXX
- 风险点：XXX（如高龄用药安全）
- 假设清单：假设XXX，如验证失败则调整XXX
- 随访计划：第X次复查XXX指标

## 六、调理师执行清单
- [ ] 查XXX指南确认诊断
- [ ] 确认无转诊红线
- [ ] 向患者解释五维定级
- [ ] 执行54牌方案（具体穴位/手法）
- [ ] 记录十八变反应
- [ ] 下次调理前复查XXX
```

### 2.3 示例片段

```markdown
【西医分析】
患者甲状腺结节，查ATA 2015指南：
- 超声TI-RADS：3类（低度可疑）
- 结节大小：1.2cm
- 关键红线：>1cm且低度可疑→建议FNA（细针穿刺）
- 但患者拒绝穿刺→进入观察期
- 观察期是炁脉介入最佳时机
- 需每3-6个月复查超声
- 如升至4类→必须建议穿刺

【中医分析】
选朱良春双结同治方：
- 理由1：甲状腺结节=朱良春专长
- 理由2：患者肝郁症状（口苦、易怒）→方中含柴胡/郁金/香附
- 理由3：结节属"痰瘀互结"→方中含夏枯草/玄参/牡蛎
- 关键药对：夏枯草18g+玄参12g+牡蛎30g（软坚散结三剑客）
- 加减：乏力加黄芪20g（脉级判断：炁6级→需补气）
- 去虫类药：患者无肿瘤，无需蜂房/守宫
- 疗程：3个月（结节软化需要时间）

【五维定级推理】
炁6级：依据→乏力（自述）、脉细（触诊）、高龄70+
  不是7级→因为还能爬楼梯，未卧床
  不是5级→因为明显比平时疲劳
毒5级：依据→结节存在（痰瘀互结）
  不是6级→无疼痛、无 Rapid growth
  不是4级→结节确实存在，非生理性
脉7级：依据→颈部僵硬、胆经压痛
  肝经循行甲状腺→肝郁气滞→脉道不畅
邪5级：依据→口苦（肝火）、苔薄黄
瘾6级：依据→易怒、失眠、工作压力大
  必须加♣牌→正念减压+作息调整
```

## 三、第二层：档案报告（V4.3标准）

### 3.1 定位

```
【读者】患者（完整版，可打印收藏）
【目的】让患者了解全貌，建立对调理师的信任
【特点】
  - 包含诊断过程，但不说太专业的推理
  - 包含治疗方案，但不说为什么选这个药（只说功效）
  - 包含回函，解答患者疑问
  - 可打印，A4纸装订
```

### 3.2 内容结构（14模块）

```markdown
# 患者档案：XXX

## 模块零：AI健康顾问自我介绍
（让患者知道这是什么）

## 模块一：五维诊断速查表
（给患者看的简化版）
- 五角雷达图（可视化）
- 各级别说明（用患者能懂的语言）
  例：炁6级="容易疲劳，需要多休息"
      毒5级="体内有湿气毒素，需要排毒"

## 模块二：四医合诊诊断
（给患者看的简化版）
- 西医怎么说（用通俗语言解释）
- 中医怎么说（用症状解释，不说"肝郁脾虚"）
- 炁脉怎么说（五维定位）
- **不说**：指南引用、方剂加减逻辑、药理学机制

## 模块三：时辰位移与作息调整
（给患者看的执行版）
- 您应该几点睡
- 为什么这个时辰重要（简单说）
- 具体调整步骤

## 模块四：中医辨证（简化版）
- 您的问题主要在XX方面
- 需要用XX方法调理
- **不说**：具体方剂组成、克数、煎煮法

## 模块五：54牌治疗方案
（给患者看的概念版）
- 您需要"补气+排毒+通脉"（不说具体牌）
- 调理师会用XX方法
- 您会感觉到XX

## 模块六：五音疗法方案
- 推荐曲目
- 聆听时间
- **不说**：五行对应、音律理论

## 模块七：动态食疗方案
- 七日食谱
- 食材金字塔
- **不说**：食物归经、性味理论

## 模块八：患者执行手册（分层版）⭐重点
- 极简版/基础版/标准版/深度版
- 打卡表
- 习惯追踪
- **这是第三层内容的预告**

## 模块九：患者回函
- 回答患者具体问题
- 解释为什么这样治
- 鼓励的话

## 模块十：自检清单
- 症状改善曲线
- 对比时间轴

## 模块十一：疗效验证记录
- 量化指标追踪

## 模块十二：炁色诊察记录
- 调理师签名

## 模块十三：持续跟踪与再接入指南
- 有问题怎么联系
- 下次调理时间

## 模块十四：微习惯启动包
- 21天微习惯表
```

### 3.3 第一层→第二层的转换规则

```
【转换原则：专业→通俗，推理→结论】

西医部分：
  第一层："查ATA指南TI-RADS 3类，>1cm建议FNA"
  第二层："西医看，您的结节目前属于低度可疑，大小1.2厘米。一般超过1厘米建议穿刺检查，但您可以先选择观察和调理，3个月后复查。"

中医部分：
  第一层："选朱良春双结同治方，夏枯草18g+玄参12g+牡蛎30g"
  第二层："中医看，您的问题是肝气郁结加上痰瘀互结。我们会用软坚散结的方法，帮助结节慢慢软化。主要用夏枯草、玄参和牡蛎，这些都是软化结节的良药。"

五维部分：
  第一层："炁6级：依据乏力+脉细+高龄"
  第二层："您的能量水平是6级（中等偏弱），主要表现是容易疲劳。这是因为年纪大了，肾气自然减弱，加上长期劳累。"

54牌部分：
  第一层："♥K+♠J+♦Q+♣J，攻伐/补益=2/1"
  第二层："您的调理方案主要是三方面：第一，补充能量；第二，清除毒素；第三，疏通经络。同时我们会教您一些调节情绪的方法。"

十八变部分：
  第一层："第7-14天可能出现颈部酸胀（排异概率70%）"
  第二层："调理1-2周后，您可能会感觉脖子有点酸胀，这是好现象，说明体内的毒素在往外排。如果持续超过3天或加重，请告诉我们。"
```

### 3.4 【修复摩擦点1】第一层→第二层模块映射表

```
【映射规则：第一层每个部分 → 第二层哪个模块】

第一层·一、西医分析
  ├── 指南引用/诊断标准 → 【删除，不进入第二层】
  ├── 转诊红线 → 模块二·四医合诊（西医部分）+ 模块十三·持续跟踪
  ├── 关键指标 → 模块二·四医合诊（数据表格）
  ├── 西医治疗阶段 → 模块二·四医合诊（治疗矩阵）
  └── 与炁脉的衔接点 → 模块二·四医合诊（协同关系）

第一层·二、中医分析
  ├── 大师选择理由 → 【删除，保留结论即可】
  ├── 核心方 → 模块四·中医辨证（方名+功效）
  ├── 选方逻辑（3个理由）→ 【删除，转为通俗解释】
  ├── 关键药对 → 模块四·中医辨证（保留药名，去克数）
  ├── 加减计划 → 【删除，保留最终处方】
  ├── 剂量依据 → 【删除】
  └── 疗程预测 → 模块五·54牌方案（疗程说明）

第一层·三、功能医学分析
  ├── 建议检测 → 模块二·四医合诊（功能医学部分）
  ├── 检测目的 → 【删除，保留检测项目】
  ├── 预期结果 → 【删除】
  └── 检测→五维映射 → 【删除】

第一层·四、炁脉分析
  ├── 五维定级推理 → 模块一·五维诊断（简化文字，保留雷达图）
  ├── 54牌组合逻辑 → 【删除，转为通俗方向】
  ├── 十八变预测 → 模块十·自检清单（预期反应）
  └── 疗程预测 → 模块五·54牌方案（疗程说明）

第一层·五、综合决策
  ├── 优先级排序 → 模块二·四医合诊（治疗矩阵）
  ├── 风险点 → 模块十三·持续跟踪（注意事项）
  ├── 假设清单 → 【删除】
  └── 随访计划 → 模块十三·持续跟踪

第一层·六、调理师执行清单
  └── 【全部删除，仅用于调理师内部】

【第一层→第二层删除内容清单】
  ❌ 所有指南引用（ATA/AACE/ACC/NCCN第X章）
  ❌ 所有方剂克数（夏枯草18g→夏枯草）
  ❌ 所有推理过程（为什么选这个方）
  ❌ 所有假设和不确定性
  ❌ 所有剂量依据（脉级X级→取上限）
  ❌ 所有调理师操作细节

### 3.5 【修复摩擦点2】第二层→第三层提取规则

```
【提取原则：提取可执行的，删除需调理师的，补充解释的】

第二层·模块一：五维诊断速查表
  ├── 五维雷达图 → 【提取】→ 第三层"了解您的身体状态"（简化版）
  ├── 各级别说明 → 【提取】→ 第三层"您的体质特点"
  └── 详细评估表格 → 【删除】

第二层·模块二：四医合诊诊断
  ├── 西医部分（通俗版）→ 【提取】→ 第三层"现代医学怎么看"
  ├── 中医部分（通俗版）→ 【提取】→ 第三层"中医怎么看"
  ├── 功能医学部分 → 【提取】→ 第三层"根源分析"
  └── 炁脉部分 → 【提取】→ 第三层"您的调理方向"

第二层·模块三：时辰位移与作息调整
  ├── 作息调整方案 → 【提取】→ 第三层"作息管理"
  ├── 时辰原理 → 【提取】→ 第三层"为什么23点前睡"
  └── 24时辰圆环图 → 【删除】→ 转为文字说明

第二层·模块四：中医辨证
  ├── 证型说明 → 【提取】→ 第三层"您的问题在哪里"
  └── 具体方剂 → 【删除】→ 患者不需要知道处方

第二层·模块五：54牌治疗方案 ⭐关键
  ├── 需要调理师操作的：
  │   ├── 行罐 → 【删除】→ 第三层不出现
  │   ├── 药灸 → 【删除】→ 第三层不出现
  │   ├── 手法调理 → 【删除】→ 第三层不出现

```markdown
# 我的居家自助调理手册

## 第一章：为什么居家自助很重要？

**师父点化**：
> "调理师一周能帮你两次，但剩下的五天，是你自己在过。
> 这五天如果不自助，两次调理的效果会被日常生活抵消。"

**核心公式**：
总疗效 = 专业调理（20%）+ 居家自助（60%）+ 心态愿力（20%）

**为什么居家自助占60%？**
因为您每天吃饭、睡觉、活动，这些都在影响身体。
做对了，调理效果加倍；做错了，调理效果抵消。

## 第二章：通神露泡脚（居家排毒第一法）

### 2.1 为什么泡脚能排毒？

**科学原理**：
- 足部有60多个穴位，6条经络起止点
- 热水扩张血管，促进全身血液循环
- 中药成分经皮吸收，直达经络
- 出汗是身体排毒的重要通道

**师父点化**：
> "在这个毒的时代，人人身处毒中。不出汗，毒就积在体内。

按摩穴位 = 给高速公路疏通交通，让气血顺畅流动。

### 3.2 您的专属穴位（根据您的五维定级）

- 作用：疏肝理气，缓解情绪压力

- 按法：同上
- 感觉：酸胀感
- 时间：每晚泡脚后

- 23-1点是胆经当令
- 1-3点是肝经当令
- 这两个时辰是身体排毒修复的黄金时间

**现代医学解释**：
- 23点后褪黑素开始分泌
- 深度睡眠时细胞修复最快
- 熬夜会打乱内分泌，影响免疫力

### 4.2 做不到怎么办？

**渐进调整法**：
- 第一周：比原来早30分钟
- 第二周：再早30分钟
- 第三周：达到23点前

**替代方案**：

## 六、常见错误与纠正

### 6.1 第一层内容混入第二层

```
❌ 错误示例（档案报告中出现深度医疗内容）：
"根据ATA 2015指南第3章，甲状腺结节>1cm且TI-RADS 3类以上建议FNA。
患者超声示TI-RADS 3类，结节1.2cm，符合穿刺标准。但患者拒绝，
故进入观察期。观察期每3-6个月复查超声，如升至4类必须穿刺。"

✅ 正确示例：
"西医看，您的甲状腺结节目前属于低度可疑，大小1.2厘米。
这种情况一般建议做个穿刺检查更放心，但如果您暂时不想做，
可以先观察和调理，3个月后我们复查超声看看变化。"

问题：第一层内容直接复制到第二层，患者看不懂ATA、TI-RADS、FNA
纠正：翻译成患者能懂的语言，保留核心信息（大小、风险、建议）
```

### 6.2 第二层内容混入第三层

```
❌ 错误示例（居家自助中直接复制档案内容）：
"您的五维定级为炁6毒5脉7邪5瘾6，54牌方案为♥J+♠Q+♦Q+♣J。
根据朱良春双结同治方，夏枯草18克，玄参12克，牡蛎30克先煎..."

✅ 正确示例：
"为什么泡脚能排毒？
因为足部有60多个穴位，热水能促进血液循环，中药成分经皮吸收...

怎么泡？
1. 水温40-45℃
2. 时长20-30分钟
3. 水位没过脚踝
4. 感觉背部微汗即可

注意事项：
- 不要泡到大汗淋漓（伤津液）
- 泡脚时不要看手机"

问题：第二层内容太专业，不适合直接给居家自助
纠正：提取可执行内容，补充通俗解释和方法，去除专业术语
```

### 6.3 第三层内容混入第一层

```
❌ 错误示例（深度医疗报告中出现口语化内容）：
"患者要每天泡脚哦，水温不要太高，泡到微微出汗就好啦~
还有记得23点前睡觉，不要玩手机啦~"

✅ 正确示例：
"外治法：通神露泡脚，每日1次，睡前1小时，水温40-45℃，
时长20-30分钟，以背部微汗为度。作用：促进足部经络气血运行，
辅助排毒。禁忌：皮肤破损、下肢静脉血栓、严重心衰。"

问题：第一层用口语化语言，不专业

## 八、AI生成流程

```
【AI生成三层报告的流程】

Step 1: 生成第一层（深度医疗报告）
  输入：患者症状、体征、检测指标
  输出：完整的四医分析+处方逻辑+假设
  读者：调理师

Step 2: 第一层→第二层（自动转换）
  操作：
    - 删除所有指南引用
    - 删除方剂克数
    - 删除推理过程
    - 翻译为通俗语言
    - 添加回函
  输出：V4.3标准档案报告（14模块）
  读者：患者（完整版）

Step 3: 第二层→第三层（自动转换）
  操作：
    - 提取档案中模块三/五/六/七/八/十四的内容
    - 补充详细解释（为什么这样做）
    - 补充具体方法（怎么做，步骤详细）
    - 补充简单原理（通俗易懂的道理）
    - 保留打卡机制
    - 去除需要调理师操作的内容（如行罐、药灸）
    - 去除专业术语（五维/54牌/炁→用通俗说法替代）
  输出：居家自助手册（参考V1.2风格）
  读者：患者（在家自助用）

【质量控制】
  - 每层生成后，用对应检查清单验证
  - 确保三层内容一致但不重复
  - 确保没有跨层混淆
```
