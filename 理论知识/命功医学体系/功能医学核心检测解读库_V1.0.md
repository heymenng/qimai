## 一、DUTCH完整激素检测（Dried Urine Test for Comprehensive Hormones）

### 1.1 检测概述

```
【是什么】
干尿法全面激素检测，同时测量：
  - 性激素（雌激素/孕酮/睾酮）及其代谢物
  - 肾上腺激素（皮质醇/DHEA）及其代谢物
  - 昼夜皮质醇节律（4个时间点）
  - 有机酸标记（营养/氧化应激/神经炎症）
  - 褪黑素

【优势】
  ✅ 比血液检测更全面（测代谢物，不只是总量）
  ✅ 比唾液检测更稳定（干尿法不受唾液流量影响）
  ✅ 一次检测 = 激素生产+代谢+排泄全链条

【局限】
  ⚠️ 不直接测甲状腺（需单独检测）
  ⚠️ 不直接测胰岛素/血糖（需单独检测）
  ⚠️ 口服激素治疗会影响结果
```

### 1.2 雌激素代谢解读

#### 核心指标

| 指标 | 正常范围 | 临床意义 | **炁脉映射** |
|------|---------|---------|------------|
| **E1（雌酮）** | 女性：1.5-4.5 | 绝经前主要雌激素 | — |
| **E2（雌二醇）** | 女性：0.5-2.2 | 活性最强雌激素 | — |
| **E3（雌三醇）** | 女性：1.0-3.5 | 孕期主要雌激素 | — |

#### 代谢通路（最关键）

```
雌激素代谢三条路：

2-OH通路（保护性）
  → 2-OH-E1 / 2-OH-E2
  → 2-MeO-E1（甲基化后）
  ✅ 抗肿瘤、保护性
  目标占比：60-80%
  
4-OH通路（危险性）
  → 4-OH-E1 / 4-OH-E2
  → 可能形成醌类（DNA损伤）
  ⚠️ 基因毒性
  目标占比：<10%
  
16-OH通路（增殖性）
  → 16-OH-E1
  → 促进组织生长
  ⚠️ 乳腺/子宫增殖风险
  目标占比：10-30%
```

#### 关键比值

| 比值 | 理想值 | <理想值 | >理想值 | **炁脉定级** |
|------|--------|---------|---------|------------|
| **2-OH:16-OH** | ≥2.0 | <1.0（增殖风险↑） | >3.0（可能过度） | 邪维↑ |
| **2-OH:4-OH** | >2.0 | <1.5（解毒差） | — | 毒维↑ |
| **甲基化比值** | 高 | 低（解毒差） | — | 毒维↑ |

#### 临床场景

```
【乳腺结节患者】
如果 4-OH >10% + 2-OH:16-OH <1.0
  → 雌激素代谢偏向危险通路
  → 乳腺结节恶性风险增加
  → 炁脉方案：♣祛（支持肝脏解毒）+ ♠排（促进雌激素排泄）
  → 具体：十字花科蔬菜（萝卜硫素支持2-OH通路）+ 膳食纤维（促进排泄）

【甲状腺结节女性】
如果 E2高 + 孕酮低 = 功能性雌激素优势
  → 雌激素刺激甲状腺细胞增殖
  → 炁脉方案：♥补（支持孕酮）+ ♣祛（平衡雌激素）
  → 具体：圣洁莓（支持黄体功能）+ 蒲公英根（肝脏解毒）
```

### 1.3 肾上腺激素（皮质醇）解读

#### 四个时间点解读

| 时间点 | 正常范围 | 意义 | 异常解读 |
|--------|---------|------|---------|
| **晨起（醒后）** | 高 | CAR（皮质醇觉醒反应） | 低=肾上腺疲劳/抑郁 |
| **中午** | 中等 | 日间维持 | 高=慢性压力/炎症 |
| **傍晚** | 低 | 开始下降 | 高=HPA轴失调 |
| **夜间** | 极低 | 睡眠准备 | 高=失眠/焦虑 |

#### 皮质醇模式类型

```
【正常模式】
晨起高 → 中午中 → 傍晚低 → 夜间极低
  = 健康的昼夜节律

【模式A：过高型】
全天高，尤其夜间也高
  → 慢性压力/炎症/焦虑
  → 炁脉：邪维高，瘾维可能也高（焦虑驱动）
  → 方案：♣祛（抗炎）+ 正念/冥想（降皮质醇）

【模式B：过低型】
晨起低，全天平坦
  → 肾上腺疲劳/HPA轴功能低下
  → 炁脉：炁维低，邪维可能高（免疫抑制）
  → 方案：♥补（支持肾上腺）+ 适应原草药（人参/黄芪/甘草）

【模式C：颠倒型】
晨起低，夜间高
  → 昼夜节律完全紊乱
  → 炁脉：脉维严重失调（时辰错乱）
  → 方案：♦通（重建节律）+ 晨间光照 + 夜间避光

【模式D：CAR异常】
醒后30-60分钟皮质醇不升或过度升高
  → 下丘脑功能障碍
  → 常见于：抑郁症/创伤后/慢性疲劳
  → 方案：需综合评估，可能涉及瘾维深层问题
```

#### 代谢化皮质醇 vs 游离皮质醇

| 组合 | 游离皮质醇 | 代谢化皮质醇 | 意义 |
|------|----------|------------|------|
| **真高** | 高 | 高 | HPA轴过度激活 |
| **清除快** | 正常/低 | 高 | 产生多但代谢快（常甲状腺功能驱动） |
| **真低** | 低 | 低 | 肾上腺衰竭/晚期HPA功能障碍 |
| **清除慢** | 高 | 正常/低 | 产生不多但清除慢（常甲状腺功能低下） |

### 1.4 雄激素解读

| 指标 | 升高意义 | 降低意义 | **炁脉映射** |
|------|---------|---------|------------|
| **DHEA** | PCOS/肾上腺增生 | 肾上腺疲劳/衰老 | 炁维指标 |
| **睾酮** | PCOS/肿瘤 | 性腺功能低下 | 炁维指标 |
| **5α-DHT** | 脱发/痤疮/前列腺 | — | 毒维（代谢失衡） |
| **5α/5β比值** | 5α还原酶活跃 | — | 毒维指标 |

```
【PCOS女性】
DHEA↑ + 睾酮↑ + 5α-DHT↑
  → 雄激素优势
  → 常伴胰岛素抵抗
  → 炁脉方案：♣祛（降雄）+ ♦通（改善胰岛素敏感）
  → 具体：肌醇+铬（改善胰岛素）+ 甘草（降睾酮）

【甲状腺结节+雄激素低】
DHEA↓ + 睾酮↓
  → 肾上腺功能不足
  → 常见于长期压力/ autoimmune
  → 炁脉方案：♥补（支持肾上腺和甲状腺）
  → 具体：适应原（黄芪/人参）+ 硒（支持甲状腺）
```

## 二、有机酸检测（OAT - Organic Acids Test）

### 2.1 检测概述

```
【是什么】
尿液有机酸检测，反映：
  - 线粒体功能（能量代谢）
  - 肠道酵母/细菌过度生长
  - 营养缺乏（维生素B族/抗氧化物）
  - 神经递质代谢
  - 草酸代谢
  - 解毒功能

【优势】
  ✅ 非侵入性（尿液）
  ✅ 反映代谢功能（不只是水平）
  ✅ 可发现肠道问题（粪便检测可能漏掉）

【局限】
  ⚠️ 受饮食/补充剂影响（需遵医嘱停药）
  ⚠️ 部分标记有多种来源（需综合分析）
```

### 2.2 肠道酵母/真菌标记

| 标记 | 来源 | 升高意义 | **炁脉映射** |
|------|------|---------|------------|
| **阿拉伯糖（Arabinose）** | 白色念珠菌 | 念珠菌过度生长 | 毒维↑ |
| **柠檬酸** | 念珠菌/曲霉菌 | 真菌过度生长 | 毒维↑ |
| **5-羟甲基糠酸** | 曲霉菌 | 霉菌过度生长 | 毒维↑ |
| **酒石酸** | 酵母 | 酵母过度生长 | 毒维↑ |

```
【解读策略】
  1-2个标记轻度升高 → 轻度菌群失调，饮食调整+益生菌
  3-5个标记升高 → 明显真菌过度生长，需抗真菌治疗
  6+个标记升高 → 严重真菌/霉菌问题，综合干预

【炁脉方案】
  ♠排：抗真菌（大蒜素/牛至油/制霉菌素）
  ♥补：益生菌（布拉氏酵母菌+乳酸菌）
  ♦通：修复肠屏障（谷氨酰胺+锌）
  ♣祛：抗炎（Omega-3/姜黄素）
```

### 2.3 细菌标记

| 标记 | 来源 | 升高意义 | **临床关联** |
|------|------|---------|------------|
| **HPHPA** | 艰难梭菌 | 艰难梭菌毒素 | 神经精神症状（抑制多巴胺转换） |
| **4-甲酚** | 艰难梭菌 | 同HPHPA | 自闭症/行为问题常见 |
| **琥珀酸** | 细菌/线粒体 | 双重来源 | 需结合其他标记判断 |
| **苯甲酸** | 肠道细菌 | 细菌过度生长 | 可能干扰解毒 |

```
【HPHPA升高的临床意义】
HPHPA抑制多巴胺-β-羟化酶
  → 多巴胺不能转化为去甲肾上腺素
  → 多巴胺相对过剩
  → 症状：多动/强迫/焦虑/攻击性

常见于：
  - 自闭症谱系儿童
  - 有肠道问题的精神症状患者
  - 长期使用抗生素后

【炁脉方案】
  ♠排：清除艰难梭菌（益生菌+针对性抗菌）
  ♦通：支持多巴胺转换（维生素C/铜/Mg）
  ♣祛：抗炎（修复肠道炎症）
```

### 2.4 线粒体标记（Krebs循环）

| 标记 | 来源 | 升高意义 | **支持营养素** |
|------|------|---------|------------|
| **柠檬酸** | Krebs循环 | 线粒体功能障碍/谷胱甘肽不足 | 谷胱甘肽/NAC |
| **顺乌头酸** | Krebs循环 | 线粒体障碍/Complex I问题 | 谷胱甘肽 |
| **异柠檬酸** | Krebs循环 | 维生素B3/B6缺乏 | B3/B6 |
| **α-酮戊二酸** | Krebs循环 | B1/B5/B6缺乏 | B族维生素 |
| **琥珀酸** | Krebs循环 | CoQ10/核黄素缺乏/毒素 | CoQ10/B2 |
| **富马酸** | Krebs循环 | 线粒体功能障碍 | CoQ10/NAD+/肉碱 |
| **苹果酸** | Krebs循环 | B3/CoQ10缺乏 | B3/CoQ10 |

```
【模式识别】
多个Krebs标记同时升高
  → 线粒体能量代谢障碍
  → 常见于：慢性疲劳/自身免疫/神经退行性疾病
  → 原因：毒素（重金属/霉菌）+ 营养缺乏 + 氧化应激

【炁脉方案】
  ♥补：线粒体支持（CoQ10+乙酰肉碱+B族+镁）
  ♠排：清除毒素（根据来源）
  ♣祛：抗氧化（维生素C/E/硒/锌）
```

### 2.5 草酸代谢

| 标记 | 升高意义 | **临床关联** |
|------|---------|------------|
| **草酸** | 草酸代谢异常 | 肾结石/疼痛/氧化应激 |
| **甘油酸** | 遗传缺陷 | 原发性高草酸尿症 |

```
【高草酸的来源】
  1. 饮食：菠菜/甜菜/坚果/巧克力/茶
  2. 肠道：草酸杆菌缺乏（降解草酸）
  3. 代谢：B6缺乏（内源性草酸合成↑）
  4. 霉菌：曲霉菌可产生草酸

【炁脉方案】
  ♠排：减少高草酸食物
  ♥补：B6补充（减少内源性合成）
  ♦通：补充草酸杆菌（益生菌）
  ♣祛：镁/钙补充（与草酸结合，减少吸收）
```

### 2.6 神经递质代谢

| 标记 | 来源 | 升高/降低意义 |
|------|------|-------------|
| **香草扁桃酸（VMA）** | 去甲肾上腺素 | 压力/交感神经兴奋 |
| **高香草酸（HVA）** | 多巴胺 | 多巴胺周转率 |
| **5-羟基吲哚乙酸（5-HIAA）** | 血清素 | 血清素代谢 |
| **喹啉酸** | 色氨酸 | 神经毒性/炎症 |
| **犬尿喹啉酸** | 色氨酸 | 神经保护 |
| **喹啉酸/犬尿喹啉酸比值** | 平衡 | >高=神经毒性倾向 |

```
【色氨酸代谢两条路】

5-HT通路（健康）
  色氨酸 → 5-HTP → 血清素 → 5-HIAA（尿液排出）
  ✅ 情绪稳定/睡眠好

犬尿氨酸通路（压力/炎症时）
  色氨酸 → 犬尿氨酸 → 喹啉酸（神经毒性）
  ⚠️ 抑郁/焦虑/认知下降
  
决定因素：
  IDO酶（炎症诱导）→ 推向犬尿氨酸通路
  维生素B6 → 支持5-HT通路
  镁 → 支持5-HT通路

【炁脉方案】
  喹啉酸高 → ♣祛（抗炎）+ B6/镁补充
  HVA/VMA失衡 → ♦通（神经递质支持）
```

## 三、功能医学检测的五维翻译

### 3.1 DUTCH → 五维定级

```
【激素失衡模式 → 五维】

雌激素优势（E>P）
  → 邪维↑（增生风险）
  → 毒维↑（肝脏解毒负担）
  → 方案：♣祛 + ♠排

皮质醇过高（全天高）
  → 邪维↑（炎症）
  → 瘾维↑（压力应对模式）
  → 方案：♣祛 + 正念/冥想

皮质醇过低（全天低）
  → 炁维↓（能量不足）
  → 邪维↑（免疫抑制）
  → 方案：♥补（适应原）

DHEA低
  → 炁维↓（活力不足）
  → 方案：♥补

昼夜节律颠倒
  → 脉维严重失调
  → 方案：♦通（重建节律）
```

### 3.2 OAT → 五维定级

```
【OAT模式 → 五维】

真菌标记高（阿拉伯糖/柠檬酸↑）
  → 毒维↑（真菌毒素）
  → 邪维↑（免疫激活）
  → 方案：♠排（抗真菌）+ ♥补（益生菌）

HPHPA高
  → 毒维↑（细菌毒素）
  → 瘾维↑（神经精神症状）
  → 方案：♠排（抗菌）+ ♦通（神经支持）

线粒体标记高（多个Krebs↑）
  → 炁维↓（能量不足）
  → 毒维↑（毒素损伤）
  → 方案：♥补（线粒体支持）+ ♣祛（抗氧化）

草酸高
  → 毒维↑（氧化应激）
  → 方案：♠排（低草酸饮食）+ ♦通（B6/益生菌）

维生素缺乏（多个B族标记↑）
  → 炁维↓（代谢辅酶不足）
  → 方案：♥补（针对性补充）
```

## 四、检测选择与组合策略

### 4.1 不同症状的首选检测

| 症状/病种 | 首选检测 | 辅助检测 | **目的** |
|----------|---------|---------|---------|
| **甲状腺结节** | 甲状腺功能全套 + 抗体 | DUTCH（激素平衡） | 评估自身免疫背景+雌激素影响 |
| **乳腺结节** | DUTCH（雌激素代谢） | 维生素D、炎症标志物 | 评估雌激素代谢通路 |
| **糖尿病/胰岛素抵抗** | 空腹胰岛素+HOMA-IR | OAT（线粒体功能） | 评估胰岛素敏感性+能量代谢 |
| **慢性疲劳** | OAT（线粒体+真菌） | DUTCH（皮质醇模式） | 找能量不足根源 |
| **抑郁/焦虑** | DUTCH（皮质醇+性激素） | OAT（神经递质） | 评估HPA轴+神经化学 |
| **自身免疫病** | OAT（线粒体+肠道） | 食物不耐受IgG | 找肠道-免疫触发点 |
| **肥胖/代谢综合征** | DUTCH（皮质醇+性激素） | 空腹胰岛素 | 评估激素驱动因素 |

## 五、本库使用原则

### 5.1 检测不是目的，是工具

```
❌ 错误：让患者做一堆检测，然后给一堆补充剂
✅ 正确：根据症状选择关键检测 → 找到"共原" → 制定54牌方案

【核心原则】
  1. 检测是为了"看见"五维无法直接看见的东西
  2. 检测结果要翻译成五维语言
  3. 干预方向由五维定级决定，不是由检测结果直接决定
  4. 补充剂是工具，54牌是策略
```

### 5.2 功能医学的局限（炁脉必须知道）

| 局限 | 说明 | **炁脉的补充** |
|------|------|--------------|
| **检测费用高** | DUTCH/OAT动辄数千元 | 炁脉五维问诊可以初步判断，必要时才做检测 |
| **解读门槛高** | 需要专业训练 | 本库提供标准化解读，但仍需经验积累 |
| **补充剂依赖** | 容易变成"吃补充剂治病" | 炁脉强调生活方式（时辰/饮食/运动/心理）为根本 |
| **忽视情志** | 功能医学较少处理心理层面 | 炁脉瘾维干预是核心优势 |
| **时代病因盲区** | 不处理光污染/电磁场等 | 炁脉时代病因学补充 |
