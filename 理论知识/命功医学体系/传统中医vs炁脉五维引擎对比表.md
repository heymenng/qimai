> - 炁脉医学是怎么开方的？

## 一、全流程对比总表

| 步骤 | 传统中医开方 | 炁脉五维引擎开方 | 本质区别 |
|------|-------------|-----------------|---------|
| **① 诊断** | 望闻问切 → 八纲辨证（阴阳表里寒热虚实）→ 定证型（如：脾虚湿盛） | 望闻问切 → **五维定量**（炁/毒/脉/邪/瘾 1-10级）→ 得坐标（如：炁6/毒7/脉5/邪5/瘾4） | **定性 → 定量** |
| **② 决策** | 凭经验判断：虚则补之，实则泻之 | **四法则算法**：急则治标？缓则治本？标本兼治？先通后补？ | **经验 → 算法** |
| **③ 选方** | 从300个经典方中找一个最接近的（如：参苓白术散） | **不需要背方**——从五维缺口直接"长"出药方 | **调用模板 → 现场编译** |
| **④ 选药** | 在主方基础上加减（加两味，减一味） | **维度定向选药**：缺什么维度 → 选什么方向（♥/♠/♦/♣）→ 归经筛选 | **经验加减 → 逻辑推演** |
| **⑤ 定君臣** | 凭感觉：这个药多放点，那个药少放点 | **君臣佐使结构**：君30-40% / 臣20-30% / 佐15-25% / 使5-10% | **模糊 → 结构化** |
| **⑥ 定剂量** | "少许"、"适量"、师徒口传心授 | **脉级分层**：轻证(5-6级)取下限 / 中证(7-8级)取中值 / 重证(9-10级)取上限 | **口传 → 标准化** |
| **⑦ 查禁忌** | 靠记忆：十八反、十九畏、妊娠禁忌 | **自动扫描**：十八反 + 十九畏 + 毒性叠加 + 孕妇禁忌，一秒出结果 | **人脑记忆 → 引擎校验** |
| **⑧ 出方** | 医师手写处方，患者看不懂 | **结构化处方**：每味药标注 ♥/♠/♦/♣ 方向 + 剂量 + 煎服法 + 疗程 | **模糊 → 透明** |
| **⑨ 疗效判断** | "感觉好点了"——主观描述 | **十八变追踪**：3天/7天/14天定量记录反应，判断是排异还是恶化 | **主观 → 可量化** |
| **⑩ 调方** | "再来看看，调整一下"——凭经验 | **反馈算法**：过补减♥、过攻减♠、过散减♣、过通减♦，有据可查 | **经验 → 可追溯** |

## 二、诊断环节对比

### 传统中医：辨证（定性）

```
患者：乏力、食少、腹胀、便溏、口苦、苔黄腻

中医诊断：
  望：面色萎黄，苔黄腻
  闻：口气重
  问：乏力食少，腹胀便溏，口苦
  切：脉濡数
  
辨证结果：脾虚湿盛，兼有湿热
  → 定性标签（没有数字，没有程度）
  → 不同医师可能辨为：脾胃湿热、脾虚湿阻、湿热中阻...
```

### 炁脉医学：五维判位（定量）

```
患者：同上

炁脉诊断：
  炁维度：6级（中度脾虚——运化无力）
  毒维度：7级（较重湿热——湿毒+热毒）
  脉维度：5级（轻度瘀堵——气血不畅）
  邪维度：5级（轻度肝郁——气机不畅）
  瘾维度：4级（轻度失眠——心神不宁）
  
五维坐标：【炁6 / 毒7 / 脉5 / 邪5 / 瘾4】
  → 定量坐标（精确到1-10级）
  → 不同医师诊断结果一致（标准统一）
  → 可比较：治疗前 vs 治疗后，数值变化可见
```

| 对比项 | 传统中医 | 炁脉五维 |
|--------|---------|---------|
| **诊断结果** | "脾虚湿盛"（文字标签） | 【炁6/毒7/脉5/邪5/瘾4】（数字坐标） |
| **可比较性** | 无法比较两个患者的轻重 | 可精确比较：A患者毒7级，B患者毒5级，A更重 |
| **可追踪性** | "好点了"——无法量化 | 治疗前毒7级 → 治疗后毒4级，改善3级 |
| **传承难度** | 需要悟性，十年出师 | 按标准操作，三个月可上手 |

## 三、组方环节对比（核心差异）

### 场景：脾虚湿热证（同上患者）

#### 传统中医开方思路：

```
辨证：脾虚湿盛，兼有湿热
→ 选方：参苓白术散（脾虚湿盛基础方）
→ 加减：
    原方：人参、白术、茯苓、甘草、山药、莲子、薏苡仁、砂仁、桔梗、白扁豆
    加减：去莲子（患者无泄泻），加黄连（清热燥湿），加茵陈（利湿退黄）
    去桔梗（无咳嗽），减薏苡仁（已加茵陈）
→ 剂量：凭经验
    人参10g、白术15g、茯苓20g、甘草6g、山药15g、薏苡仁20g
    砂仁6g、黄连6g、茵陈15g
→ 出方：参苓白术散加减
```

**特点**：
- ✅ 有经典方基础，安全有效
- ⚠️ 依赖医师背方数量（300个方 vs 5000个病证）
- ⚠️ 加减靠经验，新手容易加减错
- ⚠️ 患者不知道为什么要加黄连、去莲子

---

#### 炁脉五维引擎开方思路：

```
输入：【炁6 / 毒7 / 脉5 / 邪5 / 瘾4】

Step 1: 判断急缓
  最高维度=毒7（<9），炁=6（>5）
  → 非急症，虚实夹杂 → 标本兼治

Step 2: 确定君药
  本虚=炁6（脾虚），标实=毒7（湿热）
  脾虚不耐峻攻 → 补气为主，清热为辅
  → 君药方向：♥红桃（健脾益气）
  → 病变脏腑：脾 → 归脾经
  → 选药：党参（♥J，归脾肺）+ 白术（♥J，归脾胃）
  → 剂量：党参25g + 白术15g（共40g，占全方35%）

Step 3: 确定臣药
  辅助君药健脾 + 针对湿热
  → 臣药方向：♠黑桃（清热燥湿）+ ♥红桃（辅助健脾）
  → 选药：茯苓（♠J，归脾肾，健脾利湿）+ 黄连（♠K，归脾胃，清热燥湿）
  → 剂量：茯苓25g + 黄连6g（共31g，占全方25%）
  注意：黄连仅6g（轻证剂量），因先补后攻

Step 4: 确定佐药
  佐助：陈皮10g（♣6，理气健脾，防补气滞塞）
  佐助：柴胡6g（♣7，疏肝升阳，针对邪5肝郁）
  佐制：生姜3片（温胃和胃，制黄连苦寒）
  → 佐药总量：约20g，占15%

Step 5: 确定使药
  调和：炙甘草6g
  引经：大枣3枚（约10g，补脾和胃）
  → 使药总量：约16g，占8%

Step 6: 禁忌检查
  十八反：无冲突 ✓
  十九畏：无冲突 ✓
  毒性：无毒性药 ✓

Step 7: 出方
```

**最终处方（结构化）**：
```
【五维坐标】炁6 / 毒7 / 脉5 / 邪5 / 瘾4
【治则】标本兼治（补6攻4）
【法则】脾虚为本，湿热为标，补气为主，清热为辅

君（35%）：
  ♥ 党参  25g  （♥J，归脾肺，补中益气）
  ♥ 白术  15g  （♥J，归脾胃，健脾燥湿）

臣（25%）：
  ♠ 茯苓  25g  （♠J，归脾肾，健脾利湿）
  ♠ 黄连   6g  （♠K，归脾胃，清热燥湿）

佐（15%）：
  ♣ 陈皮  10g  （♣6，归脾肺，理气健脾）
  ♣ 柴胡   6g  （♣7，归肝胆，疏肝升阳）
  生姜 3片      （温胃和胃，佐制苦寒）

使（8%）：
  ♥ 炙甘草 6g  （调和诸药）
  ♥ 大枣   3枚 （补脾和胃，引经）

【全方总重】约156g
【煎服法】每日1剂，水煎服，分2次温服
【疗程】7剂为一个周期，复诊调方
【禁忌】忌生冷油腻
【十八变预警】预计3-5天可能出现：大便次数略增（排毒反应）、口苦减轻（湿热渐清）
```

**特点**：
- ✅ 不需要背300个方，现场"长"出药方
- ✅ 每一步可解释（为什么用党参而不用人参？因为炁6级用♥J即可，不用♥K）
- ✅ 剂量有依据（25g vs 6g，不是凭感觉，是按君臣比例+脉级分层）
- ✅ 患者看得懂（知道每味药是干嘛的，为什么选这个药）
- ✅ 可追踪疗效（7天后复测五维，看炁6→炁8？毒7→毒4？）
