## 一、引擎优化内容回顾

### V2.1新增6条规则

| 规则编号 | 规则名称 | 核心修正 | 针对问题 |
|---------|---------|---------|---------|
| **规则一** | 君臣佐使动态比例 | 急症君40%、纯虚臣30%、虚实夹杂佐20% | 比例僵化 |
| **规则二** | 本虚强制补益 | 炁≤5或瘾≥7时，强制加♥红桃J级以上补益药 | 补益偏弱 |
| **规则三** | 重度瘾强制重镇 | 瘾≥8时，强制加♣梅花K级/矿物类重镇药 | 重镇缺失 |
| **规则四** | 急症强制开窍 | 脉≥9+胸痛/神昏时，强制加芳香开窍药 | 开窍不足 |
| **规则五** | 54牌调用优先级修正 | 虚证♥优先、实证♠优先、瘾症♣K优先 | 调用偏差 |
| **规则六** | 验证后修正清单 | 快速查阅表，标记已修正病案 | 追溯管理 |

**数据库已更新**：第一章1.7节已固化V2.1规则，1.3节示例已更新为双君结构。

### CASE-01：脾虚湿盛证（V2.1修正版）

**【五维坐标】**炁6 / 毒7 / 脉5 / 邪5 / 瘾4

**【V1.0原处方问题】**
- 君药仅党参一味，补气力度不足（参苓白术散用人参+白术+茯苓三味君级）
- 与经典方偏差：君药一致率60%，补益偏弱

**【V2.1引擎重新推演】**

Step 1 → 判断急缓
```
最高维度=毒7（<9），炁=6（>5）
→ 非急症，虚实夹杂 → 标本兼治
→ 触发规则二：炁6≤5？否（炁6不触发强制补益）
→ 但本虚=脾虚，按规则五"虚实夹杂"优先级：♥红桃J + ♠黑桃K
```

Step 2 → 确定君药（规则二优化：脾虚双君）
```
本虚=炁6（脾虚），标实=毒7（湿热）
→ 君药方向：♥红桃（健脾益气）——双君结构
→ 病变脏腑：脾 → 归脾经
→ 选药：
  君药1：党参【090】♥J，归脾肺，补中益气 → 25g
  君药2：白术【091】♥J+♠J，归脾胃，健脾燥湿 → 15g
  （按规则二：脾虚必须脾+胃双补，党参益气+白术健脾）
→ 双君总量：40g，占35%
```

Step 3 → 确定臣药
```
辅助君药健脾 + 针对湿热
→ 臣药方向：♠黑桃（清热燥湿）+ ♥红桃（辅助健脾）
→ 选药：
  茯苓【092】♠J+♥7，归脾肾，健脾利湿 → 25g（一药双维）
  黄连【012】♠K，归脾胃，清热燥湿 → 6g（轻量，因先补后攻）
→ 臣药总量：31g，占25%
```

Step 4 → 确定佐药
```
佐助：陈皮【254】♣6+♠J，理气健脾 → 10g（防双君补气滞塞）
佐助：柴胡【044】♣7+♥6，疏肝升阳 → 6g（针对邪5）
佐制：生姜3片，温胃和胃，制黄连苦寒
→ 佐药总量：约20g，占15%
```

Step 5 → 确定使药
```
调和：炙甘草【031】♥5+♠4 → 6g
引经：大枣【033】♥4+♣梅花4 → 3枚（约10g）
→ 使药总量：约16g，占8%
```

**【V2.1优化处方】**
```

【治则】标本兼治（补6攻4）
【法则】脾虚为本，湿热为标，双君健脾益气，清热为辅

  ♥ 党参  25g  （♥J【090】，归脾肺，补中益气）
```
