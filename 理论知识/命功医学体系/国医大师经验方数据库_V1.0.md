## 一、朱良春：虫类药学家·疑难病克星

### 1.1 学术核心

```
【核心思想】扶正消癥，虫蚁搜剔

1. 扶正消癥是主法
   - 肿瘤/结节的根本：正气亏虚 + 癌毒/痰瘀胶结
   - 扶正 = 益气养阴（黄芪/党参/仙鹤草/珠儿参）
   - 消癥 = 软坚散结 + 清热解毒 + 活血化瘀

2. 灵活辨证是变法
   - 不同肿瘤、不同阶段、灵活调整
   - 不以一方一法守到底

3. 虫类药是特色
   - 全蝎、蜈蚣、地龙、守宫、蜂房、僵蚕
   - 搜剔经络顽邪，穿透力极强
   - "虫类药学家""五毒医生"之称

4. 大剂量是风格
   - 仙鹤草50-90g（一般医生用15-30g）
   - 黄芪60-120g（重症肌无力）
   - 生牡蛎30-60g（软坚散结）
```

## 二、邓铁涛：五脏相关·调脾护心

### 2.1 学术核心

```
【核心思想】五脏相关，调脾护心

1. 五脏相关学说
   - 不是五行生克的机械对应
   - 是五脏之间生理病理的相互影响
   - 心脾相关：冠心病从脾胃论治

2. 调脾护心
   - 冠心病的病位在心，但与脾胃最密切
   - 脾为生痰之源，痰湿→瘀血→痹阻心脉
   - 治疗着重调脾护心、益气除痰

3. 益气化痰祛瘀
   - 冠心病：本虚标实（气虚为本，痰瘀为标）
   - 南方湿重 → 早期偏重治痰，后期痰瘀同治
   - 代表方：邓氏温胆汤

4. 重用黄芪
   - 重症肌无力：黄芪60g起，常用90g
   - 高血压气虚型：黄芪30g
   - 特点：善用"南芪"五爪龙（不温不燥）
```

```
        胸闷、气促、心悸、苔腻

【五维映射】
  炁维：党参 → 益气健脾
  毒维：半夏/陈皮 → 燥湿化痰
  脉维：枳壳 → 行气宽中；丹参 → 活血通脉
```

## 三、路志正：湿病泰斗·调理脾胃

### 3.1 学术核心

```
【核心思想】持中央，运四旁，怡情志，调升降，顾润燥，纳化常

1. 湿邪理论
   - 北方亦多湿（不只是南方）
   - 湿邪伤人：天、地、人之不同
   - 现代人饮食失调 → 内湿广泛

2. 调理脾胃十八字方针
   持中央 → 脾胃为后天之本
   运四旁 → 脾健则四脏皆健
   怡情志 → 情志影响脾胃
   调升降 → 脾升胃降
   顾润燥 → 脾燥胃润
   纳化常 → 受纳运化正常

3. 治湿三法
   上焦：宣肺（杏仁/枇杷叶/苏梗）
   中焦：芳化（藿香/佩兰/苍术）
   下焦：渗利（茯苓/薏苡仁/滑石）

4. 风湿病三因论
   五虚七邪论
   脏腑气机失调论
```

```
  脉维：桃仁/皂角子 → 润肠通便通脉
  邪维：晚蚕沙/椿根皮 → 清热利湿祛邪
  
【心法】
  路老强调：湿秘不可妄用攻下
  需运脾化湿 → 湿去则便自通
  "运中有降，降中有通"
```

## 四、张学文：脑病圣手·活血化瘀

### 4.1 学术核心

```
【核心思想】活血化瘀，通脑活络

1. 中风病核心病机
   - 虚、瘀、风三者关系
   - 因虚致瘀，瘀阻脑络 → 中风
   - 瘀血阻滞脑络 = 贯穿始终的基本病机

2. 四期六证
   四期：先兆期 → 急性发作期 → 恢复期 → 后遗症期
   六证：肝热血瘀 / 气虚血瘀 / 痰瘀阻窍 / 瘀热腑实 / 颅脑水瘀 / 肾虚血瘀

3. 颅脑水瘀理论
   - "血不利则为水"
   - 瘀血 + 水湿痰浊 → 互阻脑络
   - 中风/脑积水/脑肿瘤的关键病机

4. 中风先兆识别
   - 年龄40岁以上
   - 眩晕、偏身麻木、舌紫暗、舌下瘀丝、脉弦滑
   - 强调：早发现、早防治

5. 疑难病从瘀论治
   - 久病入络，必有瘀血
   - 活血化瘀法贯穿始终
```

### 4.2 核心经验方

#### 【方1】清脑通络汤（中风先兆）

```
【组成】
  草决明30g    川芎12g      赤芍10g      山楂15g
  丹参15g      磁石30g(先煎)  菊花12g      葛根15g
  地龙10g      豨莶草30g    川牛膝15g    水蛭6g
  
【功效】清脑降压，活血通络

【主治】中风先兆（小中风/TIA）
        头痛眩晕、肢体麻木、舌紫暗、舌下瘀阻

【五维映射】
  炁维：山楂/丹参 → 养血化瘀
  毒维：菊花/草决明 → 清肝解毒
  脉维：川芎/地龙/水蛭/牛膝 → 活血通络通脉
  邪维：豨莶草 → 祛风除湿祛邪
  瘾维：⚠️ 需配合情绪管理（肝阳上亢常伴易怒）
  
【加减】
  + 大便干结：加大黄6g
  + 气虚：加黄芪30g
  + 痰热：加竹沥15ml
```

#### 【方2】通窍活血利水方（颅脑水瘀）

```
【组成】
  丹参15g      桃仁15g      红花15g      益母草30g
  茯苓24g      川牛膝15g    白茅根30g    川芎12g
  赤芍12g      水蛭6g       三七粉3g(冲)  石菖蒲10g
  
【功效】醒脑通窍，活血利水

【主治】颅脑水瘀证
        中风急性期（脑水肿）、脑积水、脑肿瘤

【五维映射】
  炁维：丹参/三七 → 养血化瘀不伤正
  毒维：茯苓/白茅根 → 利水化浊解毒
  脉维：桃仁/红花/川芎/水蛭 → 强力活血通脉
  邪维：益母草/牛膝 → 活血利水祛邪
  
【心法】
  麝香0.1g冲服 → 开窍醒神（突破血脑屏障）
  出血性中风 → 加三七粉止血化瘀
  此方降低颅内压效果显著
```

#### 【方3】通脉舒络汤（脑梗死恢复期）

```
【组成】

【功效】益气活血，通脉舒络

【主治】缺血性中风恢复期（气虚血瘀型）
        半身不遂、言语不利、肢体麻木

【五维映射】
  炁维：黄芪30g → 大补元气，推动血行
  脉维：桃仁/红花/丹参/地龙/水蛭 → 活血化瘀通脉
  邪维：赤芍/当归 → 养血活血祛邪
  
【心法】
  张老强调："气行则血行"
  重用黄芪益气 → 气足则瘀血自化
  虫类药（地龙/水蛭）→ 搜剔经络顽瘀
```

#### 【方4】脑窍通汤（脑积水/小儿脑积水）

```
【主治】脑积水（颅脑水瘀型）
        外伤性脑积水、小儿先天性脑积水

【五维映射】
  炁维：丹参/当归 → 养血益气

  脉维：麝香/石菖蒲 → 开窍通脉；天麻/钩藤 → 平肝通脉
  邪维：桃仁/红花/水蛭 → 活血化瘀祛邪
  
【心法】
  麝香是关键 → 芳香开窍，穿透血脑屏障
  水瘀同治 → 活血+利水同时进行
```

### 5.2 五维映射共性

```
【四大师的共识】

1. 重视"气"
   朱良春：扶正消癥 → 益气养阴
   邓铁涛：调脾护心 → 益气化痰
   路志正：调理脾胃 → 健脾益气
   张学文：通脉舒络 → 益气活血
   → **炁维是调理的基础**

2. 重视"通"
   朱良春：消癥 = 软坚散结通络
   邓铁涛：祛瘀 = 化痰活血通脉
   路志正：运四旁 = 脾健则四脏皆通
   张学文：通脑 = 活血利水通窍
   → **脉维是调理的关键**

3. 重视"毒/邪"的清除
   朱良春：清热解毒抗癌
   邓铁涛：清热化痰祛湿
   路志正：清热利湿分消
   张学文：清热化瘀利水
   → **毒维/邪维是调理的重点**

4. 相对忽视"瘾维"
   四位大师均较少涉及心理/情志的系统干预
   → **这是炁脉医学的独特价值所在**
```

```
   路志正的湿病方 + 饮食行为矫正
```
