## 一、知识图谱架构总览

### 1.1 图谱设计原则

**不是简单分类，是关系网络**：
```
传统中医知识库：
  脏腑 → 功能 → 症状 → 方剂 → 药物
  （线性链条，缺乏关联）

炁脉知识图谱：
  脏腑 ═══ 经络 ═══ 穴位 ═══ 五维 ═══ 54牌 ═══ 症状 ═══ 时代 ═══ 神经 ═══ 信息
  （多维网络，任意节点可关联）
```

**核心设计理念**：
1. **节点=实体**：脏腑、经络、穴位、症状、牌、维度、时代类型等
2. **边=关系**：相生、相克、表里、流注、对应、编码、映射
3. **属性=量化**：五维级别、中心性、熵值、可塑性等
4. **层级=尺度**：从分子到生态，每个实体都有多水平属性

### 7.3 关键查询模式

```cypher
// 查询1：找共原（从症状到最高维度）
MATCH (s:症状 {name: $symptom})-[:表现为]-(z:脏腑)-[:五维映射]-(w:五维)
WITH z, w, w.level as level
ORDER BY level DESC
RETURN z.name as 共原脏腑, w.name as 最高维度, level as 级别
LIMIT 1

// 查询2：最优穴位（中心性排序）
MATCH (j:经络)-[:包含]-(x:穴位)
WHERE j.name IN $target_meridians
RETURN x.name, x.betweenness_centrality, x.degree_centrality
ORDER BY x.betweenness_centrality DESC
LIMIT 5

// 查询3：传播路径预判（级联效应）
MATCH path = (start:经络 {name: $start_meridian})-[:流注*1..3]-(end:经络)
WHERE ALL(j IN nodes(path) WHERE j.stagnation_level > 5)
RETURN [j in nodes(path) | j.name] as 传播路径

// 查询4：跨学科综合评估
MATCH (p:患者 {id: $patient_id})-[:当前状态]-(w:五维)
MATCH (w)-[:对应]-(z:脏腑)
MATCH (z)-[:多水平显化]-(m:分子水平)
MATCH (z)-[:神经对应]-(n:神经结构)
RETURN w.levels as 五维, z.name as 脏腑, m.state as 分子状态, n.structure as 神经结构
```
