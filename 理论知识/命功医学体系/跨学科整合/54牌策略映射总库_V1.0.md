> **用途**：跨学科54牌策略的快速参考手册

> **版本**：V1.0

## 一、使用说明

```
【检索方法】
1. 确定目标学科 → 查看该学科4花色×4等级的策略
2. 确定干预目标 → 跨学科检索相同目标的不同手段
3. 设计复合方案 → 从多个学科选取协同策略

【策略等级】
♥3/♠3/♦3/♣3 = 基础级（日常/预防）
♥5/♠5/♦5/♣5 = 进阶级（治疗/调理）
♥7/♠7/♦7/♣7 = 强化级（重症/攻坚）
♥9/♠9/♦9/♣9 = 终极级（系统重置/深度干预）
```

## 五、策略选择决策树

```
【第一步：确定最高维度】
  五维扫描 → 最高维定根

【第二步：确定学科视角】
  炁维高 → 优先微生物组/PNI/系统生物学
  毒维高 → 优先代谢组学/微生物组/表观遗传学
  脉维高 → 优先神经科学/PNI/复杂网络
  邪维高 → 优先免疫学/微生物组/PNI
  瘾维高 → 优先PNI/表观遗传学/系统生物学

【第三步：选择花色】
  虚证 → ♥补
  实毒 → ♠排
  瘀阻 → ♦通
  炎症 → ♣祛

【第四步：确定等级】
  轻度/预防 → 3级
  中度/治疗 → 5级
  重度/攻坚 → 7级
  极重/重置 → 9级

【第五步：跨学科协同】
  主学科+1-2个辅助学科
  避免同功能重复
  追求机制互补
```
