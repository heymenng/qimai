## 一、原始知识摘要

### 1.1 稳态与稳态负荷（Allostasis & Allostatic Load）

**McEwen的经典框架**：
- **稳态（Allostasis）**：短期适应性调节，维持生存（如应激时皮质醇升高）
- **稳态负荷（Allostatic Load）**：长期适应性调节的累积代价，导致病理

**核心发现**：
```
短期应激 → 保护性反应（allostasis）
  ↓
长期应激 → 累积损伤（allostatic load）
  ↓
化学失衡 + 昼夜节律紊乱 + 脑结构萎缩
  ↓
焦虑、抑郁、敌意、物质滥用、PTSD
```

**关键洞察**：
- 糖皮质激素和儿茶酚胺短期保护，长期损害
- 大脑既是应激的解释者和反应者，也是应激的目标
- 童年虐待/忽视增加晚年稳态负荷 → 导致社会孤立、敌意、抑郁、肥胖、CVD

### 1.2 表观遗传重构：应激的分子记忆

**核心发现（PMC 2025综述）**：

慢性应激导致一致的表观遗传改变：
| 表观遗传标记 | 变化 | 影响 |
|-----------|------|------|
| **NR3C1甲基化** | 高甲基化 | 糖皮质激素受体敏感性降低 |
| **FKBP5甲基化** | 去甲基化+启动子高甲基化 | 应激反应失调 |
| **BDNF甲基化** | 启动子高甲基化 | 脑源性神经营养因子表达降低 |
| **组蛋白H3/H4乙酰化** | 降低 | 神经可塑性相关基因表达抑制 |
| **microRNA** | miR-16/124/132/135a/34c失调 | 突触可塑性、神经递质调节紊乱 |

**关键洞察**：
```
环境应激 → 表观遗传重塑 → 基因表达改变 → 脑功能/结构改变
→ 这些改变是**可逆的**（通过干预可以恢复）
→ 为"性功修炼可修复损伤"提供了分子基础
```

### 1.3 中枢-外周神经免疫动态

**核心发现（Mol Psychiatry 2025）**：

心理应激通过多通路影响全身：
```
心理应激
  ├─ 激活HPA轴 → 皮质醇升高
  ├─ 激活交感神经 → 儿茶酚胺升高
  ├─ 免疫失调 → IL-6、TNF-α升高
  ├─ 外周器官炎症（肠、脾、肝、肺、心）
  ├─ 代谢紊乱 → 心血管疾病、免疫功能障碍
  └─ 肠道菌群失调 → 肠脑轴紊乱 → 加重精神症状
```

**慢性应激的恶性循环**：
```
慢性应激 → HPA轴失调 → 糖皮质激素抵抗
  → 抗炎作用减弱 → 促炎状态持续
  → 外周炎症 → 血脑屏障通透性增加
  → 神经炎症 → 情绪/认知障碍
  → 更多应激 → 恶性循环
```

### 1.4 内感受过载（Allostatic Interoceptive Overload）

**核心概念（Biol Psychiatry 2025）**：
- **内感受（Interoception）**：整合、预期和调节内部身体状态
- **内感受过载**：内部状态调节能力崩溃

**涉及的生物学机制**：
```
全身级联反应
  ├─ 大脑结构和功能改变
  ├─ 心-脑交互（HRV降低）
  ├─ 呼吸-脑交互（呼吸模式改变）
  ├─ 肠-脑-微生物轴（菌群失调）
  ├─ 外周生物过程（炎症、免疫）
  └─ 表观遗传通路（基因表达重塑）
```

     = 不良应对习惯（暴食、熬夜、刷手机）
