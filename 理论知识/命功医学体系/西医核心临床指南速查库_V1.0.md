# 西医核心临床指南速查库 V1.0

> **定位**：炁脉医学四医合诊的西医决策支撑
> **用途**：快速查阅西医标准，明确转诊红线、诊断标准、治疗路径
> **原则**：不是替代西医，是**在西医框架内找到炁脉介入的最佳时机和位置**
> **版本**：V1.0（优先覆盖甲状腺/糖尿病/心血管/乳腺四大病种）
> **更新**：2026年5月7日
> **来源**：ATA/AACE/ACC-AHA/NCCN官方指南

---

## 一、甲状腺结节（ATA 2015 + 2023消融声明 + 2024综述）

### 1.1 诊断路径

```
发现结节
  ↓
第一步：TSH（必查）
  ├─ TSH正常/升高 → 超声评估
  └─ TSH降低 → 核素扫描（排查功能性结节）
  
第二步：超声风险分层（ATA分层 / ACR TI-RADS）
  
第三步：FNA细针穿刺（按大小和超声特征）
```

### 1.2 超声风险分层与穿刺标准

| ATA超声特征 | 风险等级 | 恶性概率 | FNA标准 | 随访间隔 |
|------------|---------|---------|---------|---------|
| **良性**（纯囊性） | 极低 | <1% | 无需FNA | 无需随访 |
| **低度怀疑**（等/高回声，实性） | 低 | 1-5% | ≥1.5cm | 12-24个月超声 |
| **中度怀疑**（低回声，规则） | 中 | 5-10% | ≥1.0cm | 12个月超声 |
| **高度怀疑**（微钙化/不规则/ taller-than-wide） | 高 | 70-90% | ≥1.0cm | 6-12个月 |

### 1.3 Bethesda细胞学分类与处理

| Bethesda级别 | 名称 | 恶性风险 | **炁脉医学处理原则** |
|-------------|------|---------|-------------------|
| **I** | 标本不满意 | 5-10% | 重复FNA（超声引导） |
| **II** | 良性 | 0-3% | **炁脉主导调理**：观察+调理，6-12个月超声复查 |
| **III** | 意义不明（AUS/FLUS） | 10-30% | 分子检测或重复FNA，**炁脉同步调理** |
| **IV** | 滤泡性肿瘤 | 25-40% | 分子检测或手术探查，**炁脉辅助术前调理** |
| **V** | 怀疑恶性 | 60-75% | **西医主导手术**，炁脉术后修复 |
| **VI** | 恶性 | 97-99% | **西医主导手术+后续治疗**，炁脉全程支持 |

### 1.4 良性结节的管理（炁脉主战场）

```
【良性结节（Bethesda II）】

西医标准：
  - 随访：6-12个月超声
  - 增长标准：体积↑50% 或 两个径线↑20% → 重复FNA
  - 药物：左旋甲状腺素抑制**不推荐**（弊大于利）

炁脉介入时机：
  ✅ 结节≤3cm、良性、无症状 → **炁脉主导调理**
  ✅ 结节>3cm或有压迫症状 → 西医评估手术必要性，炁脉同步调理
  ✅ 术后复发预防 → **炁脉核心工作**（修复体质，防复发）

关键红线：
  🔴 声音嘶哑、吞咽困难、呼吸困难 → 立即西医评估
  🔴 颈部淋巴结肿大 → 立即排除恶性
  🔴 结节短期内快速增长 → 重复FNA
```

### 1.5 甲状腺结节的炁脉五维定级参考

| 西医指标 | 对应炁维 | 对应毒维 | 对应脉维 | 对应邪维 |
|---------|---------|---------|---------|---------|
| TSH正常 | 炁5-6 | — | — | — |
| TSH异常 | 炁7 | — | — | — |
| 单发结节 | — | — | 脉5 | — |
| 多发结节 | — | — | 脉6 | — |

| 伴TPO抗体↑ | — | 毒6（免疫紊乱） | — | 邪5 |
| 微钙化 | — | — | — | 邪8 |

## 二、2型糖尿病（AACE 2023算法 + 2026更新）

### 2.1 诊断标准

| 指标 | 正常 | 糖尿病前期 | 糖尿病 |
|------|------|----------|--------|
| **空腹血糖** | <100 mg/dL | 100-125 | ≥126 |
| **HbA1c** | <5.7% | 5.7-6.4% | ≥6.5% |
| **OGTT 2h** | <140 mg/dL | 140-199 | ≥200 |
| **随机血糖** | — | — | ≥200 + 症状 |

### 2.2 AACE血糖目标（个体化）

| 患者类型 | HbA1c目标 | 空腹血糖 | 餐后2h血糖 |
|---------|----------|---------|----------|
| **大多数患者** | ≤6.5% | <110 mg/dL | <140 mg/dL |
| **老年人/并发症多** | >6.5%（放宽） | — | — |
| **严重低血糖史** | >6.5%（放宽） | — | — |

### 2.3 药物治疗路径（AACE 2023/2026）

```
【一线选择：基于并发症】

有ASCVD（动脉粥样硬化心血管疾病）：
  → SGLT2抑制剂 或 GLP-1受体激动剂（优先）

有心衰：
  → SGLT2抑制剂（ empagliflozin/dapagliflozin）

有CKD（慢性肾病）：
  → SGLT2抑制剂（ eGFR≥20时）

无并发症，以降糖为主：
  → 二甲双胍（若耐受）
  → 或 DPP-4抑制剂 / SGLT2i / GLP-1RA / TZD

【二线/联合用药】
  单药HbA1c不达标（>6.5%）→ 双药联合
  双药不达标 → 三药或加基础胰岛素
```

### 2.4 降糖药物速查表

| 药物类别 | 代表药 | 降糖效力 | 减重 | 低血糖风险 | 心肾保护 | **炁脉注意点** |
|---------|--------|---------|------|----------|---------|-------------|
| **二甲双胍** | Metformin | 中 | 轻减 | 低 | 无直接 | ⚠️ 维生素B12缺乏风险，长期用需监测 |
| **SGLT2i** | 达格列净/恩格列净 | 中 | 减重 | 低 | ✅ 心肾保护 | ⚠️ 泌尿生殖感染风险，酮症酸中毒风险 |
| **GLP-1RA** | 司美格鲁肽/利拉鲁肽 | 强 | 显著减重 | 低 | ✅ 心血管保护 | ⚠️ 胃肠道反应，甲状腺C细胞瘤风险（家族史禁忌） |
| **DPP-4i** | 西格列汀/沙格列汀 | 中 | 中性 | 低 | 中性 | ✅ 耐受性好，但无额外获益 |
| **磺脲类** | 格列美脲/格列吡嗪 | 强 | 增重 | **高** | 无 | 🔴 **低血糖风险高**，老年人慎用 |
| **胰岛素** | 多种 | 最强 | 增重 | **高** | 无 | 🔴 **低血糖+体重增加**，最后选择 |

### 2.5 糖尿病管理的炁脉介入时机

```
【炁脉可以主导】
  ✅ 糖尿病前期（HbA1c 5.7-6.4%）→ 生活方式+炁脉调理，逆转可能
  ✅ 新诊断2型，HbA1c <7.5%，无并发症 → 尝试3个月炁脉+生活方式，监测血糖
  ✅ 已用西药，血糖波动大/副作用明显 → 炁脉辅助减药（需医生配合）

【炁脉辅助，西医主导】
  ⚠️ HbA1c >8%，有并发症 → 西药为主，炁脉辅助
  ⚠️ 1型糖尿病 → 胰岛素不可替代，炁脉辅助并发症预防

【紧急转西医】
  🔴 血糖>300 mg/dL + 酮症症状 → 急诊
  🔴 严重低血糖（<54 mg/dL）→ 急诊
  🔴 糖尿病足感染/溃疡 → 专科处理
```

### 2.6 糖尿病五维定级参考

| 西医指标 | 对应炁维 | 对应毒维 | 对应脉维 | 对应邪维 | 对应瘾维 |
|---------|---------|---------|---------|---------|---------|
| HbA1c <6.5% | 炁4 | — | — | — | — |
| HbA1c 6.5-7.5% | 炁5 | — | — | — | — |
| HbA1c 7.5-9% | 炁6 | 毒5 | — | — | — |
| HbA1c >9% | 炁7 | 毒6 | — | — | — |
| 有并发症 | 炁7 | 毒6 | 脉6 | 邪6 | — |
| 胰岛素抵抗严重 | — | 毒7 | 脉7 | 邪5 | 瘾5（饮食依赖） |

## 三、高血压（ACC/AHA 2017 + AACE共识）

### 3.1 血压分类

| 分类 | 收缩压 | 舒张压 |
|------|--------|--------|
| 正常 | <120 | <80 |
| 升高 | 120-129 | <80 |
| **1级高血压** | 130-139 | 80-89 |
| **2级高血压** | ≥140 | ≥90 |

### 3.2 治疗目标

| 患者类型 | 目标血压 |
|---------|---------|
| **一般患者** | <130/80 mmHg |
| **老年人（>65岁）** | <130/80（AACE）或 <150/90（宽松） |
| **糖尿病+高血压** | <130/80 |
| **CKD+高血压** | <130/80 |

### 3.3 药物选择（基于并发症）

| 患者类型 | 首选药物 | 说明 |
|---------|---------|------|
| **一般患者** | 噻嗪类利尿剂 / ACEI / ARB / CCB | 四选一 |
| **冠心病/心衰** | ACEI/ARB + β受体阻滞剂 | 保护心功能 |
| **糖尿病** | ACEI/ARB（首选） | 保护肾脏 |
| **CKD+蛋白尿** | ACEI/ARB（首选） | 降蛋白尿 |
| **黑人患者** | 噻嗪类/CCB（首选） | ACEI/ARB单用效果较差 |
| **妊娠期** | 拉贝洛尔 / 硝苯地平 / 甲基多巴 | **禁用ACEI/ARB** |

### 3.4 高血压的炁脉介入时机

```
【炁脉可以主导】
  ✅ 血压升高（120-139/80-89）→ 生活方式+炁脉调理，3个月观察
  ✅ 1级高血压，无并发症，年轻患者 → 尝试3-6个月炁脉，监测血压
  ✅ 药物副作用明显（咳嗽/水肿/乏力）→ 炁脉辅助减药

【炁脉辅助】
  ⚠️ 2级高血压 → 西药降压+炁脉调理体质
  ⚠️ 已有靶器官损害 → 西药为主，炁脉辅助

【紧急转西医】
  🔴 血压≥180/120 + 症状（头痛/胸痛/视力模糊）→ 高血压急症，急诊
  🔴 妊娠期高血压 → 产科紧急评估
```

## 四、乳腺结节/乳腺癌筛查（NCCN指南框架）

### 4.1 乳腺影像报告系统（BI-RADS）

| BI-RADS | 评估 | 恶性概率 | **处理** |
|---------|------|---------|---------|
| **0** | 需补充评估 | — | 补充影像 |
| **1** | 阴性 | 0% | 常规筛查 |
| **2** | 良性 | 0% | 常规筛查 |
| **3** | 可能良性 | <2% | **6个月复查** |
| **4** | 可疑 | 2-95% | **活检** |
| **5** | 高度可疑 | ≥95% | **活检+治疗** |
| **6** | 已确诊恶性 | — | 治疗 |

### 4.2 乳腺结节的炁脉介入时机

```
【炁脉可以主导】
  ✅ BI-RADS 2-3级 → **炁脉主导调理**，定期复查
  ✅ 乳腺增生/纤维腺瘤 → **炁脉核心适应证**
  ✅ 术后调理/预防复发 → **炁脉核心工作**

【必须西医评估】
  ⚠️ BI-RADS 4级及以上 → 活检明确诊断
  ⚠️ 乳头溢液（尤其血性）→ 立即专科检查
  ⚠️ 皮肤橘皮样改变/乳头内陷 → 立即排除恶性
```

## 五、急症红线（必须立即转西医）

| 系统 | 急症表现 | 处理 |
|------|---------|------|
| **心血管** | 胸痛+出汗+放射痛 | 立即急诊（心梗） |
| **心血管** | 血压≥180/120 + 症状 | 急诊（高血压急症） |
| **内分泌** | 血糖>300 + 酮症 | 急诊（DKA） |
| **内分泌** | 低血糖<54 + 意识障碍 | 急诊 |
| **甲状腺** | 甲状腺肿大+呼吸困难 | 急诊（压迫气道） |
| **肿瘤** | 不明原因消瘦+夜间盗汗 | 尽快排查（淋巴瘤等） |
| **神经** | 突发偏瘫/失语 | 立即急诊（卒中） |

## 六、使用说明

### 6.1 四医合诊中的西医角色

```
【炁脉医学不是替代西医，是找到最佳协作点】

西医负责：
  ✓ 明确诊断（影像/病理/实验室）
  ✓ 急症处理（手术/急救/重症监护）
  ✓ 标准治疗（药物/放疗/化疗）
  ✓ 监测指标（定期复查/随访）

炁脉负责：
  ✓ 体质调理（五维定级→54牌方案）
  ✓ 预防复发（术后/缓解期修复体质）
  ✓ 减毒增效（减轻西药副作用）
  ✓ 生活方式（时辰/饮食/运动/心理）
  ✓ 瘾维干预（情绪/行为模式重塑）

协作原则：
  - 诊断不明时 → 西医先明确
  - 急症危险时 → 西医先处理
  - 慢性调理时 → 炁脉主导
  - 术后康复时 → 炁脉核心
```
