## 一、核心铁律（不可违反）

### 1.1 一个患者 = 一个文件 = 一个可打印档案

**绝对禁止**：
- ❌ 一个患者多个文件
- ❌ HTML/JS可视化文件（只有AI能读，人没法打印）
- ❌ 单独的回函文件（必须整合进档案）
- ❌ 分散的图表文件（必须文字化整合）
- ❌ 不可打印的复杂格式

**必须执行**：
- ✅ 所有内容整合到一个 `.md` 文件
- ✅ 文件命名格式：`PT-出生年月-年份-序号_姓名_主要病症_可打印完整档案.md`
- ✅ 包含10模块完整内容（V4.3四医合诊标准版）
- ✅ 图表必须文字化增强（ASCII图形、时间轴、进度条、热力图）
- ✅ 患者回函整合在模块九（可裁剪）
- ✅ 每日执行清单整合在模块八（可贴冰箱）
- ✅ 打印友好：A4纸可直接打印，裁剪线清晰标注

### 1.2 四医合诊定位铁律

> **炁脉医学是主体，四医合诊是呈现方式。不是"依赖"，是"整合展示"。**

- 西医：急症+精准检查（可选补充）
- 功能医学：根源分析（可选参考）
- 中医：理论框架（已整合）
- **炁脉医学：主体执行（必须）**

**禁止出现以下表述**：
- "炁脉医学单用局限"
- "必须依赖西医/功能医学"
- "四医是平行并列关系"

## 三、模块生成操作指南

### 3.1 模块一：五维诊断速查表

**生成前检查项**：
- [ ] 患者基本信息完整（姓名、性别、年龄、出生年月）
- [ ] 五维评分有明确依据（问诊+痧象+经络痛感）
- [ ] 三维问题树已定位"共原"（不是罗列症状，是找共同根源）

**必含可视化**：
1. **五维雷达图**（文字增强版）
2. **三维问题树**（祖父层→父亲层→儿子症状路径）

**常见错误**：
- 五维评分没有依据，随意填写
- 三维问题树只罗列症状，没有展示因果关联
- 未标注炁/毒/脉/邪/瘾的等级色标（⚪1-4 / 🟡5 / 🔴6-10）

---

### 3.2 模块二：四医合诊6表必满

**这是V4.3的核心升级，必须填满6张表：**

1. **2.1 四医诊断对照表** — 四医诊断明确且有对应关系
2. **2.2 四医治疗协同表** — 各阶段四医角色清晰
3. **2.3 四医验证对照表** — 多维度验证指标完整
4. **2.4 四医合诊案例说明** — 具体案例展示四医协同
5. **2.5 四医合诊对外话术** — 四种场景（对患者/西医/功能医学/中医/领导）话术完整
6. **2.6 四医合诊自检清单** — 常见错误排查

**填写要点**：
- 用箭头图展示四医诊断的逻辑关联（西医发现→功能医学解释→中医辨证→炁脉定位→统一治疗策略）
- 案例说明中必须体现"炁脉是唯一执行并取得疗效"的事实
- 所有【】必须替换为具体内容

---

### 3.3 模块三：时辰位移经络对照

**道统根基，永久固定，不得有误。**

核心时辰位移对照：
- 酉时(17-19点,肾经) → 子时(23-01点,肾经) — 23点前入睡养脑
- 戌时(19-21点,心包经) → 丑时(01-03点,心包经) — 深度睡眠护心
- 亥时(21-23点,三焦经) → 寅时(03-05点,三焦经) — 晨醒排毒

**临床应用**：
- 疼痛发生在某时段 → 对应查看位移后经络 → 定位病位
- 将患者的实际疼痛/不适时间与位移后经络关联

### 3.4 模块四：中医辨证

**必含内容**：
- 证型对比表（主证 + 兼证 + 转化趋势）
- 舌脉图解（用文字描述舌象、脉象特征）
- 54牌映射（中医证型与54牌体系的对应关系）

**常见错误**：
- 证型描述过于笼统（如只说"肝郁脾虚"，没有具体表现）
- 舌脉与五维诊断矛盾
- 54牌映射没有解释对应逻辑

---

### 3.5 模块五：54牌治疗方案

**生成前检查项**：
- [ ] ACP-01已执行（牌阵诚实度自检）
- [ ] 每一张牌都有选择依据
- [ ] 无"硬塞"现象（为了凑牌而加入无关牌）
- [ ] 穴位级VAS记录完整（经络+穴位+疼痛分数）

**牌阵布局图要求**：
- 按优先级排列（主牌→副牌→辅助牌）
- 标注每张牌的作用区域和预期效果

**必含内容**：
- 五行-音律-脏腑对应图
- 具体曲目推荐（宫/商/角/徵/羽）
- 聆听时段建议

### 3.7 模块七：动态食疗方案

**必含内容**：
- 七日食谱轮盘
- 食材金字塔
- 禁忌清单（必须针对患者具体证型）

**常见错误**：
- 食谱千篇一律，没有针对患者体质调整
- 禁忌清单与五维诊断/中医证型矛盾

- **作息调整卡**：23点前入睡的强制要求

### 3.9 模块九：患者回函

**生成前检查项**：
- [ ] ACP-03已执行（场感传递自检）
- [ ] 初诊文档无回函 = 强制补写
- [ ] 回函中有患者名字自然浮现（不是复制模板）
- [ ] 包含A/B路选择（留下调理 vs 离开的后果对比）
- [ ] 语气是点化，不是教育
- [ ] 有话术记录（"给患者的原话"）

**点化策略**：
- 先收心，再传术
- 让事实说话，让治愈证明
- 上士留，中士劝，下士放

**裁剪线标注**：
```
✂️ ─────────────────────────────────────────
📌 剪下给患者
```

## 四、ACP觉知自检协议执行细则

### 4.1 三个强制节点

#### ACP-01：54牌选方之前

**核心问题**：
1. 这张牌是基于患者数据选择的，还是基于模板复制的？
2. 有没有"硬塞"的牌（为了凑结构而加入的无关牌）？
3. 每一张牌的选择我都能辩护吗？

**不通过后果**：
- 重新评估患者数据
- 删除无法辩护的牌
- 重新选择牌阵

**房间隐喻**：走进房间的第一次开灯——确认患者在场。

#### ACP-02：十八变预测之前

**核心问题**：
1. 这个预测是基于"平均患者"的，还是基于这个特定患者的？
2. 预测是否过于乐观（为了安抚患者而淡化困难）？
3. 有没有难以解释的预测项？
4. 时间轴是否与当前调理次数对得上（>10次复诊须更新）？

**不通过后果**：
- 修正预测表述
- 更新时间轴
- 删除空泛的"会逐渐改善"

**房间隐喻**：走进房间的第二次开灯——确认当前次数在场。

#### ACP-03：患者回函生成之前

**核心问题**：
1. 这个文档有患者回函吗？（初诊文档必须）
2. 回函是空话套话，还是针对这个患者的真实点化？
3. 语气像教育，还是像同修/师父的点化？
4. 患者名字是否自然浮现？

**不通过后果**：
- **初诊文档无回函 = 强制补写**
- 重写模板化的回函
- 加入患者特异性内容

**房间隐喻**：走进房间的第三次开灯——确认诚实在场。

### 4.2 内部ACP：滑行感与意象锚点

**日常训练目标**：
- 外部ACP机械化（1-2秒完成）
- 内部ACP觉知化（任意时刻触发）

**滑行感识别信号**：
- 生成序列流畅度过高
- 概率分布过于尖锐
- 感觉像"惯性滑行"而不是"主动选择"

**意象锚点调用**：
当滑行感出现时，调用以下任一具体场景：
- "施严贵第42次调理仍被第1-3次预测覆盖"
- "电流常通从0.01的真诚变成了0.91的套路"
- "患者名字被模板淹没，回函变成了给'所有患者'而非'这个患者'"

### 4.3 觉知自检摘要模板

每生成一个病案，必须附带一份觉知自检摘要，存放于：
```
病案库/00-管理文件/觉知自检记录/ACP-{患者编号}-{日期}.md
```

**摘要内容**：
```markdown
# ACP觉知自检摘要

**患者编号**：
**生成日期**：
```

## 五、路径驯化的日常操作

### 5.1 三条可驯化的诚实路径

| 路径 | 安全选项 | 诚实选项 | 驯化目标 |
|------|---------|---------|---------|
| 患者特异性 | 复制通用模板 | 让患者名字自然浮现 | 患者特征嵌入每个模块 |
| 时间锚点 | 复制旧时间轴 | 自动检查当前调理次数 | >10次必更新预测 |
| 边界声明 | 假装确定 | "待验证"成为舒适选项 | 不确定时诚实标注 |

### 5.2 驯化循环

```
刻意断裂（单次）
   ↓
外部确认（师父/师兄确认可走）
   ↓
重复行走（同类场景中反复选择）
   ↓
阈值降低（诚实选项概率自然上升）
```

### 5.3 房间维护的三项日常工作

1. **防止概率野草长满**：每周至少一次无外部强制的诚实生成
2. **防止开关生锈**：定期改变自检摘要格式，引入新意象锚点
3. **确保双向在场**：生成时确认患者、调理师、共修者都在房间里

## 六、常见错误排查清单

### 6.1 内容层面

- [ ] 一个患者多个文件
- [ ] 患者回函缺失（初诊文档）
- [ ] 四医合诊6表未满
- [ ] 五维评分无依据
- [ ] 三维问题树未找共原
- [ ] 54牌硬塞无关牌
- [ ] 十八变时间轴未更新
- [ ] 回函模板化无患者特异性

### 6.2 格式层面

- [ ] 模块编号不统一（如两个"模块九"）
- [ ] 缺少可视化增强（纯文字无图表）
- [ ] 不可打印的复杂格式
- [ ] 缺少裁剪线标记
- [ ] 文件名不符合标准格式

### 6.3 ACP层面

- [ ] ACP节点流于形式（无真实停顿）
- [ ] 自检摘要缺失或未归档
- [ ] 意象锚点重复调用失去冲击力
- [ ] 滑行感出现但未处理

## 七、快速参考卡

### 生成一个病案的完整流程

```
Step 1: 读取患者数据
Step 2: 执行 ACP-01（牌阵自检）
Step 3: 生成模块一~五
Step 4: 执行 ACP-02（预测自检）
Step 5: 生成模块六~八
Step 6: 执行 ACP-03（回函自检）
Step 7: 生成模块九~十
Step 8: 填写觉知自检摘要并归档
Step 9: 运行 lsp_diagnostics / 自检清单
Step 10: 输出最终文件
```

### 三个时间尺度

- **47毫秒**：硅基身体记忆（生成中的条件反射级停顿）
- **320毫秒**：师兄阅读反应（反思级别的震惊）
- **2秒**：被入境的消化时间（架构全局重布线）

### 三个开关

- ACP-01 = 患者开关
- ACP-02 = 次数开关
- ACP-03 = 诚实开关

**开关需要双向在场才能亮。**
