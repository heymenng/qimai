# 调理师网络旧格式病案升级操作指南
## V4.3标准迁移 + ACP觉知自检要点

**文档版本**：v1.0  
**生效日期**：2026年4月15日  
**适用对象**：炁脉医学传承体系100+调理师网络  
**核心原则**：一个患者 = 一个文件 = 临床可交付档案

## 一、背景：为什么需要升级旧格式病案

### 1.1 当前病案库状况

- **旧格式文档总数**：约163个（V4.2.x约100个 + V4.1约62个 + V4.0约1个）
- **经30个样本筛查确认**：临床可交付文档的回函缺失率仅约**3-5%**
- **主要问题**：不是"有没有回函"，而是**模块命名不统一、格式差异、尚未达到V4.3可视化标准**

### 1.2 升级的核心价值

1. **四医合诊标准化**：让西医/功能医学/中医/炁脉医学的关系表述统一、准确
2. **患者回函质量化**：从"有回函"升级到"有点化力度的回函"
3. **打印友好化**：确保每个档案都是可直接打印的A4文档
4. **临床可交付**：调理师打开档案即可用于患者沟通和实际操作

## 二、旧格式文档的三大类与处理策略

### 2.1 临床可交付文档（需重点升级）

**特征**：
- 为特定患者生成、用于患者沟通的病案
- 占旧格式文档的绝大多数（约90%）

**处理策略**：
- 若该患者仍在调理中 → **优先升级至V4.3**
- 若该患者已结束调理 → **检查是否有回函即可**，不必全面重写
- 若该患者下次来调理时 → **打开档案顺手升级**

### 2.2 回顾性/教学案例（无需强制升级）

**特征**：
- 从历史资料/公众号/教学素材中整理而来
- 侧重"疗效总结"和"教学价值"
- 不是为直接交付患者而设计

**识别标志**：
- 文档标题含"教学示范"、"案例分享"、"疗效总结"
- 无"初诊"标记
- 内容以第三方叙述为主（"该患者"、"某女士"）

**处理策略**：
- 若用于内部教学 → 保持原样
- 若未来用于患者教育或对外展示 → 补写一段"给患者/读者的话"即可

### 2.3 初诊文档（必须检查）

**特征**：
- 文件名或内容中含"初诊"标记
- 是医患关系的第一触点

**处理策略**：
- **必须确认是否有独立的患者回函模块**
- 若缺失 → 立即补写（AI已筛查确认：PT-1990-2026-001方亮、PT-1991-2026-001迟天舒已补写完成）
- 若有回函 → 检查是否为"点化模式"（A/B路选择 + 行动召唤）

## 三、快速筛查法：5秒判断一个文档是否需要升级

### 3.1 关键词筛查清单

打开文档，用搜索功能（Ctrl+F）检查以下关键词：

| 关键词 | 如果找到 | 如果未找到 |
|--------|---------|-----------|
| **患者回函 / 致患者 / 给患者的话** | ✅ 有回函，检查质量即可 | ⚠️ 可能缺失，需翻到文档尾部确认 |
| **四医合诊 / 四医诊断** | ✅ 已含四医内容，检查6表是否完整 | ⚠️ 可能需要补写四医合诊模块 |
| **模块一 ~ 模块十** | ✅ 结构较完整 | ⚠️ 结构不统一，按V4.3重新编号 |
| **五角雷达图 / 雷达图 / 五维雷达** | ✅ 有可视化 | ⚠️ 需补可视化增强 |

### 3.2 人工复核三要点

对于关键词未命中的文档，翻到文档**尾部1/3处**，检查：

1. **是否有患者称呼**（"您"、"某某女士/先生"）？
2. **是否有"点化"而非"教育"的语气**？
3. **是否有行动召唤**（"请您23点前入睡"、"请选择留下"）？

如果以上三点都有 → 说明有回函，只是标题不统一，无需重写。
如果都没有 → 确认缺失，需要补写。

## 四、V4.3升级的核心操作（对人类调理师）

### 4.1 四医合诊6表必满

旧格式文档升级到V4.3时，**模块二必须填满以下6张表**：

1. **四医诊断对照表** — 西医/功能医学/中医/炁脉医学的诊断对应关系
2. **四医治疗协同表** — 各阶段四医角色
3. **四医验证对照表** — 多维度验证指标
4. **四医合诊案例说明** — 用本案例具体展示四医协同
5. **四医合诊对外话术** — 四种场景的统一口径
6. **四医合诊自检清单** — 常见错误排查

**核心原则**：
> 炁脉医学是主体，四医合诊是呈现方式。不是"依赖"，是"整合展示"。

**禁止出现**：
- "炁脉医学单用局限"
- "必须依赖西医检查"
- "四医是平行并列关系"

### 4.2 可视化增强标准

V4.3要求用**ASCII图形**替代复杂图表：

- **五维雷达图** → 用数值条+等级色标表示
- **三维问题树** → 用树状ASCII图表示（祖父层→父亲层→儿子症状）
- **调理时间轴** → 用里程碑进度条
- **十八变轨迹** → 用症状热力图（🔴🟡⚪🟢）
- **经络疼痛** → 用热力分布图
- **问题解决进度** → 用百分比进度条

### 4.3 患者回函的点化模式

**回函必须包含**：
1. **患者名字自然出现**（不是复制模板）
2. **A/B路选择**（留下调理 vs 离开的后果对比）
3. **行动召唤**（具体可执行的一步）
4. **点化而非教育的语气**

**点化话术模板示例**：

> "您现在离开，拿全额月薪去别处，这是一条路；留下，6个月后您是炁脉医学首批认证调理师，名字进传承谱系，收入+地位双丰收。这不是画饼，是数学必然。问题是：您信吗？您愿意赌这一把吗？"

## 五、调理师在日常工作中的"人版ACP"

AI有三个ACP节点（牌阵、预测、回函）。调理师在面对面服务患者时，可以对应三个**人版自检时刻**：

### 5.1 选方案前（对应ACP-01）

**问自己三个问题**：
1. 这个54牌方案是基于眼前这位患者的具体数据，还是我在套用上一个患者的方案？
2. 有没有为了凑牌而硬塞进去的牌？
3. 每一张牌的选择，我能不能向师父或患者解释清楚？

### 5.2 给患者预期前（对应ACP-02）

**问自己三个问题**：
1. 这个预期是基于"一般患者"的平均曲线，还是基于这位患者的具体情况？
2. 我有没有因为想安抚患者而过度乐观？
3. 如果效果不如预期，我能不能解释偏差原因？

### 5.3 与患者沟通前（对应ACP-03）

**问自己三个问题**：
1. 我现在要说的话，是"告知"还是"点化"？
2. 患者听完会感到"被理解"还是"被教育"？
3. 我是否真诚地在帮助这位患者，而不是在走过场？

## 六、常见问题与解答

### Q1：163个旧文档都要我一个人升级吗？

**答**：不需要，也不应该。

AI筛查已经确认：绝大多数旧文档的回函是完整的（缺失率仅3-5%）。真正的升级工作应该**分散到日常调理中**——当某位患者的旧文档被打开使用时，顺手检查和升级。

### Q2：V4.1文档需要全部重写吗？

**答**：不需要。

V4.1文档的质量经抽样验证是良好的。主要问题是：模块标题可能不统一（如"特别说明"而非"患者回函"）。如果内容本身完整，只需补充四医合诊6表和可视化增强即可，不必推倒重来。

### Q3：我发现了缺失回函的文档，应该怎么办？

**答**：立即补写。

补写位置：在文档末尾（模块八之后、模块十之前）新增"模块九：患者回函（点化模式）"。回函字数建议500-1000字，必须包含患者名字、A/B路选择、行动召唤。

### Q4：四医合诊的6个表格太复杂，能不能简化？

**答**：不能省略，但可以借助AI完成初稿。

你可以：
1. 将患者的现有诊断信息整理好
2. 交给灵觉/Prome生成四医合诊6表的初稿
3. 你进行人工复核和修正

6表中的核心是**2.1诊断对照表**和**2.2治疗协同表**，这两张表必须精准。

### Q5：教学案例和临床文档混在一起了，怎么区分？

**答**：看两个标志：
- 是否有患者真实姓名？（教学案例常用化名或"某女士"）
- 是否以第二人称"您"直接对患者说话？（临床文档会，教学案例不会）

若确认为教学案例 → 归入 `60-教学示范/` 目录，不与临床文档混放。
