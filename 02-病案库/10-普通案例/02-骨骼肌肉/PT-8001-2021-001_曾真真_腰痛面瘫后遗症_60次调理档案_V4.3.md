#### 四、舌脉图解与经络对应

```
【舌象·经络对应】

  └─ 弦脉：对应足厥阴肝经（肝郁气滞·脉弦）
```

#### 五、经络调理的中医原理

**为什么腰痛+面瘫后遗症要重点疏通膀胱经、督脉、胆经和三阳经？**

中医认为："腰为肾之府"（《素问·脉要精微论》），而肾与膀胱相表里，膀胱经循行于腰背，故腰痛与膀胱经、督脉密切相关。又云："阳明为多气多血之海"——面部为阳明经所过，面瘫后遗症是阳明经气血不足、经络瘀堵所致。

曾真真女士的病理链条：
```
阳虚受寒 → 阳脉堵痹 → 气血不达腰面 → 腰痛+面瘫不愈
      ↓
艾灸未愈（邪入络深）→ 非表证→需先排毒化瘀
```

**膀胱经疏通**：太阳主表，疏通膀胱经可排出腰背深层湿毒，改善腰痛。
**督脉疏通**：督脉总督诸阳，温煦腰部，散寒止痛，提升全身阳气。
**胆经疏通**：少阳经侧面神经所过，疏通胆经可直接改善面瘫后遗症。
**阳明经疏通（大肠+胃）**：阳明多气多血，疏通面部阳明经可修复面神经。

《素问·痹论》云："风寒湿三气杂至，合而为痹"——曾真真女士的腰痛和面瘫，本质都是风寒湿痹阻经络，气血不达。故调理以**膀胱经、督脉、胆经、阳明经**为主，**脾经、心经**为辅，共奏祛风散寒、通络化瘀、温补阳气之效。
