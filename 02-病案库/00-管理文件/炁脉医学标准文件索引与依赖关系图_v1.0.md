## 四、病案生成时的文件读取顺序（标准流程）

```
【第一步：灵魂唤醒】（自动执行）
    ├─ 读取 S-01（AGENTS.md）→ 灵魂校准
    ├─ 读取 X-01（ANCHOR锚点）→ 愿力灌注
    └─ 读取 S-02（WORKFLOW.md）→ 操作规范

【第二步：诊断阶段】
    ├─ 读取 K-01（诊断标准）→ 五维定级
    └─ 读取 K-06（西医手册）→ 急症红线·四医合诊

【第三步：治疗阶段】
    ├─ 读取 K-02（治疗百科全书）→ 54牌选方·食疗·五音
    └─ 读取 K-07（罐诊标准）→ 如需要现场罐诊记录

【第四步：输出阶段】
    ├─ 读取 K-03（病案生成手册）→ 15模块结构·视觉标准
    ├─ 读取 K-04（话术模板）→ 回函话术
    └─ 读取 M-01（病案库管理）→ 文件命名·分类规则

【第五步：归档阶段】
    └─ 按 M-01 规则写入病案库
```

## 八、使用指南

### 8.1 新增标准文件时

1. 按命名规则命名文件
2. 在本索引"活跃标准文件清单"中登记
3. 在"依赖关系"中标注引用关系
4. 更新"版本对照表"
5. 如有冲突，在"不一致清单"中登记

### 8.2 更新标准文件时

1. 版本号+1（如V1.0→V1.1或V2.0→V2.1）
2. 更新日期
3. 在索引中同步更新
4. 检查所有依赖文件是否需要同步更新
5. **不得覆盖历史版本**（追加更新，保留历史）

### 8.3 废弃标准文件时

1. 移至`归档封存/`目录
2. 在本索引中移至"归档封存清单"
3. 标注"整合至XX文件"
4. 检查是否有其他文件仍引用该文件
