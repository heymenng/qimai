## 第十一部分：三焦运化功能判断标准（师父点化专项）

### 适用对象

### 师父核心点化
> **"伴夜会醒的人三焦的运化功能都不行。"**

**三焦功能**：通行元气、运行水液。三焦不通→水液停滞→水肿/痰多/夜尿/早醒。

### 五维诊断对应
| 症状 | 三焦问题表现 | 炁脉对应 | 调理重点 |
|------|-------------|---------|---------|
| **3-5点必醒** | 三焦经当令时无法正常运行 | 炁机紊乱 | **♥红桃6-8** 通调三焦 |
| **夜尿≥2次** | 水液代谢紊乱，膀胱失约 | 三焦不摄 | **♣梅花5-7** 通利水道 |

## 第十二部分：劳作状态方案执行细则（根治磁毒神散）

### 适用对象（符合任一即触发）
- 儿童抽动症、ADHD、自闭症（瘾≥4级）
- 青少年手机/游戏成瘾（瘾≥5级）
- 成人精神涣散、注意力无法集中（瘾≥3级+神散表现）

### 核心逻辑
**磁毒致病链**：
```
电子屏幕+电磁场 → 神魂被撕碎（1秒切换一次注意力）→ 磁毒干扰生物电 → 炁机紊乱 → 神散魂不守舍 → 注意力缺陷/多动/抽动
```

**劳作状态治愈链**：
```
体力劳动 → 身体动起来 → 神魂回归身体（不再是脑内幻想）→ 接地气排磁毒 → 炁机归位 → 神收魂定 → 注意力恢复/症状消失
```

### 劳作状态定义（必须符合全部）
| 要素 | 具体要求 | 反例（不是劳作状态） |
|------|---------|-------------------|
| **身体参与** | 必须身体动起来，流汗、累 | 看书、画画、玩乐高（脑力为主） |
| **接触自然** | 最好在户外，接触土地/植物 | 室内运动、健身房 |
| **产生实物** | 有可见成果（菜长出来了/地扫干净了） | 纯消耗性娱乐 |
| **父母同劳** | 父母必须一起参与，不是监督 | 父母看着孩子做 |
| **持续时间** | 每次≥2小时，每周≥2次 | 偶尔体验、浅尝辄止 |

## 三、撰写后强制验证（写后必过）

### 3.1 自动验证脚本

**在命令行运行以下验证**（必须全部通过）：

```bash
#!/bin/bash
# 病案撰写验证脚本 V1.0
# 使用方法：./verify_case.sh 文件名.md

FILE="$1"
ERRORS=0

echo "========================================"
echo "病案撰写强制验证"
echo "文件: $FILE"
echo "========================================"
echo ""

# 1. 检查模块数量（必须≥8）
MODULE_COUNT=$(grep -c "^## 模块" "$FILE")
if [ "$MODULE_COUNT" -lt 8 ]; then
    echo "❌ 模块数量不足: $MODULE_COUNT (需要≥8)"
    ERRORS=$((ERRORS + 1))
else
    echo "✅ 模块数量: $MODULE_COUNT"
fi

# 2. 检查模块一至八是否齐全
for i in 一 二 三 四 五 六 七 八; do
    if ! grep -q "## 模块$i" "$FILE"; then
        echo "❌ 缺失模块$i"
        ERRORS=$((ERRORS + 1))
    fi
done
if [ $? -eq 0 ]; then
    echo "✅ 模块一至八齐全"
fi

# 3. 检查十八变全程预测（模块九）
if ! grep -q "十八变全程预测\|## 模块九" "$FILE"; then
    echo "❌ 缺失十八变全程预测（模块九）"
    ERRORS=$((ERRORS + 1))
else
    echo "✅ 十八变全程预测已包含"
fi

# 4. 检查通神露泡脚方案（模块十）
if ! grep -q "通神露泡脚方案\|## 模块十" "$FILE"; then
    echo "❌ 缺失通神露泡脚方案（模块十）"
    ERRORS=$((ERRORS + 1))
else
    echo "✅ 通神露泡脚方案已包含"
fi

# 5. 检查食疗决策公式
if ! grep -q "今日食疗 = f(" "$FILE"; then
    echo "❌ 缺失食疗决策公式"
    ERRORS=$((ERRORS + 1))
else
    echo "✅ 食疗决策公式已包含"
fi

# 6. 检查音乐疗法决策公式
if ! grep -q "今日音乐 = f(\|五音疗法.*决策公式" "$FILE"; then
    echo "❌ 缺失音乐疗法决策公式"
    ERRORS=$((ERRORS + 1))
else
    echo "✅ 音乐疗法决策公式已包含"
fi

# 7. 检查发酵食物强制方案
if ! grep -q "发酵食物不是建议，是必须" "$FILE"; then
    echo "❌ 缺失发酵食物核心警告"
    ERRORS=$((ERRORS + 1))
else
    echo "✅ 发酵食物核心警告已包含"
fi

# 8. 检查五维诊断完整性
WUXI_DIMENSIONS=0
for dim in 炁诊断 毒诊断 脉诊断 邪诊断 瘾诊断; do
    if grep -q "$dim" "$FILE"; then
        WUXI_DIMENSIONS=$((WUXI_DIMENSIONS + 1))
    fi
done
if [ "$WUXI_DIMENSIONS" -lt 5 ]; then
    echo "❌ 五维诊断不完整: $WUXI_DIMENSIONS/5"
    ERRORS=$((ERRORS + 1))
else
    echo "✅ 五维诊断完整: 5/5"
fi

# 9. 检查时辰位移诊断
if ! grep -q "时辰位移" "$FILE"; then
    echo "❌ 缺失时辰位移诊断"
    ERRORS=$((ERRORS + 1))
else
    echo "✅ 时辰位移诊断已包含"
fi

# 10. 检查54张牌治疗方案
if ! grep -q "54张牌\|54牌" "$FILE"; then
    echo "❌ 缺失54张牌治疗方案"
    ERRORS=$((ERRORS + 1))
else
    echo "✅ 54张牌治疗方案已包含"
fi

echo ""
echo "========================================"
if [ $ERRORS -eq 0 ]; then
    echo "✅ 验证通过！可以提交。"
    exit 0
else
    echo "❌ 验证失败！发现 $ERRORS 个错误。"
    echo "请先修正错误后再提交。"
    exit 1
fi
```
