## 第一步：判断严重程度（决定一级分类）

### 检查清单（按优先级排序）

| 检查项 | 如果符合 | 归入分类 |
|--------|---------|---------|
| **是否有肿瘤征兆？** | 肿瘤标志物异常/肿块/癌症术后 | **30-特殊档案/肿瘤相关/** |
| **炁虚级别≥7级？** | 炁虚7-10级，生命垂危 | **30-特殊档案/极虚急救/** |
| **是否为出家人？** | 佛教/道教出家人、寺院住持 | **30-特殊档案/高僧大德/** |
| **是否特级保密？** | 知名人士、敏感身份 | **30-特殊档案/特级案例/** |
| **是否为急症？** | 需立即处理，生命体征不稳 | **40-急救重症/** |
| **是否疑难复杂？** | 多系统疾病、久治无效 | **20-疑难杂病/** |
| **是否为内部人员？** | 调理师、员工、家属 | **50-自己人/** |
| **是否为教学案例？** | 典型案例、痊愈示范 | **60-教学示范/** |
| **以上都不是** | 常规慢性病 | **10-普通案例/**（进入第二步） |
### 多分类情况处理规则

**当案例同时符合多个特殊分类时，按以下优先级存放**：

| 优先级 | 分类 | 存放方式 |
|--------|------|----------|
| **1（最高）** | 30-特殊档案/极虚急救/ | 主档案存放 |
| **2** | 30-特殊档案/肿瘤相关/ | 主档案存放 |
| **3** | 40-急救重症/ | 主档案存放 |
| **4** | 20-疑难杂病/ | 主档案存放 |
| **5** | 30-特殊档案/高僧大德/ | 引用标记* |
| **5** | 30-特殊档案/特级案例/ | 引用标记* |
| **6** | 60-教学示范/ | 引用标记* |

**\*引用标记**：在身份类目录中创建引用文件，指向主档案位置

**示例**：
- 光泉大和尚 = 出家人 + 炁虚7级 → 主档案存极虚急救，高僧大德目录留引用
- 某明星癌症患者 = VIP + 肿瘤 → 主档案存肿瘤相关，特级案例目录留引用

    ↓

    ↓
3. 移动文件到正确文件夹

    ↓

## 常见错误

| 错误 | 正确 |
|------|------|
| ❌ 儿童患者按病种归入其他分类 | ✅ 所有14岁以下一律归入 10-儿童/ |
| ❌ 肿瘤术后归入普通案例 | ✅ 所有肿瘤相关一律归入 30-特殊档案/肿瘤相关/ |
| ❌ 高僧大德按病种分类 | ✅ 所有出家人一律归入 30-特殊档案/高僧大德/ |
| ❌ 极虚案例归入普通案例 | ✅ 炁虚7级以上一律归入 30-特殊档案/极虚急救/ |
| ❌ 多系统疾病随意选一个病种 | ✅ 疑难复杂病例归入 20-疑难杂病/ |
