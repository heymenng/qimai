## 二、每天必做六件事（30分钟搞定）

### 【第一件事】通神露泡脚（每晚20:00·10分钟）

> **师父点化**："泡脚不是建议，是底线。坐着就能出汗排毒，是保命之法。"

| 项目 | 标准 |
|------|------|
| **配方** | 艾叶15g + 生姜30g + 红花10g（煮水） |
| **水温** | 38-40℃（用手腕内侧试，温热不烫） |
| **时间** | 15-20分钟 |
| **出汗量** | 后背微微出汗 |
| **水位** | 没过脚踝，到小腿肚 |

**操作步骤**：
1. 准备一个小盆，倒入煮好的药水
2. 加温水调到38-40℃
3. 子栎把脚放进去，边泡边讲故事/听音乐
4. 泡到后背微微出汗
5. 擦干脚，立刻穿袜子

**给子栎的游戏**：
> "子栎，每天泡脚就是'打败湿气怪兽'。泡到出汗，就是怪兽被打跑了！泡完可以吃一颗红枣奖励自己。"

**注意事项**：
- ❌ 饭后1小时内不泡
- ❌ 泡后不洗澡、不吹风
- ❌ 水温不可超过40℃（儿童皮肤嫩）

### 【第二件事】穴位点按（睡前·5分钟）

**每天按3个穴位，每个1分钟**

#### ① 足三里（强壮穴·健脾）

| 项目 | 内容 |
|------|------|
| **定位** | 膝盖下面，外膝眼下4横指（子栎的4个手指宽） |
| **作用** | 让孩子吃饭香、长个子 |
| **手法** | 用大拇指轻轻按，顺时针揉1分钟 |
| **感觉** | 有点酸胀就对了 |

**给子栎的游戏**：
> "子栎，这是'强壮穴'。每天按一按，你就会长得像大树一样高！"

#### ② 百会穴（聪明穴·安神）

| 项目 | 内容 |
|------|------|
| **定位** | 头顶正中，两个耳朵尖连线的中点 |
| **作用** | 让孩子聪明、睡觉好 |
| **手法** | 用手掌轻轻揉1分钟 |
| **感觉** | 头皮发热、放松 |

**给子栎的游戏**：> "子栎，这是'聪明穴'。每天揉一揉，上课更专心！"

#### ③ 太冲穴（开心穴·降火）

| 项目 | 内容 |
|------|------|
| **定位** | 脚背，大脚趾和二脚趾之间的缝隙，往上推，摸到凹陷处 |
| **作用** | 让孩子不那么爱发脾气 |
| **手法** | 用大拇指从脚趾缝往脚踝方向推1分钟 |
| **感觉** | 有点酸胀或疼（说明堵，越堵越要推） |

**给子栎的游戏**：> "子栎，这是'开心穴'。每天推一推，脾气就变小啦！"

### 【第四件事】金刚呼吸（睡前·3分钟）

**最简单的方法：数呼吸**

1. 子栎躺在床上
2. 闭上眼睛
3. 慢慢吸气，数到4
4. 慢慢呼气，数到6
5. 重复10次

**给子栎的游戏**：> "子栎，这是'吹蜡烛'游戏。吸气像闻花香，呼气像吹蜡烛，看谁吹得慢！"

### 【第五件事】拍打通脉（隔日1次·5分钟）

**每天拍3个地方**

| 部位 | 怎么拍 | 拍多久 | 感觉 |
|------|--------|--------|------|
| **后背** | 家长用空心掌，从肩膀拍到腰 | 2分钟 | 后背发热 |
| **大腿外侧** | 从髋部拍到膝盖 | 每侧1分钟 | 腿发热 |
| **手臂外侧** | 从肩膀拍到手腕 | 每侧1分钟 | 手臂轻松 |

**注意事项**：
- 力度：轻轻拍，像拍灰尘一样
- 时间：早上起床后或下午
- 禁忌：饭后1小时内不拍

**给子栎的游戏**：> "子栎，这是'拍拍打打'游戏。每天拍一拍，把身体里的'堵堵虫'赶跑！"

### 【第六件事】吃对的食物（每餐·最重要！）

**这是六件事里最重要的！**

#### 每天必吃的食物

| 餐次 | 吃什么 | 为什么 |
|------|--------|--------|
| **早餐** | 山药小米粥 + 老面馒头 + 蒸南瓜 | 山药健脾，小米养胃，南瓜补中益气 |
| **上午加餐** | 核桃2个 + 植物酸奶150ml | 核桃补肾健脑，植物酸奶补益生菌 |
| **午餐** | 糙米饭 + 清蒸鱼/鸡肉 + 炒青菜 | 鱼肉补蛋白质，青菜补维生素 |
| **下午加餐** | 黑豆芝麻糊（无糖） | 黑豆补肾助长，黑芝麻补精血 |
| **晚餐** | 小米粥 + 豆腐/蒸蛋 + 凉拌黄瓜 | 小米养胃，豆腐易消化 |

#### 助长身高的"明星食物"

| 食物 | 作用 | 怎么吃 |
|------|------|--------|
| **山药** | 健脾益胃，助营养吸收 | 每天早餐吃，蒸/煮粥 |
| **黑豆** | 补肾益精，促进骨骼生长 | 打豆浆或煮粥 |
| **核桃** | 补肾健脑 | 每天2-3个 |
| **黑芝麻** | 补肝肾，益精血 | 每天1勺，加入粥中 |
| **虾皮** | 补钙佳品 | 撒在粥或汤中 |
| **深绿色蔬菜** | 维生素K，助钙沉积骨骼 | 每天1份 |

#### ⚠️ 绝对不能吃的食物（三条底线）

❌ **牛奶及奶制品**——子栎过敏，越喝鼻炎越重、越长不高
❌ **冷饮**——冰淇淋、冰饮料、从冰箱拿出来的酸奶（必须放到常温）
❌ **辛辣刺激**——辣椒、辣条、烧烤、花椒——越吃肝火越旺、越爱流鼻血
❌ **甜食**——糖果、蛋糕、含糖饮料——越吃脾胃越困、越不想吃饭

**给家长的提醒**：
> "这三条底线，一条都不能妥协。子栎哭闹要喝牛奶、要吃冰淇淋的时候，请想想他的背上那片紫黑色的痧。现在的心软，就是对他身体的伤害。用燕麦奶替代牛奶，用常温水果替代冷饮，用蒸南瓜替代蛋糕。"
