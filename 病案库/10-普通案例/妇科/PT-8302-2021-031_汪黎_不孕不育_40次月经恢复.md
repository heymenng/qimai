### 4.2 五维分析

**核心病机**：
```
脉（6级）道瘀阻 → 输卵管堵塞/切除 + 颈腰椎病变
    ↓
毒（6级）聚胞宫 → 内膜息肉 + 卵巢囊肿 + 盆腔积液
    ↓
炁（5级）虚血少 → AMH下降 + 月经紊乱 + 不孕
    ↓
瘾（4级）神浮 → 长期熬夜 + 心神不宁 → 进一步耗伤气血
```

**病因溯源**：

**第一层：结构性问题（脉维度）**
- 2010年、2016年两次异位妊娠 → 输卵管病变
- 颈腰椎间盘突出 → 督脉、膀胱经瘀阻 → 影响生殖轴

**第二层：功能性问题（炁维度）**
- 长期熬夜（12点睡）→ 耗伤肝血、肾精
- 手术损伤 → 气血亏虚
- 慢性炎症 → 持续耗炁

**第三层：器质性病变（毒维度）**
- 湿毒内阻 → 内膜息肉、卵巢囊肿
- 血瘀胞宫 → 月经紊乱

**治疗优先级**：
1. **第一优先：通脉（♦方块6-7）**——颈腰椎疏通，改善督脉、膀胱经
2. **第二优先：排毒（♠黑桃6-7）**——胞宫湿毒，清理息肉囊肿环境
3. **第三优先：补气（♥红桃5-6）**——提升AMH，恢复卵巢功能
4. **第四优先：祛邪（♣梅花3-4）**——慢性咽炎，清除余邪
5. **第五优先：安神（♥红桃4-5）**——调整作息，养心助眠
