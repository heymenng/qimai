# 第二模块：多医学对比分析

## 2.1 现代医学视角

| 项目 | 内容 |
|------|------|
| **诊断** | ①高血压病 ②甲状腺术后 ③腰痛（退行性改变/外伤后） ④周围神经病变（足麻） |
| **病理机制** | 老年血管硬化，甲状腺激素缺乏，腰椎退变，神经损伤 |
| **治疗方案** | ①降压药终身服用 ②甲状腺激素替代 ③止痛药/理疗 ④营养神经药物 |
| **治疗周期** | 终身服药控制 |
| **预后** | 症状可控制，但无法根治，逐年加重 |
| **局限性** | 分科治疗，只见树木不见森林，药物副作用累积 |

## 2.2 传统中医视角

| 项目 | 内容 |
|------|------|
| **诊断** | 脾肾两虚，湿毒内蕴，瘀血阻络，肝肾不足 |
| **病理机制** | 年高肾亏，脾失健运，湿毒内生，瘀血阻络，筋脉失养 |
| **治疗方案** | 健脾补肾，祛湿化痰，活血通络，滋养肝肾 |
| **代表方剂** | 金匮肾气丸、独活寄生汤、补阳还五汤加减 |
| **局限性** | 汤药长期服用不便，老年脾胃功能弱，吸收有限 |

## 2.3 炁脉医学视角（核心）

| 项目 | 内容 |
|------|------|
| **诊断** | 老年复命期炁虚毒重脉堵型 |
