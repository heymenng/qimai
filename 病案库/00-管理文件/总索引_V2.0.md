## 二、归类决策速查

```
新患者初诊
    ↓
是否有肿瘤征兆/癌症？ → 是 → 30-肿瘤科/
    ↓ 否
是否为高僧大德/宗教人士？ → 是 → 50-特殊档案/
    ↓ 否
是否为炁虚7级以上/生命垂危？ → 是 → 20-疑难重症/
    ↓ 否
是否为疑难复杂/多系统疾病？ → 是 → 20-疑难重症/
    ↓ 否
是否为中风后遗症？ → 是 → 40-中风康复/
    ↓ 否
是否为急症/需立即处理？ → 是 → 20-疑难重症/
    ↓ 否
是否为调理师/内部人员？ → 是 → 50-特殊档案/
    ↓ 否
是否为经典教学案例？ → 是 → 60-教学示范/
    ↓ 否
是否为不孕调理成功生育？ → 是 → 70-药王宝贝/
    ↓ 否
└── 归入 10-普通案例/（按病种细分）
```

### 2.1 儿童患者特殊规则
- **14岁以下**：优先归入 10-普通案例/07-儿童/
- **14-18岁**：可归入对应病种，但需在档案中标注"青少年"
