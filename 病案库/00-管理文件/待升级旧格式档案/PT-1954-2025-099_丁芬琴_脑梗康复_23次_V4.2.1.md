## 模块八：通神露泡脚方案（必做）

### 8.1 方案说明
泡脚可温经散寒，促进血液循环，改善肢体麻木。

### 8.2 标准方案
| 项目 | 标准 |
|------|------|
| **频率** | 每日1次 |
| **时间** | 20:00-20:30 |
| **时长** | 30分钟 |
| **水温** | 42℃ |

### 8.3 中风后专用通神露配方

**基础配方**：艾叶30g + 红花15g + 生姜50g + 花椒20g + 益母草30g + 丹参20g

**加减配方**：
- 中风后：川芎15g + 天麻15g
- 高血压：钩藤20g + 夏枯草15g
- 肢体麻木：牛膝15g + 桑枝20g
- 寒湿重：独活15g + 威灵仙15g

**丁芬琴专用配方**：
```
基础方：艾叶30g + 红花15g + 生姜50g + 花椒20g + 益母草30g + 丹参20g
加味：  川芎15g + 天麻15g + 钩藤20g + 夏枯草15g + 牛膝15g + 桑枝20g + 
       独活15g + 威灵仙15g
────────────────────────────────────────────────────────────────────
总计：约325g/剂，可分4-5次使用
```

### 8.4 操作流程
1. 煮药：药材装入纱布袋，加水2500ml，煮沸后转小火煮20分钟
2. 调温：药液倒入泡脚桶，加冷水调至40-45℃
3. 泡脚：水位至小腿肚，泡20-30分钟，以微微出汗为度
4. 收功：泡完后擦干，穿上袜子保暖

### 8.5 禁忌
- ❌ 空腹或饭后1小时内
- ❌ 血压过高时（>180/110mmHg）
- ❌ 头晕头痛剧烈时
- ❌ 皮肤破损、感染时
