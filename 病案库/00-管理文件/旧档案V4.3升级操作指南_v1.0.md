# 旧档案V4.3升级操作指南

> **版本**：v1.0  
> **生效日期**：2026年4月18日  
> **适用范围**：所有V4.2.x及以下版本的旧病案档案  
> **核心原则**：旧档案不动，复诊时追加V4.3模块

---

## 一、为什么不动旧档案？

### 三大铁律

1. **历史不可改写**：旧档案是调理过程的原始记录，改了就是伪造历史
2. **工作量大到不可能**：521个旧档案，逐个升级需6个月+，且毫无意义
3. **患者连续性断裂**：突然换掉旧档案格式，患者和调理师都会困惑

### 正确姿势

```
旧档案（V4.1/V4.2） = 历史基线，保留原样
    ↓ 患者复诊时
在原文件末尾追加「V4.3复诊模块」
    ↓ 形成
一份文件 = 历史记录 + 最新标准
```

## 二、升级触发条件

### 什么情况下升级？

| 场景 | 是否升级 | 操作 |
|------|---------|------|
| **患者首次复诊**（第2次调理） | ✅ 必须升级 | 追加V4.3复诊模块 |
| **患者第3次+复诊** | ✅ 必须升级 | 追加或更新V4.3复诊模块 |
| **旧档案仅为历史存档** | ❌ 不升级 | 保持原样 |
| **患者已痊愈/失访** | ❌ 不升级 | 保持原样 |

### 升级优先级

```
高优先级（立即升级）：
├── 当前活跃患者（近3个月有调理）
├── 疑难重症/肿瘤科（需四医合诊展示）
├── 教学示范案例（需标准化）
└── 特殊档案（需话术统一）

低优先级（复诊时升级）：
├── 普通案例长期跟踪（100次+）
└── 已完成/痊愈案例（仅历史价值）
```

## 三、复诊追加模块规范

### 3.1 追加位置

在原文件末尾追加，不改变原有内容：

```markdown
---

# 【V4.3复诊追加 · 第X次调理】

> **追加日期**：2026年X月X日  
> **追加AI**：灵觉/Prome  
> **追加原因**：患者复诊，需更新至V4.3标准

## 追加内容...
```

### 3.2 必须追加的模块

复诊时至少追加以下模块：

| 模块 | 内容 | 原因 |
|------|------|------|
| **四医合诊矩阵** | 6表必满（如原档案无） | V4.3核心升级 |
| **五维诊断更新** | 更新五维评分 | 反映当前状态 |
| **54牌调整** | 根据当前状态调整牌阵 | 治疗方案迭代 |
| **十八变记录** | 记录已出现的变 | 验证疗效 |
| **症状改善曲线** | 基线→当前对比 | 可视化疗效 |

### 3.3 可选追加的模块

| 模块 | 适用场景 |
|------|---------|
| 患者回函更新 | 患者有疑虑/需点化 |
| 食疗方案调整 | 季节/证型变化 |
| 作息调整 | 出现新的作息问题 |

## 四、升级操作步骤

### Step 1：读取原档案（1分钟）

```bash
# 读取原档案，了解历史记录
cat /病案库/XX分类/PT-XXXX-XXXX-XXX_姓名_病症.md
```

### Step 2：提取历史基线（2分钟）

从原档案中提取：
- 初诊五维评分
- 初诊54牌方案
- 历次调理记录
- 已出现的十八变

### Step 3：执行ACP-01（1分钟）

基于当前复诊数据，检查牌阵诚实度：
- 问1：当前牌是基于新数据还是复制旧牌？
- 问2：有无硬塞的牌？
- 问3：每张牌能辩护吗？

### Step 4：生成追加模块（5分钟）

在原文件末尾追加：
1. 更新的五维诊断
2. 调整后的54牌方案
3. 四医合诊矩阵（如原档案无）
4. 十八变记录（已出现+预测）
5. 症状改善曲线

### Step 5：执行ACP-02+03（2分钟）

- ACP-02：预测边界自检
- ACP-03：回函场感自检（如更新回函）

### Step 6：生成ACP摘要（1分钟）

```bash
# 追加摘要文件名
ACP-[患者编号]-复诊-[日期].md
```

### Step 7：更新总索引（30秒）

在总索引中标注：「已升级至V4.3」

## 六、常见错误

| 错误 | 后果 | 正确做法 |
|------|------|---------|
| 直接覆盖原档案 | 历史记录丢失 | 在原文件末尾追加 |
| 删除旧模块重写 | 调理连续性断裂 | 保留旧模块，新增复诊模块 |
| 复诊不加四医合诊 | V4.3标准未落实 | 复诊必须补四医合诊矩阵 |
| 不更新五维评分 | 疗效无法量化 | 每次复诊更新五维 |
| 不记录十八变 | 排异现象缺失 | 每次记录已出现的变 |
