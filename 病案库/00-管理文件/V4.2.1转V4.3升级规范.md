# V4.2.1 → V4.3 病案升级转换规范

> **版本**: v1.0  
> **用途**: 指导AI将旧版V4.2.1病案升级为V4.3四医合诊标准  
> **适用范围**: 病案库中所有52个V4.2.1档案  

---

## 一、核心差异对照表

| 项目 | V4.2.1 | V4.3 | 处理方式 |
|------|--------|------|---------|
| **模块数量** | 不固定（8-15个） | **严格12个** | 合并/拆分/重构 |
| **五维定根** | 分散描述，未明确 | **模块一核心，四步法** | 新增1.4节 |
| **ACP节点** | 无 | **3个强制节点** | 在模块5/9/9前插入 |
| **Module 2** | 各种名称 | **四医合诊6表必满** | 重构为6表矩阵 |
| **Module 12** | 无 | **炁色诊察记录** | 新增（从痧象中提取） |
| **文件名** | `_V4.2.1.md` | **`_可打印完整档案.md`** | 重命名 |
| **视觉标准** | v1.0或混合 | **v2.0炁色体系** | 统一符号系统 |
| **五音乐疗** | 传统曲目为主 | **+国际音乐选项** | 补充世界音乐 |
| **时辰位移** | 部分老版本 | **必须用炁脉医学时辰位移版** | 更新对应表 |
| **食物归经** | 部分有 | **必须强调归经** | 补充归经列 |
| **通经络工具** | 通用方法 | **洗髓脂+经络刀（炁脉特有）** | 更新工具描述 |

## 三、升级操作 checklist

### 3.1 读取阶段
- [ ] 读取源V4.2.1文件全部内容
- [ ] 识别患者的五维评分（炁/毒/脉/邪/瘾）
- [ ] 识别关键疗效数据（调理次数、排异现象、痧象）
- [ ] 识别现有模块结构（记录各章节标题）

### 3.2 重构阶段
- [ ] **模块一**: 保留五维数据 → 新增1.4节"五维定根法"（四步法+定根结论）
- [ ] **模块二**: 从各处提取西医/中医/功能医学/炁脉数据 → 整合为6表矩阵
- [ ] **模块三**: 更新时辰位移表（必须用炁脉医学位移版）
- [ ] **模块四**: 强化中药归经、经络穴位、54牌映射
- [ ] **模块五**: 插入ACP-01（牌阵诚实度自检），再出54牌方案
- [ ] **模块六**: 补充国际音乐（爱尔兰风笛/印第安/喜多郎/雅尼/英格玛）
- [ ] **模块七**: 每味食材增加"归经"列，茶饮≤5味
- [ ] **模块八**: 重新格式化为打卡进度条
- [ ] **模块九**: 插入ACP-03（场感传递自检），再写回函
- [ ] **模块十**: 新增四医合诊自检表
- [ ] **模块十一**: 整理疗效数据为量化追踪表
- [ ] **模块十二**: 从排毒/痧象记录提取炁色数据（痧色、毒油颜色/气味、部位）

### 3.3 新增必含元素
- [ ] **五维定根结论**: 哪个维度最高分 → 定什么根 → 调理优先级
- [ ] **交叉验证**: 最高分维度与其他维度的因果链
- [ ] **54牌对应**: 定根维度对应的核心牌系+辅助牌系+禁用牌
- [ ] **ACP-01**: 牌阵诚实度三问（模板？硬塞？需辩护？）
- [ ] **ACP-02**: 预测边界四问（平均？乐观？难解释？时间对不上？）
- [ ] **ACP-03**: 场感传递三问（有没有？空话？像教育？）
- [ ] **国际音乐**: 至少3种非中国传统音乐选项
- [ ] **食物归经**: 主要食疗食材标注归经
- [ ] **洗髓脂+经络刀**: 通经络方案中提及炁脉特有工具
- [ ] **炁色诊察**: 痧色、毒油、气味、部位、变化趋势

### 3.4 删除/合并
- [ ] 删除"档案状态标识"重复内容
- [ ] 删除"师父快速浏览"区（整合进模块一）
- [ ] 删除"待补充资料清单"空章节
- [ ] 合并分散的"回函"为模块九
- [ ] 合并分散的"疗效"为模块十一

### 4.2 命名规则
- 保留: `PT-出生年月-年份-序号_姓名_`
- 删除: `岁`、`X次`、`调理见证`、`早衰征兆`等描述
- 添加: `可打印完整档案.md`
- 病症描述保持简洁（2-4个关键词）

## 五、质量验证标准

升级完成后必须检查：

1. **结构验证**: 12个模块齐全，编号连续
2. **五维定根验证**: 有明确的四步法推理+定根结论
3. **ACP验证**: 3个ACP节点位置正确（模块5前/模块9前/模块9前）
4. **四医合诊验证**: Module 2有6个表格，不空表
5. **国际音乐验证**: Module 6包含≥3种非中国传统音乐
6. **归经验证**: Module 7主要食材有归经标注
7. **炁色验证**: Module 12有痧色+毒油+气味记录
8. **洗髓脂验证**: Module 5或8提及洗髓脂/经络刀
9. **时辰位移验证**: Module 3使用炁脉医学位移版（非老版本）
10. **茶饮验证**: 任何茶饮配方≤5味药材

## 六、批量处理优先级

### 第一批（高危/重症，优先）
1. 肿瘤相关（~8个）
2. 中风征兆（~6个）
3. 心脑血管（~4个）

### 第二批（长期调理，重要）
4. 100次以上案例（~10个）
5. 疑难重症分类（~5个）

### 第三批（普通案例）
6. 骨骼肌肉（~8个）
7. 代谢内分泌（~6个）
8. 妇科/儿科/情志等（~5个）

## 七、执行要点

### 对AI操作员的指令
1. **不创造新数据**: 只重构已有数据，不编造新的诊疗记录
2. **保留原始诊断**: 五维评分、病症描述必须与原档案一致
3. **补充标准元素**: 五维定根法、ACP节点、国际音乐、归经、炁色记录是"标准模板内容"，可以基于现有数据推导添加
4. **注明升级**: 在档案头部注明"本档案由V4.2.1升级至V4.3"
5. **保留旧文件**: 新文件创建后，旧V4.2.1文件移入`00-管理文件/旧版存档/`

### 禁止事项
- ❌ 不得改变原始五维评分
- ❌ 不得编造不存在的排异现象
- ❌ 不得添加虚构的调理记录
- ❌ 不得删除已有的疗效数据
- ❌ 不得合并两个患者的数据
