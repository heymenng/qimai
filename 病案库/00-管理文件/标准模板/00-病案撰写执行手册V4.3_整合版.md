## 第三部分：师父核心点化汇总（按主题分类）

### 主题1：儿童磁毒神散根治法

> **师父原话**："这类的孩子自闭症也好，多动症也好，磁毒影响的这些孩子只有父母带着孩子回到劳作状态下的生活方式，才能彻底根除，加上炁脉的调理。"

**核心解读**：
- 不是简单的断电，是生活方式的根本转变
- 劳作状态 = 身体动起来的体力劳动，不是脑力劳动
- 父母带头 = 不是只要求孩子，父母要一起劳作
- 炁脉调理+劳作生活 = 双管齐下，才能根治

**劳作状态定义**（5要素）：
1. **身体参与**：必须身体动起来，流汗、累
2. **接触自然**：最好在户外，接触土地/植物
3. **产生实物**：有可见成果（菜长出来了/地扫干净了）
4. **父母同劳**：父母必须一起参与，不是监督
5. **持续时间**：每次≥2小时，每周≥2次

**病案撰写要求**：
- 所有涉及儿童磁毒神散的病案，必须包含劳作状态方案
- 必须给家长两个选择（A路/B路）
- 必须预告前2周的戒断反应

### 主题2：三焦运化功能诊断

> **师父原话**："伴夜会醒的人三焦的运化功能都不行。"

**诊断标准**：
- 半夜3-5点必醒者
- 夜尿频繁者（每晚≥2次）
- 晨起水肿、面部浮肿者
- 痰多、水液代谢紊乱者

**三焦功能**：通行元气、运行水液。三焦不通→水液停滞→水肿/痰多/夜尿/早醒。

**五维对应**：
- 半夜3-5点醒 = 三焦经当令时无法正常运行
- 调理重点：**♥红桃6-8** 通调三焦

**病案撰写要求**：
- 所有涉及夜醒/夜尿的患者，必须包含三焦运化说明
- 必须给患者两个选择（A路不管/B路调理）

### 主题3：时辰位移诊断法

**核心规则**：时辰位移约6小时，原时辰的功能移至新时间。

**诊断逻辑**：
1. 问患者："您几点睡？几点起？半夜醒吗？几点醒？"
2. 对表格：看"现在的实际时间"列→找到对应经络→看"身体反应机理"
3. 出判断：
   - 23点不睡 → 伤肾（不是伤胆）→ 腰膝酸软/健忘/耳鸣
   - 05-07点不起 → 伤胆（不是补肾）→ 头痛口苦/决策力差
   - 半夜3-5点醒 → 三焦运化不行 → 水肿/痰多/代谢差

### 主题4：炁虚分级与炁荡法则

**关键原则：炁虚7级以上，必须先炁荡，后排毒通脉！**

| 炁虚级别 | 治疗顺序 |
|---------|---------|
| 1-3级 | 可直接排毒/通脉 |
| 4-6级 | ♥红桃5-6打底 → 排毒/通脉 |
| 7-8级 | **♥红桃8-9炁荡** → 排毒/通脉 → 固本 |
| 9-10级 | **♥红桃8-10强力炁荡** → 排毒/通脉 → 固本 |

**核心心法**：
> "炁虚7级+，如灯油将枯。此时拨灯芯（排毒）或修灯座（通脉），都会加速油尽灯灭。必须先添油（炁荡唤醒），让火焰重新旺起来，再清理灯罩（排毒），最后稳固灯座（固本）。"

### 主题5：五维诊断强制标准

**评估原则**：逐条对照，快速定级，不可误判

**五维评估标准**（简化速查表）：

**炁（生命能量）**：
- 1-3级：精力充沛/轻度乏力 → 维持/调整作息
- 4-6级：明显乏力/动则气喘 → ♥红桃5-7
- 7-8级：动辄气喘卧床仍累 → **♥红桃8-9炁荡**
- 9-10级：气息奄奄昏迷嗜睡 → **♥红桃9-10+J急救**

**毒（代谢废物）**：
- 1-3级：大便正常/偶有便秘 → 调整饮食
- 4-6级：经常便秘/舌苔黄腻 → ♠黑桃5-7
- 7-8级：实体肿瘤/肝硬化 → ♠黑桃7+药物/♠J-Q-K
- 9-10级：全身转移/恶病质 → **A-2急救**

**脉（能量通道）**：
- 1-3级：无疼痛/偶有酸胀 → ♦方块3-4
- 4-6级：持续隐痛/僵硬如板 → ♦方块5-7
- 7-8级：结构变形（如肋骨断裂） → ♦方块8-9
- 9-10级：肢体坏死/脉绝 → ♦方块K/A

**邪（外来致病因素）**：
- 1-3级：无外感/轻微感冒 → ♣梅花3-4
- 4-6级：邪入脏腑/炎症反复 → ♣梅花5-7
- 7-8级：败血症/神昏谵语 → ♣梅花8-9
- 9-10级：深度昏迷/阴阳离决 → ♣梅花K/**A急救**

**瘾（精神依赖/空窗）**：
- 1-3级：情绪稳定/偶有走神 → ♥红桃3-5
- 4-6级：严重手机依赖/物质依赖 → ♥红桃5-7 + **断磁毒方案**
- 7-8级：严重精神障碍/自杀倾向 → ♥红桃8-10+J
- 9-10级：植物人状态/脑死亡边缘 → **A-2急救**
