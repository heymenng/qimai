## 三、具体手法与顺序（标准流程）

### 3.1 调理顺序

1. **俯卧位**：背部（心肺区、肝区排毒）→ 腰部 → 腿部 → 足底 → 头部
2. **仰卧位**：头部 → 手部（手三阳、三焦经）→ 腿部（胆经、胃经）→ 腹部

### 3.2 重点部位与手法

| 部位 | 手法 | 时长 | 重点说明 |
|------|------|------|---------|
| **背部心肺区** | 疏理+热推 | 15分钟 | 观察是否有黑色/白色颗粒、絮状物 |
| **背部肝区** | 疏理+排毒 | 10分钟 | 肝经排毒通道，继续观察酒气/黏腻感 |
| **督脉** | 热推搓热 | 5分钟 | 升阳核心，必须搓热 |
| **腰部膀胱经** | 热推+按揉 | 15分钟 | VAS仍5分，重点疏通，观察腰部排异 |
| **肩颈** | 热推+拿肩 | 10分钟 | VAS已降至3分，可适度加强 |
| **头部** | 疏理 | 10分钟 | 敲头后观察眼睛反应（流泪=肝经排毒） |
| **手三阳经** | 疏理 | 5分钟 | VAS降至2分，疼痛最轻，说明改善显著 |
| **大腿胆经** | 按揉+疏理 | 10分钟 | VAS仍5分，中期瘀堵未清，持续疏通 |
| **小腿膀胱经** | 疏理 | 10分钟 | VAS降至4分，继续疏通 |
| **足底** | 点痛+按揉 | 5分钟 | 观察足底是否发痒（阳气通达反应） |
| **红丸艾灸** | 艾灸30分钟 | 30分钟 | **必做**。观察热传导范围、肠鸣音 |

2. 评估是否需要恢复服用红丸
