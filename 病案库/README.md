## 一、核心铁律（不可违反）

### 1.1 一个患者 = 一个文件（绝对禁止多个文件）

**绝对禁止**：
- ❌ 一个患者多个文件
- ❌ 主档案 + 回函文件分开存放
- ❌ 按日期拆分多个版本
- ❌ 重复内容分散在不同文件

**必须执行**：
- ✅ 所有内容整合到一个文件
- ✅ 回函作为档案的一个章节（第10章"行罐后调整"）
- ✅ 所有修改在原文件内更新
- ✅ 删除任何多余的副本

**错误示例**（已纠正）：
```
❌ PT-81XX-2026-005_小彬_肩颈不适+心阳预警.md
❌ PT-81XX-2026-005_小彬_回函（行罐后调整）.md  
❌ PT-81XX-2026-005_小彬_回函（完整版）.md
```

**正确示例**：
```
✅ PT-81XX-2026-005_小彬_肩颈不适+心阳预警.md（唯一文件，包含所有内容）
```

### 1.2 内容去重规范

**禁止重复**：
- ❌ 同一内容出现2次以上
- ❌ "师父心法"重复引用
- ❌ "档案状态"重复出现
- ❌ "下次调理"重复出现
- ❌ "附件清单"重复出现
- ❌ 空章节、空标题

**精简原则**：
- 内容说一次即可
- 重要内容放在最相关章节
- 删除"待整理"标记（如无实际内容）

**固化提醒**（每次建档必看）：
> "一个患者一个文件，回函内嵌不单独，内容精简不重复，所有更新在原档。"

### 6.3 通神露泡脚方案模板（必含）

每个案例必须包含以下章节：

```markdown
## 十、通神露泡脚方案

### 10.1 方案说明

**适用对象**：所有炁脉调理客户（无论能否早睡）

**核心原则**：
- 作息调整是首选，通神露泡脚是保底
- 做不到早睡，就必须泡脚；能做到早睡，也要泡脚
- 在这个毒的时代，泡脚是底线

### 10.2 标准方案

| 项目 | 标准 | 患者实际情况 |
|------|------|-------------|
| **频率** | 每日1次或隔日1次 | |
| **时间** | 睡前1小时（22:00左右） | |
| **时长** | 20-30分钟 | |
| **水温** | 40-45℃ | |
| **水位** | 没过脚踝，至小腿肚 | |

### 10.3 通神露配方

**基础配方**：
- 艾叶 30g —— 温经散寒
- 红花 15g —— 活血化瘀
- 生姜 50g —— 温阳散寒
- 花椒 20g —— 温中止痛
- 益母草 30g —— 活血调经
- 丹参 20g —— 活血化瘀

**加减配方**（根据患者体质）：
- 湿气重者：+ 薏苡仁 30g、茯苓 20g
- 寒气重者：+ 肉桂 10g
- 失眠者：+ 夜交藤 30g、合欢皮 20g
- 高血压者：+ 钩藤 20g、夏枯草 15g

### 10.4 患者执行确认

- [ ] 已理解通神露泡脚的必要性
- [ ] 已掌握泡脚的时间、温度、时长要求
- [ ] 已购买或准备药材
- [ ] 已确定每日泡脚的具体时间
- [ ] 知晓禁忌（空腹、饭后立即、皮肤破损等）

### 10.5 话术记录

**给患者的原话**：
> "您工作繁忙，23点前睡确实困难。那就必须通神露泡脚——坐着也能出汗排毒，替代早睡的排毒效果。这不是建议，是底线。"

> "这个时代是毒的时代，人人身处毒中。不出汗，毒就积在体内。通神露泡脚，就是让您坐着也能出汗排毒，这是保命之法。"
```
