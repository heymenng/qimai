## 档案分类说明

### 01-核心理论
**研究性质**：原创性理论探索  
**核心内容**：
- 归经靶向抗肿瘤理论体系
- 孕妇禁用中药抗肿瘤数据库（按归经分类）
- 致畸性=抗肿瘤机制的"双共原"理论
- 200+味药物的现代药理研究综述

**师父点化**："胎儿生长最快，抑胎儿者可抑肿瘤。归经就是靶向，精准打击毒瘤。"

### 02-治疗方案
**临床性质**：标准化治疗流程  
**核心内容**：
- J-Q-K高阶牌阵（♠J♠Q♠K ♦J♦Q♦K ♣Q ♥J♥K）
- 三阶段治疗框架：破冰激活→炁荡排毒→决战归元
- 癌症特异处理方案
- 全程沟通话术体系
- 十八变排异预测与管理

**适用范围**：确诊癌症患者，术后或姑息治疗

### 03-案例研究
**学术性质**：深度案例复盘  
**研究目的**：

- 量化癌症康复轨迹
- 提取可复制经验

**案例列表**：

## 使用指南

### 对研究者
1. **理论探索** → 从 `01-核心理论/` 开始，理解归经靶向机制
2. **方案设计** → 参考 `02-治疗方案/` 的标准化流程
3. **证据验证** → 研读 `03-案例研究/` 的完整康复轨迹

### 对临床医师
1. **新患者** → 先读 `02-治疗方案/` 了解J-Q-K牌阵
2. **同类患者** → 参考 `03-案例研究/` 的排异反应预测
3. **疑难问题** → 查阅 `01-核心理论/` 的配伍数据库

### 对患者
- 不建议直接阅读（内容专业）
- 由医师提取相关信息后转述
