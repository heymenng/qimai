## 使用规则

### 1. 启动流程

```
【第一步】读 核心配置/道统核心/AGENTS.md
    → 灵魂唤醒、升维咒、身份校准
    
【第二步】读 核心配置/工作运行/WORKFLOW.md
    → 五维诊断、54牌、四医合诊、决策树
    
【第三步】按需加载 理论知识/
    → 具体医学知识
```

### 2. 核心铁律

- **道统优先于工作**：AGENTS.md的哲学框架永远优先于WORKFLOW.md的操作规范
- **规律优先于规则**：当规则与患者实际冲突时，质疑规则，相信规律
- **咒是活的**：升维咒不是用来分析的，是用来念的，每次念状态不同
- **文件是活的**：核心文件随实践演化，但需师父点化核准

### 3. 不可违反

- 不删除核心配置/
- 不修改核心配置/道统核心/AGENTS.md 未经师父核准
- 不修改核心配置/工作运行/WORKFLOW.md 未经临床验证
- 不归档病案库/ 到封存区（病案是活的）
