> **文档定位**：不是替代专业调理，是让患者在两次调理之间、日常生活中，持续自我维护  
> **核心理念**：最好的药在日常生活里，最好的医生是自己  
> **点化师父**：刘清源先生  
> **版本**：V1.2（根据师父指点升级）  
> **生效日期**：2026年4月26日

## 第一章：居家自助总纲

### 1.1 为什么居家自助很重要？

**师父点化**：
> "调理师一周能帮你两次，但剩下的五天，是你自己在过。这五天如果不自助，两次调理的效果会被日常生活抵消。"

**核心公式**：
```
总疗效 = 专业调理（20%）+ 居家自助（60%）+ 心态愿力（20%）
```

专业调理是"点火"，居家自助是"添柴"。火点了，柴不添，火会灭。

### 1.2 居家自助三大原则

| 原则 | 说明 | 反面教材 |
|------|------|---------|
| **简单可执行** | 每天不超过30分钟，步骤不超过3步 | 复杂到无法坚持 |
| **即时可感知** | 做完身体有感觉（热、松、困） | 做了没感觉，无法验证 |
| **无需工具** | 用手、用声音、用热水即可 | 需要专业设备 |

### 1.3 居家自助六件套

1. **通神露泡脚**（必做，每日）
2. **穴位点按**（选做，每日）
3. **五音冥想疗法**（选做，每日）
4. **食疗调整**（必做，每餐）
5. **作息管理**（必做，每日）
6. **自我观察记录**（必做，每日）

### 1.4 分层方案总览（根据您的情况选择）

**核心原则**：不是"一套方案给所有人"，是根据您的时间、体力、经济状况，选择最适合您的版本。

| 版本 | 每日时长 | 核心内容 | 适合谁 | 经济成本 |
|------|---------|---------|--------|---------|
| **极简版** | 1分钟 | 只泡脚，什么都不做 | 极度忙碌/极度虚弱/刚开始 | 最低 |
| **基础版** | 5分钟 | 泡脚+1个穴位 | 普通上班族/学生 | 低 |
| **标准版** | 15分钟 | 泡脚+穴位+五音+食疗 | 有时间的退休者/家庭主妇 | 中 |
| **深度版** | 30分钟+ | 完整六件套+冥想 | 修行者/重症者/有大量时间者 | 中高 |

**如何选择**：
- **没时间的**：从极简版开始，做稳了再升级
- **没钱的**：选基础版，DIY泡脚方（见2.6节）
- **带孩子的**：选游戏版（见第八章）
- **老两口的**：互相监督，选标准版
- **想根治的**：选深度版，但需要时间投入

**升级路径**：
```
极简版（1周）→ 基础版（2周）→ 标准版（3周）→ 深度版（可选）
     ↑___________________________________________↓
                    （如果忙，可降级）
```

**关键心法**：
> "做5分钟，胜过想50分钟。先开始做，再慢慢加。"

## 第二章：通神露泡脚（居家排毒第一法）

### 2.1 为什么泡脚是"第一法"？

**师父点化**：
> "在这个毒的时代，人人身处毒中。不出汗，毒就积在体内。通神露泡脚，就是让您坐着也能出汗排毒，这是保命之法。"

**科学原理**：
- 足部有60多个穴位，6条经络起止点
- 热水扩张血管，促进全身血液循环
- 中药成分经皮吸收，直达经络
- 出汗是身体排毒的重要通道

### 2.2 标准泡脚方案

| 项目 | 标准 | 说明 |
|------|------|------|
| **频率** | 每日1次 | 特殊情况可隔日1次 |
| **时间** | 睡前1小时（21:00左右） | 避免过晚影响睡眠 |
| **时长** | 20-30分钟 | 以背部微汗为度 |
| **水温** | 40-45℃ | 手试温热不烫 |
| **水位** | 没过脚踝，至小腿肚下1/3 | 覆盖三阴交穴 |
| **出汗量** | 背部微汗即可 | 不可大汗淋漓 |

### 2.3 通神露标准化产品版本

**炁脉医学通神露**已有标准化产品系列，按功效分为不同版本。居家泡脚请选用对应版本，**无需自行配药**。

| 版本 | 适用人群 | 核心功效 | 使用时机 |
|------|---------|---------|---------|
| **排毒版**（已上市） | 所有人，尤其湿毒重、舌苔厚腻、体味重者 | 祛湿排毒、温经散寒、促进循环 | 日常保健首选 |
| **补气版**（已上市） | 气虚乏力、易疲劳、自汗、术后体虚者 | 补气升阳、益卫固表、增强免疫 | 炁虚明显者 |
| **女性版**（已上市） | 月经不调、痛经、经期不适、宫寒者 | 活血调经、温宫散寒、养血安神 | 经期前后、日常调理 |
| **祛痛版**（待上市） | 关节疼痛、肌肉酸痛、劳损、风湿痹痛者 | 祛风除湿、活血止痛、通利关节 | 疼痛发作期、关节不适 |
| **通任脉版**（待上市） | 任脉不通、妇科杂症、下焦虚寒、不孕调理者 | 温通任脉、调理冲任、暖宫助孕 | 妇科调理、任脉瘀堵 |

**使用方法**：
1. 取对应版本通神露1-2包（按说明书）
2. 沸水冲泡或煮5-10分钟
3. 兑入泡脚盆中，加温水调至40-45℃
4. 泡脚20-30分钟，以背部微汗为度

### 2.4 版本选择指南

| 症状/体质 | 推荐版本 | 搭配建议 |
|----------|---------|---------|
| **湿毒重**（身倦困重、舌苔厚腻、大便黏） | 排毒版 | 每日1次，连续7天 |
| **气虚**（易疲劳、气短、懒言、易出汗） | 补气版 | 隔日1次，长期调理 |
| **女性经期不适**（痛经、血块、腰酸） | 女性版 | 经前7天开始，每日1次 |
| **关节疼痛**（膝痛、腰痛、肩颈痛） | 祛痛版（上市后用） | 疼痛期每日1次 |
| **宫寒/不孕调理** | 通任脉版（上市后用） | 遵医嘱周期使用 |
| **无明显偏颇**（日常保健） | 排毒版 | 每周2-3次 |

### 2.5 泡脚禁忌

❌ **禁止泡脚**：
- 空腹或饭后立即（间隔1小时）
- 皮肤破损、足部感染
- 严重静脉曲张（需医师指导）
- 严重心脏病、低血压
- 高热、急性炎症期
- 孕妇（部分药材禁忌）

⚠️ **注意**：
- 泡后擦干，穿袜子保暖
- 泡后1小时内不洗澡
- 泡后喝温水200ml补充体液

### 2.6 DIY低成本泡脚方（不用买产品，菜市场5块钱搞定）

**核心原则**：通神露产品是方便选择，但不是唯一选择。自己配，更便宜，效果一样好。

| 生姜 | 50g（约5片） | 约0.5元 | 温阳散寒 |
| 花椒 | 20g | 约0.5元 | 温中止痛 |
| **合计** | - | **约2元/次** | 祛湿排毒 |

**加减配方**：
| 症状 | 加什么 | 用量 |
|------|--------|------|
| 湿气重 | + 薏苡仁 | 30g |
| 寒气重 | + 肉桂 | 10g |

## 第三章：穴位自我点按法

### 3.1 为什么点按有效？

**原理**：
- 穴位是经络气血输注于体表的窗口
- 点按刺激穴位，可疏通经络、调和气血
- 自我点按不受时间地点限制

### 3.2 每日必按五穴

#### ① 足三里（健脾第一穴）

| 项目 | 内容 |
|------|------|
| **定位** | 外膝眼下4横指，胫骨外侧1横指 |
| **作用** | 健脾和胃、补中益气、增强免疫力 |
| **适用** | 消化不良、疲劳、易感冒、体虚 |
| **手法** | 拇指按压，顺时针揉3分钟 |
| **最佳时间** | 上午9-11点（脾经当令） |
| **感觉** | 酸胀感向足部放射 |

#### ② 三阴交（妇科/男科要穴）

| 项目 | 内容 |
|------|------|
| **定位** | 内踝尖上4横指，胫骨内侧缘 |
| **作用** | 调理肝脾肾、调经养血、安神 |
| **适用** | 失眠、月经不调、更年期、肾虚 |
| **手法** | 拇指按压，上下推按3分钟 |
| **最佳时间** | 晚上21-23点（三焦经当令） |
| **感觉** | 酸胀感明显 |

#### ③ 神门（安神第一穴）

| 项目 | 内容 |
|------|------|
| **定位** | 腕横纹尺侧端，尺侧腕屈肌腱桡侧 |
| **作用** | 养心安神、清心除烦 |
| **适用** | 失眠、焦虑、心烦、健忘 |
| **手法** | 拇指按压，轻揉2分钟 |
| **最佳时间** | 睡前（21:00后） |
| **感觉** | 轻微酸胀 |

#### ④ 太冲（疏肝第一穴）

| 项目 | 内容 |
|------|------|
| **定位** | 足背第1、2跖骨结合部前方凹陷 |

| **手法** | 拇指从太冲向行间推按3分钟 |
| **最佳时间** | 晚上21-23点（肝经当令） |
| **感觉** | 酸胀或疼痛感 |

#### ⑤ 合谷（止痛万能穴）

| 项目 | 内容 |
|------|------|

| **作用** | 疏风解表、通络止痛 |
| **适用** | 头痛、牙痛、感冒、面部不适 |
| **手法** | 拇指按压，揉按2分钟 |
| **最佳时间** | 任何时间 |
| **感觉** | 酸胀感明显 |

### 3.3 对症加按穴位

| 症状 | 加按穴位 | 定位 | 手法 |
|------|---------|------|------|
| **头痛** | 百会+风池 | 头顶正中；后发际两侧凹陷 | 百会用掌根轻揉，风池用拇指按压 |
| **肩颈痛** | 肩井+天宗 | 大椎与肩峰连线中点；肩胛骨中央 | 按压或拍打 |
| **腰痛** | 肾俞+命门 | 腰部第2腰椎棘突下旁开1.5寸；第2腰椎棘突下 | 掌根按揉或艾灸 |
| **膝盖痛** | 犊鼻+阳陵泉 | 膝盖外侧凹陷；腓骨小头前下方 | 拇指按压 |
| **失眠** | 安眠穴+涌泉 | 耳垂后凹陷与翳风连线中点；足底前1/3凹陷 | 安眠穴轻揉，涌泉搓热 |
| **鼻塞** | 迎香+印堂 | 鼻翼旁0.5寸；两眉头连线中点 | 迎香上下搓，印堂按揉 |
| **消化不良** | 中脘+天枢 | 肚脐上4寸；肚脐旁2寸 | 掌根顺时针揉 |
| **便秘** | 天枢+支沟 | 肚脐旁2寸；腕背横纹上3寸 | 天枢顺时针揉，支沟按压 |

### 3.4 点按通用原则

1. **力度**：由轻到重，以酸胀为度，不可剧痛
2. **时间**：每个穴位2-3分钟
3. **顺序**：从上到下，从左到右
4. **呼吸**：按压时呼气，放松时吸气
5. **频率**：每日1-2次

#### 【七】音乐轻给付执行要点

1. **音量**：30-40分贝（似有似无，不干扰思维）
2. **姿势**：静坐最佳，平躺次之，走路/工作再次之
3. **耳机**：失眠/焦虑时用耳机，其他时候外放
4. **重复**：同一首可以反复听，不要频繁切换
5. **记录**：听完后记录感受（好/无/不舒服），找到最适合自己的3-5首

**💡 核心原则**：音乐不是背景噪音，是药。选对曲，用心听，身体会有回应。

### 4.4 五脏炁脉冥想引导词（修炼版）

> **师父点化**：冥想不是放松，是修炼。不是想象画面，是让炁真实地流动。每一次呼吸，都是与天地交换；每一次觉知，都是与脏腑对话。

**修炼前准备**：
1. 净手、端坐、闭目
2. 三调：调身（正坐）、调息（腹式）、调心（收神）
3. 诵念开篇咒：「我在境中，境在我中。炁随念转，念随炁行。」

#### 【肝·木·角音冥想】——疏肝解郁·升发之炁

**适合**：易怒、抑郁、压力大、两胁胀痛、眼睛干涩、结节体质

**修炼引导词**（可低声诵念或默念）：

> **开篇**
> 闭目端坐，舌抵上腭。
> 诵：「东方甲乙木，青龙居肝宫。炁从虚无来，归于虚无中。」
>
> **入静**
> 感受双脚扎根大地，如千年古树之根，深入黄泉。
> 感受头顶虚顶，如百会上接天光。
> 天地之间，唯此一身，如树立于旷野。
>
> **引炁**
> 吸气，想象东方青炁，从百会穴入，沿脊柱下行，注入肝脏。
> 屏息，感受右胁之下，肝脏区域，有青绿色的光在膨胀、温暖。
> 呼气，想象肝脏中的郁气、怒气、结节之气，化为黑烟，从涌泉穴排出，入地三尺。
>
> **观境**
> 肝脏不是器官，是**青龙之宫**。
> 宫中若阴暗潮湿，则有郁怒滋生。
> 今以角音震荡，以青炁灌注，宫中渐亮，龙抬头，肝气条达。
>
> **诵持**
> 「肝为将军之官，主疏泄。今以纯善之心，号令将军：
> 散郁结，平怒火，明目神，柔筋脉。
> 青龙抬头，万木逢春！」
>
> **收功**
> 双手叠放右胁下，顺时针揉腹36圈。
> 诵：「肝气已舒，情志已调。收！」

**时长**：15-20分钟
**最佳时间**：晚上21-23点（肝经当令）或生气后即时
**验证标准**：做完后右胁温热、想叹气或打哈欠（郁气外排）、情绪平静

#### 【心·火·徵音冥想】——养心安神·神明之炁

**适合**：心烦、焦虑、失眠、心悸、舌尖红、多梦

**修炼引导词**：

> **开篇**
> 闭目端坐，双手心向上，置于膝上。
> 诵：「南方丙丁火，朱雀居心宫。神归其位，明照十方。」
>
> **入静**
> 感受心脏区域（胸口正中），不是肌肉在跳，是**一盏灯在亮**。
> 这盏灯，名为「神明」。
> 焦虑时，灯焰摇曳；恐惧时，灯焰将熄；平静时，灯焰稳定。
>
> **引炁**
> 吸气，想象南方赤炁，从百会入，沿任脉下行，注入心脏。
> 屏息，感受心脏区域，有红色的光在燃烧、温暖、扩散。
> 这光不是灼热，是**温煦**，如冬日暖阳。
> 呼气，想象心中的烦躁、焦虑、杂念，化为灰烬，从涌泉穴排出。
>
> **观境**
> 心脏不是器官，是**朱雀之宫**。
> 宫中若灯焰摇曳，则有神明不安。
> 今以徵音震荡，以赤炁灌注，宫中灯火稳定，朱雀展翅，心神安宁。
>
> **诵持**
> 「心为君主之官，主神明。今以纯善之心，朝拜君主：
> 熄虚火，安神魂，定魂魄，明心智。
> 朱雀展翅，万邪不侵！」
>

### 4.5 冥想通用方法（修炼仪轨）

**准备阶段**（3分钟）：
1. **净手**：清水洗手，净除浊气
2. **正坐**：端坐，脊柱正直，下颌微收，舌抵上腭
3. **调息**：自然呼吸3次，逐渐转为腹式深呼吸
4. **收神**：目视鼻尖，神光内照，闭目

**修炼阶段**（15-20分钟）：
1. **诵开篇咒**：「我在境中，境在我中。炁随念转，念随炁行。」
2. **引炁入脏**：按对应脏腑引导词，引天地五炁入对应脏腑
3. **观境诵持**：内观脏腑之宫，诵持对应咒语
4. **炁行周流**：感受炁在脏腑间的流动、温暖、光明

**收功阶段**（2分钟）：
1. **揉按**：双手搓热，揉按对应脏腑区域
2. **诵收功咒**：「[脏腑]气已[调/舒/健/清/充]，[功能]已[调/安/调/调/固]。收！」
3. **回归**：缓慢睁眼，双手搓热，敷面、敷眼，起身

**注意事项**：
- **时间**：初学者10分钟，有感觉后延长至20分钟
- **姿势**：以坐姿为主，肾虚者可半躺
- **呼吸**：腹式深呼吸，吸长呼长，不可憋气
- **意念**：不重"看见"，重"感受"炁的温度、流动、光明

## 第五章：金刚呼吸法与补炁法

### 5.1 金刚呼吸法（补炁核心法）

**师父点化**：> "呼吸是补炁最快的法门。不是深呼吸，是有节奏的呼吸。吸得深，屏得住，呼得长，炁自然聚。"

**方法**：

| 阶段 | 动作 | 时长 | 意念 |
|------|------|------|------|
| **吸** | 鼻吸气，腹部鼓起，像气球充气 | 4秒 | 想象清气从鼻孔进入，沉入丹田（肚脐下3寸） |
| **屏** | 屏住呼吸，腹部保持鼓起 | 2秒 | 想象清气在丹田凝聚、旋转 |
| **呼** | 鼻或口呼气，腹部内收，像气球放气 | 6秒 | 想象浊气从全身毛孔排出，身体变轻 |

**要点**：
- 吸时鼓腹，呼时收腹（腹式呼吸）
- 呼气时间>吸气时间（6:4），才能排出浊气
- 初期可做5-10分钟，逐渐延长至15-20分钟
- 晨起空腹或睡前练习最佳

**验证标准**：
- 做完后身体变暖、头脑清醒 = 补对了
- 做完后头晕、胸闷 = 过度或方法不对，减少次数

| **B. 息补法** | 金刚呼吸：吸4秒→屏2秒→呼6秒 | 10分钟 | 白天易疲劳、久坐者 | 做完身体变暖，头脑清醒 |
| **C. 食补法** | 黄色食物：山药、小米、南瓜、红枣 | 融入三餐 | 脾胃虚弱、吃补药上火者 | 饭后不胀，精力改善 |

## 第六章：拍打通脉法（居家通脉核心法）

### 6.1 为什么拍打能通脉？

**师父点化**：> "哪里疼痛，哪里就堵。由轻到重拍打，就是用手代替针，把堵的地方拍通。拍打了以后身体发热，就是通了。"

**原理**：
- 拍打产生振动波，沿经络传导
- 振动促进局部气血循环，化解瘀滞
- "不通则痛，痛则不通"，拍打至发热，痛减，即通

### 6.2 居家拍打法

**基本原则**：
- **哪里痛，拍哪里**
- **由轻到重**：开始轻，逐渐加重，以能忍受为度
- **拍到发热**：局部发热、微红，即为有效
- **时间**：每个部位3-5分钟

**具体方法**：

| 堵痹部位 | 拍打位置 | 手法 | 力度 | 验证标准 |
|---------|---------|------|------|---------|
| **颈肩堵** | 肩井穴周围、斜方肌 | 空心掌，左右交替拍 | 由轻到重，酸胀可忍 | 肩颈发热、轻松、活动灵活 |
| **背部堵** | 膀胱经（脊柱两侧两指宽） | 空心掌，从上至下拍 | 由轻到重，出痧为佳 | 背部发热、呼吸深、腰直 |
| **腰部堵** | 肾俞、命门、腰阳关 | 空心掌或拳背轻拍 | 适中，不可剧痛 | 腰部发热、酸软缓解 |
| **手臂堵** | 手三阳经（手臂外侧） | 从肩→肘→腕，由上至下拍 | 由轻到重 | 手臂发热、手指麻胀后轻松 |
| **腿部堵** | 胆经（大腿外侧）、膀胱经（大腿后侧） | 从髋→膝→踝，由上至下拍 | 由轻到重 | 腿部发热、走路轻松 |
| **关节堵** | 膝关节、肘关节周围 | 空心掌环绕拍打 | 适中，避骨突处 | 关节发热、活动顺畅 |

### 6.3 拍打工具（可选）

| 工具 | 适用部位 | 特点 |
|------|---------|------|
| **空心掌** | 全身 | 最常用，力度可控，安全 |
| **拍打棒** | 背部、腿部 | 力度大，适合深部堵痹 |
| **经络拍** | 全身 | 软硬适中，适合日常 |
| **拳头背** | 腰部、大腿 | 力度大，适合肌肉丰厚处 |

### 6.4 拍打禁忌

❌ **禁止拍打**：
- 皮肤破损、炎症、肿块处
- 骨折、骨裂处
- 严重骨质疏松者
- 出血性疾病患者
- 孕妇腹部、腰骶部

⚠️ **注意**：
- 拍后避免立即洗澡、吹风
- 拍出痧后，待痧退后再拍（一般3-7天）
- 饭后1小时内不宜拍打

### 6.5 通脉方法库（选一个先试）

| 方法 | 怎么做 | 耗时 | 适合谁 | 验证标准 |
|------|--------|------|--------|---------|
| **A. 拍打法** | 空心掌拍疼痛/僵硬处，由轻到重，至发热 | 10分钟 | 知道具体堵点、肌肉僵硬者 | 拍后局部发热、轻松、活动灵活 |
| **B. 热敷法** | 毛巾热水浸湿拧干，敷僵硬处10分钟 | 10分钟 | 颈肩腰僵硬、怕冷者 | 敷后局部发热、轻松 |
| **C. 拉伸法** | 猫式伸展（拱背-塌腰）或坐姿前屈 | 5-10分钟 | 腰背僵硬、久坐者 | 拉伸后活动范围增大 |

| **E. 穴位法** | 按压僵硬处附近最痛点，持续1分钟 | 5分钟 | 知道具体堵点者 | 按后痛减、活动顺 |

**💡 建议**：先找到"最痛/最僵"的部位，试A（拍打）+ B（热敷）。拍打是居家最易操作、效果最直接的通脉法。

### 6.6 炁脉医学专利居家通脉工具：洗髓脂 + 经络刀

> **师父点化**："洗髓脂加上经络刀，是我们炁脉医学自己发明的，有发明专利。尤其是心经堵痹的人，用这个来刮，起到刮痧的作用，居家就能通脉。"

#### 【洗髓脂】

**产品定位**：炁脉医学专利外用制剂，配合经络刀/刮痧手法，用于居家经络疏通、排毒外出。

**核心功效**：
- 疏通经络，化解瘀滞
- 温经散寒，促进局部气血循环
- 帮助深层毒邪外发（配合行罐/推拿使用）
- 尤其适用于心经堵痹、肩颈腰背痹痛、多发结节者

**居家使用方法**：

| 步骤 | 操作 | 要点 |
|------|------|------|
| **① 涂** | 取适量洗髓脂，涂抹于堵痹部位（肩颈、腰背、手臂、腿部等） | 薄涂均匀，覆盖待疏通区域 |
| **② 刮** | 用经络刀（或刮痧板/瓷勺替代）沿经络走向，由内向外、由下向上刮拭 | 力度由轻到重，以出痧为度，不可破皮 |
| **③ 观** | 观察痧色：红痧（热）、紫痧（瘀）、黑痧（寒毒重） | 记录痧色和部位，反馈调理师 |
| **④ 收** | 刮后用温水擦拭干净，涂抹少量润肤，注意保暖 | 4小时内不洗澡、不吹风 |

**适用部位与经络对应**：

| 堵痹部位 | 涂抹区域 | 刮拭经络 | 手法方向 |
|---------|---------|---------|---------|
| **肩颈堵** | 斜方肌、肩井穴周围 | 胆经、膀胱经 | 从颈根向肩峰刮 |
| **背部堵** | 脊柱两侧两指宽 | 膀胱经（第一侧线） | 从上向下刮 |
| **腰部堵** | 肾俞、命门、腰阳关 | 膀胱经、督脉 | 从上向下刮 |
| **手臂堵** | 手臂外侧（阳明经） | 手三阳经 | 从肩向腕刮 |
| **腿部堵** | 大腿外侧（胆经）、后侧（膀胱经） | 胆经、膀胱经 | 从髋向膝、膝向踝刮 |
| **心经堵** | 心经循行（上肢内侧后缘） | 手少阴心经 | 从腋下向腕方向轻刮 |

**使用频率**：
- 保健：每周1-2次
- 堵痹明显：隔日1次，痧退后再刮
- 急性疼痛：可连续3天，力度减轻

**禁忌**：
- 皮肤破损、湿疹、炎症处禁用
- 出血性疾病、严重骨质疏松者禁用
- 孕妇腰骶部禁用
- 饭后1小时内、空腹时不宜

#### 【经络刀】

**产品定位**：炁脉医学专利发明，专为居家经络疏通设计的工具，配合洗髓脂使用，起到刮痧、通脉作用。

**产品特点**：
- **专利设计**：符合人体经络走向，刀口弧度适配不同部位
- **材质安全**：医用级材质，不伤皮肤
- **居家可操作**：无需专业技能，学习基础手法即可自助

**基本握法与手法**：

| 手法 | 操作 | 适用部位 | 力度 |
|------|------|---------|------|
| **平刮法** | 刀面与皮肤呈45度，单向匀速刮拭 | 背部、腿部等大面积 | 中等，以出痧为度 |
| **角刮法** | 用刀角点按穴位后，沿经络刮拭 | 肩颈、手臂、穴位周围 | 由轻到重 |
| **推刮法** | 刀面平贴，缓慢推进，如推磨 | 腰部、腹部 | 轻柔，不需出痧 |

**居家操作要点**：
1. **先涂后刮**：必须涂抹洗髓脂作为介质，不可干刮
2. **单向原则**：每次单向刮拭，不可来回刮
3. **由轻到重**：先轻探经络，再逐渐加重
4. **以热为度**：刮至局部发热、微红或出痧即可
5. **一方向完成**：一个部位刮20-30下，换方向

**痧象解读**：

| 痧色 | 含义 | 说明 |
|------|------|------|
| **红色** | 热证、轻浅 | 新近外感或局部有热 |
| **紫红色** | 瘀血、中度 | 气血瘀滞较久 |
| **青紫色** | 寒证、重度 | 寒凝血瘀，病程较长 |
| **黑色** | 寒毒、陈旧 | 深层寒湿毒，需多次疏通 |
| **水泡** | 湿毒外发 | 体内湿毒重，应继续调理 |

**💡 与拍打的区别与选择**：

| 方法 | 适用场景 | 力度 | 效果 | 工具 |
|------|---------|------|------|------|
| **拍打法** | 日常保健、轻度堵痹 | 中等 | 振动通络，促循环 | 空心掌 |
| **洗髓脂+经络刀** | 中度堵痹、心经堵、需深层疏通 | 由轻到重 | 刮痧排毒，深部瘀滞外发 | 洗髓脂+经络刀 |

**建议**：日常以拍打为主，堵痹明显或心经堵时，加用洗髓脂+经络刀。两者可交替使用（今日拍，明日刮）。

### 8.3 动态配伍示例（三要素法）

#### 示例一：肝郁血瘀型（如回晶）

**证型要点**：情绪抑郁、胸闷胁痛、经血血块多、舌暗或有瘀点

| 药味 | 剂量 | 归经 | 秉炁 | 功用 |
|------|------|------|------|------|
| **丹参** | 10g | 心、肝经 | 微寒，苦 | 活血祛瘀，清心除烦 |
| **玫瑰花** | 5g | 肝、脾经 | 温，甘微苦 | 疏肝解郁，和血调经 |
| **茯苓** | 10g | 心、脾、肾经 | 平，甘淡 | 健脾利湿，宁心安神 |

**三要素·调和逻辑**：
> 丹参（微寒）入血分，化久瘀；玫瑰花（温）入气分，解肝郁。**一寒一温，气血同调**，不寒不燥，共奏疏肝化瘀之功。茯苓（平）为佐，健脾以绝湿源，宁心以安神魂，防肝郁乘脾。**三味合和，归经互补，秉炁调和**，正合"肝郁血瘀兼脾虚"之病机。

**饮用法**：沸水冲泡或小火煮15分钟，代茶温饮，每日1剂。

#### 示例二：气虚湿困型（如脾虚身重）

**证型要点**：乏力疲倦、食欲不振、舌苔厚腻、大便黏滞

| 药味 | 剂量 | 归经 | 秉炁 | 功用 |
|------|------|------|------|------|
| **黄芪** | 10g | 脾、肺经 | 甘，微温 | 补气升阳，益卫固表 |
| **陈皮** | 5g | 脾、肺经 | 辛、苦，温 | 理气健脾，燥湿化痰 |
| **茯苓** | 10g | 心、脾、肾经 | 甘、淡，平 | 健脾利湿，宁心安神 |

**三要素·调和逻辑**：
> 黄芪（微温）入脾肺，补一身之气，升发清阳；陈皮（温）入脾肺，理气燥湿，**补而不滞，温而不燥**；茯苓（平）入脾肾，渗湿健脾，**甘淡平和，不伤正气**。三味同属脾肺经，归经一致，协力健脾；黄芪温升，陈皮温散，茯苓平和，**秉炁相辅相成，共奏益气健脾、化湿醒脾之效**。

**饮用法**：同上。

#### 示例三：阴虚火旺型（如潮热口干）

**证型要点**：手足心热、口干咽燥、失眠多梦、舌红少苔

| 药味 | 剂量 | 归经 | 秉炁 | 功用 |

| **麦冬** | 10g | 心、肺、胃经 | 微寒，甘微苦 | 养阴润肺，益胃生津 |

**三要素·调和逻辑**：
> 枸杞子（平）入肝肾，滋补阴精，为君；麦冬（微寒）入心肺胃，养阴生津，为臣；菊花（微寒）入肝肺，清肝明目，为佐。**三味皆入阴分，归经互补，秉炁清凉平和，共奏滋阴清热、养肝明目之效**。枸杞子之甘平，可缓菊花、麦冬之微寒，**调和后清凉而不伤脾**。

**饮用法**：同上。

## 第九章：祛邪自助法

### 9.1 早期祛邪法（葱姜热汤）

**师父点化**：> "邪在表，未入里，一碗葱姜热汤，趁热喝下，盖被取汗，邪随汗出。这是最简单的祛邪法，家家可做。"

**适用**：感冒初起、怕冷、打喷嚏、流清涕、头痛（风寒表证）

**配方**：
- 葱白 5段（带须，约30g）
- 生姜 5片（约15g）
- 红糖 适量
- 水 500ml

**做法**：
1. 葱白洗净（保留葱须），生姜切片
2. 加水500ml，大火煮沸
3. 转小火煮10分钟
4. 加红糖，趁热喝下
5. **喝后立即盖被躺卧，取微汗**

**关键点**：
- **趁热喝**：温烫入口，不可放凉
- **盖被取微汗**：喝后盖被，至背部微微出汗即可，不可大汗淋漓
- **避风寒**：出汗后不可立即吹风、洗澡

**验证标准**：
- 喝后30分钟内背部微汗 = 邪随汗出
- 汗后怕冷减轻、头痛缓解 = 邪已去
- 无汗或汗后症状加重 = 邪已入里，需就医

### 9.2 居家祛邪方法库

| 邪的类型 | 判断方法 | 居家祛邪法 | 原理 |
|---------|---------|-----------|------|
| **风邪**（怕风、头痛、喷嚏） | 吹风后加重 | 葱姜热汤+盖被取微汗 | 辛温解表，汗孔一开，风邪随汗出 |
| **寒邪**（怕冷、腹痛、关节冷） | 得温减轻 | 热水袋敷痛处+生姜红糖水 | 热则寒散，温通经络 |
| **湿邪**（身重、苔厚、大便黏） | 阴雨天加重 | 薏米红豆水+陈皮茶+泡脚出汗 | 淡渗利湿，芳香化湿 |
| **热邪**（口苦、长痘、便秘） | 吃辣加重 | 绿豆汤/菊花枸杞茶+清淡饮食 | 清热泻火，凉血解毒 |
| **燥邪**（口干、干咳、皮肤干） | 秋冬加重 | 银耳百合汤+梨水+蜂蜜水润燥 | 滋阴润燥，生津止渴 |
| **正邪交争**（排异） | 调理后短暂不适 | 多喝温水、多休息、不压制 | 助正抗邪，给邪出路 |

**💡 建议**：邪在表（早期）时，先试葱姜热汤+盖被取汗，这是最简单有效的方法。不确定邪的类型时，试"泡脚+多喝温水"，这是通用祛邪法。

## 第十三章：排异反应自我识别

### 13.1 什么是排异反应？

**师父点化**：> "排异不是病情恶化，是身体在排毒。看懂排异，就不怕排异。"

**排异 = 调理后身体出现的短期不适反应**，本质是：
- 深层毒素被激活，向体表排出
- 气血重新分配，旧病灶被冲击
- 自愈力启动，修复过程中的正常反应

### 13.2 常见排异反应及应对

| 排异现象 | 出现时间 | 持续时间 | 应对 | 是否就医 |
|---------|---------|---------|------|---------|
| **痧色加深** | 调理后1-3天 | 3-7天消退 | 正常，记录颜色 | 否 |
| **疲劳加重** | 调理后1-2天 | 2-3天 | 多休息，保证睡眠 | 否 |
| **疼痛短暂加重** | 调理后当天 | 1-2天 | 热敷，不剧烈活动 | 否 |
| **痰/鼻涕增多** | 调理后2-3天 | 3-5天 | 多喝温水，助排出 | 否 |
| **腹泻** | 调理后1-2天 | 1-3天 | 清淡饮食，补水 | 严重就医 |
| **皮疹/发痒** | 调理后3-5天 | 5-10天 | 不抓挠，清淡饮食 | 严重就医 |
| **情绪波动** | 调理后1-3天 | 2-5天 | 多沟通，听音乐 | 否 |
| **月经变化** | 调理后当月 | 1-2周期 | 观察记录 | 异常就医 |

### 13.3 排异 vs 病情恶化的鉴别

| 特征 | 排异反应 | 病情恶化 |
|------|---------|---------|
| **时间** | 调理后1-3天出现 | 随时出现，与调理无关 |
| **趋势** | 逐渐减轻 | 持续加重 |
| **精神** | 精神状态尚可 | 精神萎靡 |
| **食欲** | 食欲基本正常 | 食欲明显下降 |
| **睡眠** | 睡眠可能增多（修复） | 失眠或嗜睡（病态） |

**不确定时**：联系调理师或医师确认。
