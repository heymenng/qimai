### 模块2：54张牌选方决策树

```
┌─────────────────────────────────────────────────────────────────────┐
│                      54张牌选方决策逻辑                              │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  【第一层】紧急程度判定                                              │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  IF 任一键度≥8级（危重）                                      │   │
│  │     → 转入人工通道，AI辅助                                    │   │
│  │  IF 炁虚≥7级                                                  │   │
│  │     → 必须先♥红桃8-10炁荡（绝对禁止先排毒/通脉）              │   │
│  │  ELSE                                                         │   │
│  │     → 进入标准选牌流程                                        │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                              │                                      │
│                              ▼                                      │
│  【第二层】五维优先级排序                                            │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  排序规则（按身体紧急程度+病因源发点）：                       │   │
│  │  1. 毒≥7级 → ♠黑桃优先（排毒）                               │   │
│  │  2. 脉≥7级 → ♦方块优先（通脉）                               │   │
│  │  3. 邪≥6级 → ♣梅花优先（祛邪）                               │   │
│  │  4. 瘾≥6级 → ♥红桃+断磁毒（固神）                            │   │
│  │  5. 炁虚≤6级 → ♥红桃打底（补炁）                             │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                              │                                      │
│                              ▼                                      │
│  【第三层】牌阵组合（最多4张牌）                                      │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  示例组合：                                                   │   │
│  │  • 基础版：♥打底 + 主攻牌 + 辅助牌 + 收功牌                   │   │
│  │  • 重症版：♥红桃8-10炁荡 → ♠排毒 → ♦通脉 → ♥固本            │   │
│  │  • 情志版：♥红桃5-6 → ♣梅花4-5（开表）→ 断磁毒 → ♥红桃7-8   │   │
│  └─────────────────────────────────────────────────────────────┘   │
│                              │                                      │
│                              ▼                                      │
│  【第四层】具体参数生成                                              │
│  ┌─────────────────────────────────────────────────────────────┐   │
│  │  每张牌输出：                                                 │   │
│  │  • 穴位/部位：具体经络穴位（如足三里、关元）                  │   │
│  │  • 时间：每次操作时长（如艾灸30分钟）                         │   │
│  │  • 温度：温度控制（如药灸45-50°C）                            │   │
│  │  • 频次：每日/隔日/每周次数                                   │   │

│  └─────────────────────────────────────────────────────────────┘   │
```
