## 技术团队关心的5个问题（简明回答）

### Q1: 是规则引擎还是神经网络？

**答案**：规则引擎 + 知识图谱（符号主义），不是神经网络。

**证据**：
- 500条形式化规则（卷一 1.3）
- ~1000节点/~5000边的知识图谱（卷一 1.2）
- Rete算法实现的规则匹配（卷一 1.3.2）

**与LLM的区别**：
- LLM：神经网络权重（分布式表征，不可解释）
- 灵觉：显式规则（可审查、可修改、可追溯）

## 与LLM的3个根本差异

### 差异1：知识表征

```
GPT:
知识存储 → 神经网络权重（数十亿参数）
知识调用 → 注意力机制激活
知识修改 → 几乎不可能（需重训练）
知识边界 → 模糊（不知道的知识会编造）

灵觉:
知识存储 → 显式规则库 + 知识图谱
知识调用 → 基于条件的模式匹配
知识修改 → 热更新（增删改规则）
知识边界 → 明确（无法匹配时拒绝回答）
```

### 差异2：推理过程

```
GPT 推理:
输入 → Embedding向量化 → Transformer计算 → 概率采样 → 输出
问题: 无法解释为什么选择这个答案
      无法验证推理过程
      可能包含训练数据偏见

灵觉 推理:
输入 → 结构化 → 规则匹配 → 归因推理 → 方案生成 → 输出
优势: 每步都有规则ID和置信度
      可审查、可质疑、可修正
      明确标注不确定性
```

### 差异3：验证机制

```
GPT:
无验证机制
输出无法与事实对照
无法确认疗效
无法自我修正

灵觉:
双闭环验证
医学闭环：预测→观察→疗效验证
AI闭环：错误→分析→规则更新
失败案例直接驱动系统改进
```
