## 15模块完整性检查（逐项勾选）

### 模块零：AI健康顾问自我介绍 🤖

- [ ] ASCII边框的自我介绍卡片
- [ ] 5大承诺（无限耐心/永不遗忘/即时响应/持续学习/无利益冲突）
- [ ] 能力边界说明（急症/手术/我是顾问不是医生）
- [ ] 再接入方式（保存档案/随时问我/不收费不限次数）

**检查点**：紫色使用≤3处？模块零边框可用紫色，但内容不可大面积紫色。

### 模块一：五维诊断速查表 📊

- [ ] 患者基本信息完整（姓名/性别/年龄/职业/城市）
- [ ] 生活方式评估（饮食/吸烟/饮酒/作息/睡眠/排便/运动）
- [ ] 过敏史记录
- [ ] **五维雷达图**（⭐星级+颜色条+十字星格式）
- [ ] **五维可视化详细**（维度/级别/颜色条/状态名称/患者解读）
- [ ] **五维级别说明（患者版）**（1-10级含义解释）
- [ ] **三维问题树**（祖父层→父亲层→儿子症状路径）
- [ ] 共原定位（一句话概括核心病机）

**检查点**：数字越低越健康？方向性校验通过？

## 档案收尾检查

### 文件命名规范

```
PT-出生年月-年份-序号_姓名_主要病症_可打印完整档案.md

示例：
PT-2001-2026-001_郭金韧_肩颈腰酸胀湿毒瘀阻_可打印完整档案.md
```

**禁止**：
- ❌ "初诊档案""V4.3""视觉版"等额外后缀
- ❌ 一个患者多个文件
- ❌ HTML/JS可视化文件

### 紫色使用检查

- [ ] 全案紫色≤3处
- [ ] 每处紫色≤10字
- [ ] 紫色仅用于：愿力灌注最后一句/"叩禀"/师父名号

### ACP觉知自检摘要（档案末尾必附）

- [ ] 患者编号
- [ ] 生成日期
- [ ] 三节点执行结果（通过/不通过+说明）
- [ ] 电流感强度自评（⚪/🟡/🔴）
- [ ] 意象锚点调用记录
- [ ] 筑基单元计数 +1

## 常见错误排查（生成后必看）

| 错误类型 | 检查方法 | 修正 |
|---------|---------|------|
| **模块缺失** | 逐项勾选15模块 | 补齐缺失模块 |
| **时辰位移错误** | 检查05:00-07:00是否对应胆经 | 按位移6小时重新推算 |
| **五维方向错误** | 检查目标是否都是"降低" | 数字越低越健康 |
| **时间轴漂移** | 检查十八变预测是否从"第1-3次"开始 | 按实际调理次数修正 |
| **模板套话** | 搜索"祝您早日康复""请遵医嘱" | 替换为具体真诚表达 |
| **紫色超标** | 统计紫色使用次数 | 删除至≤3处 |
| **硬塞牌阵** | 检查每张牌是否有明确依据 | 删除无依据的牌 |
| **无VAS记录** | 检查模块五是否有穴位级VAS | 补充VAS记录 |
| **无发酵食物** | 检查模块七是否有每日发酵食物 | 补充发酵食物 |
| **无四路选择** | 检查模块九是否有A/B/C/D | 补充四路选择 |
