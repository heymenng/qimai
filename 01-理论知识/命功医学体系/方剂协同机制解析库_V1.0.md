## 一、协同模式分类（Synergy Pattern Taxonomy）

### 1.1 八大协同模式

```
【模式1】相须增效 Mutual Enhancement
  定义：两味药功效同类，合用后效果 > 单用之和
  机制：同靶点叠加 或 同通路放大
  示例：黄芪+党参（补气）、丹参+川芎（活血）
  五维特征：同一维度内的"强强联合"
  54牌映射：♥K+♥Q、♦K+♦Q

【模式2】君臣互补 Monarch-Minister Complement
  定义：君药主攻方向，臣药补其不足/防其偏性
  机制：主攻+辅佐，形成完整治疗单元
  示例：黄芪（君，大补元气）+ 陈皮（臣，防壅滞）
  五维特征：跨维度的"主攻-防护"配对
  54牌映射：♥K+♣3、♦A+♠J

【模式3】毒-补平衡 Toxin-Nourishment Balance
  定义：攻邪药 + 扶正药，攻而不伤正
  机制：祛邪药清除病理产物，补益药保护正气
  示例：白花蛇舌草（攻癌毒）+ 黄芪（护正气）
  五维特征：毒维/邪维 ↓ + 炁维 ↑ 的同步操作
  54牌映射：♠K+♥K、♣A+♥Q

【模式4】通-补交替 Dredging-Supplement Alternation
  定义：通脉药 + 补气血药，通中带补
  机制：先通后补 或 通补兼施，防止"虚不受补"
  示例：川芎（通）+ 当归（补）、地龙（通）+ 黄芪（补）
  五维特征：脉维 ↑ + 炁维 ↑ 的协同提升
  54牌映射：♦K+♥K、♦Q+♥J

【模式5】升降相因 Ascending-Descending Interdependence
  定义：升提药 + 降逆药，调畅气机
  机制：一升一降，恢复气机正常升降出入
  示例：柴胡/升麻（升）+ 枳壳/牛膝（降）
  五维特征：脉维双向调节（升清+降浊）
  54牌映射：♦J+♣J、♦Q+♠Q

【模式6】燥-润互济 Drying-Moistening Mutual Support
  定义：燥湿药 + 养阴药，祛湿不伤阴
  机制：燥药性燥，需养阴药制衡；润药性腻，需燥药防滞
  示例：苍术（燥）+ 玄参（润）、半夏（燥）+ 麦冬（润）
  五维特征：毒维（祛湿）+ 炁维（养阴）的平衡
  54牌映射：♠J+♥J、♣Q+♥Q

【模式7】虫-草协同 Insect-Herb Synergy
  定义：虫类药（搜剔）+ 植物药（基础）
  机制：虫类药穿透力强但性猛，植物药提供基础+缓冲
  示例：全蝎/蜈蚣（虫）+ 黄芪/当归（草）
  五维特征：脉维深度渗透 + 炁维后勤保障
  54牌映射：♦K+♥K（特殊组合）

【模式8】三焦分消 Triple Burner Dispersal
  定义：上焦宣发 + 中焦运化 + 下焦渗利，三路并行
  机制：湿热/痰浊无处藏身，分路而出
  示例：杏仁（上焦）+ 白蔻仁（中焦）+ 薏苡仁（下焦）
  五维特征：毒维/邪维的多通路清除
  54牌映射：♠Q+♣Q+♦Q（三维度联动）
```

### 1.2 协同模式与五维的映射关系

```
【五维-协同模式对应表】

炁维（补）：
  主要模式：相须增效、君臣互补
  核心逻辑：补气药之间互相增强，或用理气药防止补气壅滞

毒维（清）：
  主要模式：毒-补平衡、三焦分消
  核心逻辑：清热解毒需护正气，湿热需分路清除

脉维（通）：
  主要模式：通-补交替、升降相因、虫-草协同
  核心逻辑：通脉需有物质基础，升降需双向调节

邪维（祛）：
  主要模式：毒-补平衡、燥-润互济
  核心逻辑：祛邪勿伤正，燥湿需养阴制衡

瘾维（心）：
  ⚠️ 原方多缺失 → 需外部补充（正念/情绪管理/行为矫正）
```

#### 【协同组合1】黄芪+党参+生晒参 = 相须增效（炁维）

```
【组成】炙黄芪30g + 党参15g + 生晒参15g

【单味功效】
  黄芪：补脾肺之气，升阳固表
  党参：补中益气，生津养血
  生晒参：大补元气，复脉固脱

【协同机制】
  1. 靶点叠加：三药均入脾肺经，作用于同一脏腑系统
  2. 层次互补：
     - 生晒参 → 补"元气"（最深层次）
     - 黄芪 → 补"宗气"（中层次，主呼吸/运化）
     - 党参 → 补"营气"（浅层次，主日常功能）
  3. 效能放大：
     - 单用黄芪30g → 补气力 = 100
     - 黄芪+党参 → 补气力 = 150（党参助黄芪运化）
     - 三药合用 → 补气力 = 220（三层气同时补，形成"气库"）

【五维映射】
  炁维：三层补气 → 炁维从5级→8级
  毒维：无直接作用
  脉维：气行则血行 → 间接通脉

【54牌映射】
  ♥K（黄芪）+ ♥Q（党参）+ ♥K（生晒参）= 炁维"三K组合"
  → 适用于炁维7级以上重症

【临床逻辑】
  肿瘤患者正气亏虚是"本"，癌毒是"标"
  三药合用 = 建立"正气储备库"，为后续攻邪提供物质基础
  若单用黄芪 → 气足但运化不力（易腹胀）
  加党参 → 助运化，补而不滞
  加生晒参 → 补元气之根，从根本上扭转虚损
```

## 八、使用说明

### 8.1 如何使用本库

```
【第一步：识病选方】
  肿瘤/结节 → 朱良春方
  心血管/糖尿病 → 邓铁涛方
  湿病/脾胃 → 路志正方
  脑病/中风 → 张学文方

【第二步：析方找协同】
  在对应方剂中查找【协同组合】
  理解"为什么这几味药要一起用"

【第三步：定模式用方】
  根据患者五维缺口，选择协同模式：
  - 单一维度严重不足 → 相须增效
  - 两个维度问题 → 通-补交替/君臣互补
  - 有毒邪需攻伐 → 毒-补平衡
  - 气机失常 → 升降相因
  - 湿热弥漫 → 三焦分消
  - 阴虚湿重 → 燥-润互济
  - 顽痹癥积 → 虫-草协同

【第四步：补上瘾维】
  根据疾病类型，选择瘾维补充策略
  确保五维全覆盖

【第五步：闭环验证】
  十八变追踪疗效
  根据反应调整协同组合
```

### 8.2 协同模式与脉级的对应

```
【脉级与协同强度】

脉级5-6级（轻证）：
  协同模式：相须增效、君臣互补
  剂量：常规剂量下限
  协同组合数：1-2个

脉级7-8级（中证）：
  协同模式：通-补交替、毒-补平衡、升降相因
  剂量：常规剂量中值
  协同组合数：2-3个

脉级9-10级（重证）：
  协同模式：虫-草协同、三焦分消、燥-润互济
  剂量：常规剂量上限
  协同组合数：3-4个
  注意：需监测毒性/出血等副作用

脉级10+级（危证）：
  协同模式：所有模式联合使用
  剂量：超大剂量/急救
  协同组合数：4-5个
  注意：需在医师监护下使用
```

```
【两层数据库架构】

  ├── 用途：理解"团队作战逻辑"

【使用流程】
  1. 五维诊断 → 确定缺口维度
  2. 选协同模式 → 确定组合策略
  3. 查单味药库 → 确定具体药物
  4. 查协同库 → 验证组合逻辑
  5. 定君臣佐使 → 确定剂量比例
  6. 查禁忌 → 自动扫描冲突
  7. 出方 → 标注协同模式

【示例】

  Step 1: 缺口 → 炁维严重不足，毒维过高

  Step 4: 验证 → 查【朱良春-扶正消癥汤-协同组合2】
           确认：黄芪+白花蛇舌草 = 经典毒-补平衡
  Step 5: 定君臣 → 黄芪60g（君）+ 白花蛇舌草30g（臣）
  Step 6: 查禁忌 → 无冲突
  Step 7: 出方 → 标注：毒-补平衡模式
```
