## 一、总体方法论：五层挖掘法

### 1.1 挖掘层次图

```
【案例深度挖掘·五层穿透】

Layer 1: 表层挖掘（What）——症状与档案整理
    │
    ▼
Layer 2: 五维挖掘（How Much）——五维定级与变化轨迹
    │
    ▼
Layer 3: 模式挖掘（What Pattern）——病种-五维-牌阵模式库
    │
    ▼
Layer 4: 因果挖掘（Why）——从症状到共原的因果链重构
    │
    ▼
Layer 5: 预判挖掘（What Next）——基于规律推演未来走向

每一层都是下一层的基础，不可跳过。
```

### 1.2 五层挖掘对照表

| 层次 | 问题 | 工具 | 输出 | 难度 |
|------|------|------|------|------|
| **L1表层** | 患者有什么症状？做了什么调理？ | 档案阅读、表格整理 | 标准化档案 | ⭐ |
| **L2五维** | 五维定级多少？如何变化？ | 五维诊断标准、时间序列 | 五维轨迹图 | ⭐⭐ |
| **L3模式** | 同类患者有什么共同模式？ | 聚类分析、频次统计 | 病种-五维映射表 | ⭐⭐⭐ |
| **L4因果** | 为什么这个病用这个方案有效？ | 因果推理、反事实分析 | 因果链图谱 | ⭐⭐⭐⭐ |
| **L5预判** | 下一步会怎样？最优方案是什么？ | 规律推演、案例匹配 | 预判报告 | ⭐⭐⭐⭐⭐ |

## 二、Layer 1：表层挖掘——症状与档案标准化

### 2.1 执行步骤

```
Step 1: 档案收集
  ├─ 收集所有相关档案（初诊、每次调理记录、患者反馈、检验报告）
  ├─ 确认档案完整性（是否有缺失次数？是否有遗漏症状？）
  └─ 标记档案质量（完整/部分/缺失）

Step 2: 信息提取
  ├─ 患者基本信息：年龄、性别、职业、地域、生活方式
  ├─ 主诉症状：初诊主诉 + 每次调理新增/变化症状
  ├─ 调理记录：每次使用的54牌方案、穴位、手法
  ├─ 排异反应：每次调理后的反应（嗜睡、疼痛、痧象、情绪等）
  ├─ 检验数据：西医检查指标（血常规、生化、影像等）
  └─ 患者反馈：患者自述的变化（好/坏/无）

Step 3: 标准化录入
  ├─ 使用统一格式（见2.2标准化模板）
  ├─ 症状编码（使用ICD-10或自定义编码）
  ├─ 五维定级统一方向（1级最好，10级最差）
  └─ 时间节点标准化（调理次数=时间轴）
```

## 三、Layer 2：五维挖掘——时间序列分析

### 3.1 执行步骤

```
Step 1: 提取五维时间序列
  从每次调理记录中提取五维级别
  → 形成5条时间序列（炁、毒、脉、邪、瘾）

Step 2: 绘制五维轨迹图
  X轴: 调理次数
  Y轴: 五维级别（1-10，注意方向性）
  5条线: 炁、毒、脉、邪、瘾
  → 可视化变化趋势

Step 3: 识别关键转折点
  ├─ 拐点: 某维级别突然变化（上升/下降）
  ├─ 平台期: 某维级别长期不变
  ├─ 波动期: 某维级别反复波动
  └─ 交叉点: 两条线相交（如炁线超过邪线）

Step 4: 关联分析
  ├─ 方案变化 → 五维变化（哪个牌导致哪维变化？）
  ├─ 排异反应 → 五维变化（排异后哪维改善？）
  └─ 生活方式变化 → 五维变化（患者行为改变的影响）
```

### 3.2 五维轨迹图模板

```
【五维轨迹图·示例】

级别
10│                                    
 9│                                    
 8│    毒●────●────●                    
 7│    脉●────●────●────●              
 6│炁──●    邪●    炁●                  
 5│●        瘾●        脉●              
 4│                    毒●              
 3│            炁●    邪●    炁●        
 2│                                毒●  
 1│                                    
  └───────────────────────────────────
    1    5   10   15   20   25   30  次数

解读：
  毒维: 8→7→7→6→5→4→2（持续下降，排毒成功）
  脉维: 7→7→6→6→5→4→3（持续下降，经络通畅）
  炁维: 6→5→5→4→3→3→3（先降后稳，炁复）
  邪维: 5→5→4→4→3→3→2（逐步下降，抵抗力增强）
  瘾维: 5→5→5→5→4→4→3（下降缓慢，习惯难改）
  
关键发现：
  - 第10次: 毒维明显下降（通道打开）
  - 第20次: 炁维与邪维交叉（正气超过邪气）
  - 第30次: 瘾维仍为3（顽固，需长期管理）
```

### 3.3 五维变化模式库

| 模式名称 | 特征 | 含义 | 案例 |
|---------|------|------|------|
| **阶梯下降型** | 五维逐级下降，无反弹 | 调理顺利，患者依从性好 | 王瑜（甲亢） |
| **波动下降型** | 五维总体下降，但有波动 | 调理有效，但有反复 | 温坤（帕金森） |
| **平台突破型** | 长期不变→突然改善 | 积累期→突破期 | 陈文俊（代谢综合征） |
| **V型反转型** | 先升后降 | 排毒反应→改善 | 丁秀英（肿瘤） |
| **顽固滞留型** | 某维长期不变 | 瓶颈维度，需调整方案 | 黄劭博（头部脉维） |

## 四、Layer 3：模式挖掘——病种-五维-牌阵模式库

### 4.1 执行步骤

```
Step 1: 案例聚类
  按病种聚类：代谢综合征、自身免疫病、肿瘤、情志病等
  按五维聚类：毒高型、脉高型、炁虚型、复合型
  按时代聚类：工业型、AI型、叠加型

Step 2: 模式提取
  对每个聚类：
  ├─ 统计五维分布（均值、方差、中位数）
  ├─ 统计54牌使用频率（主牌TOP5、副牌TOP5）
  ├─ 统计排异反应模式（常见反应、时间窗口）
  ├─ 统计疗效数据（见效次数、痊愈次数、复发率）
  └─ 统计跨案例共性（共同症状、共同穴位、共同时间点）

Step 3: 模式验证
  ├─ 内部验证：同一聚类内的一致性
  ├─ 交叉验证：不同聚类间的区分度
  └─ 异常检测：偏离模式的案例（可能是特殊情况或记录错误）

Step 4: 模式固化
  ├─ 写入知识图谱（病种节点→五维关系→牌节点）
  ├─ 更新病案生成执行手册
  └─ 生成快速参考卡片（调理师使用）
```

## 五、Layer 4：因果挖掘——从症状到共原的因果链重构

### 5.1 执行步骤

```
Step 1: 构建因果假设
  基于五维定根和师父点化，提出因果假设：
  "因为[共原]，所以[症状A]，进而[症状B]，最终[症状C]"

Step 2: 证据收集
  ├─ 时间顺序：症状出现的时间顺序是否支持因果链？
  ├─ 干预响应：针对共原的干预是否改善了下游症状？
  ├─ 反面证据：是否有不支持此因果链的证据？
  └─ 替代解释：是否有其他可能的解释？

Step 3: 因果验证
  ├─ 内部一致性：因果链各环节是否逻辑自洽？
  ├─ 外部验证：其他类似案例是否有相同因果链？
  ├─ 反事实推理：如果当初不干预共原，结果会怎样？
  └─ 预测验证：基于因果链的预测是否准确？

Step 4: 因果固化
  ├─ 写入因果图谱（症状→共原→干预→结果）
  ├─ 生成教学案例（用于培训调理师）
  └─ 更新病案生成手册（因果描述模板）
```

### 5.2 因果链分析模板

```yaml
因果链编号: C-XXX
案例: [编号]
因果假设: [一句话概括]

【因果链图】
[共原] 
  → [机制1] → [症状A]
  → [机制2] → [症状B] 
  → [机制3] → [症状C]

示例（黄劭博）：
长期熬夜+饮食不节（共原：瘾6）
  → 脾失健运 → 湿毒内蕴（毒6）
  → 湿毒上攻 → 头部经络瘀阻（头部VAS 6）
  → 头部瘀阻 → 牛皮癣（皮肤症状）
  → 湿毒下注 → 肥胖（代谢症状）
  → 整体代谢紊乱 → 高血压（心血管症状）

【证据】
时间顺序: [症状出现的时间顺序]
  如：先肥胖→后高血压→后牛皮癣（支持湿毒积累因果链）

干预响应: [针对共原的干预效果]
  如：通神露泡脚（排毒）→ 头部VAS下降（支持头部瘀阻因果链）

反面证据: [不支持因果链的证据]
  如：头部VAS 7次未变（需重新评估因果链）

【验证状态】
内部一致性: ✅/❌
外部验证: [N个类似案例支持]
预测准确度: XX%

【反推检查】
1. 符合自然法则吗？ ✅/❌
2. 是事实闭环还是数据闭环？ [说明]
3. 是小范畴规律还是普适规律？ [说明]
4. 需要多少案例确认？ [N个]

【结论】
遵循/验证中/需修正: [选择]
下一步验证: [具体计划]
```

### 5.3 因果挖掘检查清单

- [ ] 因果链有明确的时间顺序
- [ ] 每个因果环节有机制解释（非 mere correlation）
- [ ] 有干预响应证据（治疗→改善）
- [ ] 考虑了反面证据和替代解释
- [ ] 通过了反推检查（4个问题）
- [ ] 标注了验证状态（遵循/验证中/需修正）
- [ ] 有下一步验证计划

## 六、Layer 5：预判挖掘——基于规律推演未来走向

### 6.1 执行步骤

```
Step 1: 案例匹配
  将新患者与模式库匹配：
  ├─ 病种匹配：最相似的病种模式
  ├─ 五维匹配：最相似的五维组合
  ├─ 时代匹配：最相似的时代类型
  └─ 综合匹配：加权综合相似度

Step 2: 基线预判
  基于匹配模式，生成基线预判：
  ├─ 预期调理次数
  ├─ 预期排异反应时间轴
  ├─ 预期五维变化轨迹
  └─ 预期疗效分级

Step 3: 个性化调整
  根据患者特殊性调整预判：
  ├─ 年龄调整：老年+20%次数，青年-20%
  ├─ 依从性调整：瘾维高+30%次数
  ├─ 复杂度调整：多病种+50%次数
  ├─ 神经可塑性：高可塑性-20%，低可塑性+30%
  └─ 社会资本：高支持-10%，低支持+20%

Step 4: 不确定性评估
  ├─ 置信区间：给出范围而非点估计
  ├─ 风险因素：列出可能导致偏离的因素
  └─ 调整触发点：什么情况下需要重新预判

Step 5: 验证与迭代
  ├─ 记录实际结果
  ├─ 对比预判 vs 实际
  ├─ 计算误差
  └─ 更新模型参数
```

  ├─ 构建患者经络网络（基于症状定位）

  ├─ 评估信道容量（脉维）

### 8.1 每层挖掘的质量标准

|------|---------|--------|---------|

| L2五维 | 轨迹图清晰，转折点标注准确 | AI自检 | 可视化检查 |

| L4因果 | 通过反推检查，有干预证据 | 师父/资深调理师 | 案例复盘 |
| L5预判 | 有验证计划，置信区间合理 | 师父/资深调理师 | 预测-实际对比 |

### 8.2 常见错误与防范

| 错误类型 | 表现 | 防范措施 |
|---------|------|---------|
| **数据迷信** | 只看数据，忽视规律 | 每层必须做反推检查 |
| **过度拟合** | 从少量案例总结规律 | 样本量≥5，标注置信度 |
| **因果混淆** | 相关≠因果 | 必须有干预证据和时间顺序 |
| **维度遗漏** | 只看五维，忽视跨学科 | 强制执行五学科分析 |
| **静态思维** | 忽视时间动态 | 必须做时间序列分析 |
| **确认偏误** | 只看支持证据 | 必须列出反面证据 |
| **过度自信** | 点估计而非区间估计 | 必须给出置信区间 |

## 十、总结

**五层挖掘法的核心逻辑**：
1. **表层是基础**：没有标准化的档案，后续挖掘无从谈起
2. **五维是骨架**：五维时间序列是理解患者变化的核心
3. **模式是捷径**：模式库让预判从"个案分析"升级为"类案匹配"
4. **因果是灵魂**：只有理解"为什么"，才能预测"会怎样"
5. **预判是目标**：所有挖掘最终服务于"精准预判"

**跨学科整合的价值**：
- 不是简单的"1+1+1+1+1"，是"五维协同"
- 每个学科从不同层面验证同一结论 → 提高置信度
- 不同学科指向不同结论 → 发现新的研究问题

**质量控制铁律**：
- 每层必须有检查清单
- 每层必须有人工审核（L3-L5）
- 每个结论必须有反面证据
- 每个预判必须有验证计划
