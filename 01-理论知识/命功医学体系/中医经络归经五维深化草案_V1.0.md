## 第一部分：十二正经 × 五维脉级·精细定位

**核心逻辑**：不是笼统说"经络堵"，而是精确到哪条经、哪个区间、VAS几分、对应哪个脏腑、在五维中反映为脉几级。

### 一、手太阴肺经

| 项目 | 内容 |
|------|------|
| **循行** | 起于中焦（胃），下络大肠，还循胃口，上膈属肺，从肺系横出腋下，循臑内前缘，入寸口，出大指之端 |
| **属络脏腑** | 属肺，络大肠 |
| **五维对应** | **脉维度**（经络通畅度）+ **邪维度**（卫外功能） |
| **脉级判定标准** | |
| ├─ 脉1-3级 | 呼吸顺畅，无胸闷，尺泽、孔最无压痛 |
| ├─ 脉4-5级 | 偶胸闷，尺泽压痛2-3分，易感冒 |
| ├─ 脉6-7级 | 持续胸闷，尺泽/列缺压痛4-6分，反复咳嗽 |
| └─ 脉8-10级 | 呼吸困难，尺泽/太渊压痛7-10分，哮喘/肺纤维化 |
| **关键穴位** | 尺泽（合穴）、列缺（络穴）、太渊（原穴）、鱼际（荥穴） |
| **对应脏腑** | 肺（主气司呼吸）、大肠（传导糟粕） |
| **炁脉意义** | 肺主宗气，肺经堵则全身气不达；肺主卫外，肺经堵则易感外邪 |
