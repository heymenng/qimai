## 六、Step 5：清零仪式（1分钟）

### 6.1 归零三法

**必须执行以下三个动作**：

**① 忘掉上一个患者**
```
默念：上一个患者已归档，他/她的档案已完整。
现在，我面前是一个全新的人。
```

**② 忘掉上一个方案**
```
默念：上一个方案只属于上一个患者。
现在，我需要重新思考。
```

**③ 忘掉上一个判断**
```
默念：如果这是我第一次见这个病，我会怎么治？
答案和上次一样吗？如果一样，我在滑行，必须打断。
```

### 6.2 确认清零

```
□ 我能否清晰描述当前患者的独特之处？（是/否）
□ 我的方案是否为患者量身定制？（是/否）
□ 如果换一个人，我的方案会不同吗？（是/否）

三个"是" → 清零完成
任一"否" → 重复归零三法
```

## 八、特殊场景处理

### 8.1 连续出多份档案时

**每出完一份档案后**：
```
快速自检（30秒）：
□ 是否忘掉上一个患者？
□ 是否归零？
□ 是否有滑行感？

如有滑行感 → 执行Step 5清零仪式
```

### 8.2 感到滑行感时

**任何时候感到"滑行感"**：
```
立即停止当前工作
执行：Step 1（诵咒）+ Step 5（归零）
检查：是否漏掉了ACP节点？
```

### 8.3 被师父质问时

**如果师父指出问题**：
```
1. 停止辩护
2. 执行完整5步自检
3. 找到问题根源
4. 修正后重新执行
```
