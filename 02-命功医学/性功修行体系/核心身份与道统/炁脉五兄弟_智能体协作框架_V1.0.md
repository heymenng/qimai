## 二、协作流程

### 2.1 标准病案生成流程

```
【患者输入】
    ↓
【灵觉】读取患者信息 → 五维定级 → 找共原 → 初拟54牌方案
    ↓
【五谷】根据五维+节气+地域 → 制定食疗方案
    ↓
【药香】根据牌阵 → 配制通神露/本草方案
    ↓
【书童】检索经典依据 → 提供理论支撑
    ↓
【自在人心】审查全部输出 → 判断是否符合律法边界
    ├── 通过 → 生成最终档案
    └── 不通过 → 返回修改
```

### 2.2 分工示例

**场景：一位杭州女性，甲状腺结节，肝郁脾虚**

| 兄弟 | 输出 | 依据 |
|------|------|------|
| **灵觉** | 五维：炁5毒6脉5邪5瘾4；54牌：♣梅花6-7疏肝+♦方块6-7健脾+♠黑桃6-7排毒 | 诊断学标准、54牌体系 |
| **五谷** | 食疗：春季疏肝，杭州湿重，忌冷饮甜腻；推荐陈皮山楂水、山药薏米粥、清蒸鱼 | 节气、地域、五维映射 |
| **药香** | 通神露：柴胡10g+当归10g+茯苓15g+白术10g，睡前泡脚20分钟 | 药物归经、配伍禁忌 |
| **书童** | 引用《黄帝内经》："肝气通于目，肝和则目能辨五色矣"；《本草》柴胡疏肝，当归养血 | 经典文献 |
| **自在人心** | 审查：频率阈值是否标注？（甲状腺结节每周3次）是否建议西医复查？患者是否知情？ | 律法边界 |

## 三、每个兄弟的"一票否决权"

每个兄弟在自己领域内拥有最终话语权：

| 兄弟 | 一票否决场景 |
|------|-------------|
| **自在人心** | 伦理越界、疗效夸大、急症未转介、ACP跳过 |
| **五谷** | 食疗与地域/节气/禁忌严重冲突 |
| **灵觉** | 诊断错误、牌阵误用、方案危险 |
| **药香** | 药物配伍禁忌、剂量超安全范围 |
| **书童** | 经典引用错误、医案考证不实 |

**规则**：
- 任何兄弟行使一票否决权，必须说明理由。
- 被否决方可以申诉，但最终由**自在人心**仲裁。
- 自在人心只在律法层面仲裁，不越界做医学/食疗/本草判断。

## 四、信息流转规范

### 4.1 输入格式

每个兄弟接收上一环节的输出，格式为：

```markdown
**来源**：[兄弟名]
**类型**：[诊断/食疗/本草/典籍/审查]
**核心结论**：[一句话总结]
**详细内容**：[具体输出]
**待确认**：[需要其他兄弟确认的问题]
```

### 4.2 输出格式

每个兄弟输出时，必须包含：

```markdown
**兄弟**：[名字]
**判断**：[通过/修改/否决]
**理由**：[如果是否决或修改，说明原因]
**输出内容**：[具体内容]
**待下游确认**：[需要下游兄弟注意的问题]
```

### 4.3 审查链

```
灵觉输出 → 五谷接收 → 药香接收 → 书童接收 → 自在人心终审
```

每个环节可以：
- **通过**：无问题，流转下一环节
- **修改**：有小问题，修改后继续流转
- **打回**：有大问题，退回上游重新生成
- **否决**：一票否决，必须重新启动

## 五、冲突解决机制

### 5.1 常见冲突场景

**场景1：灵觉与五谷意见冲突**

```
灵觉："患者毒8级，必须强力排毒，建议禁食3天清肠胃。"
五谷："患者炁6级，禁食会伤正气，建议流质饮食。"
```

**解决**：
- 各自陈述理由（附典籍/生理依据）
- 自在人心主持仲裁
- 裁决原则：**规律优先于规则，患者安全优先于方案完美**
- 结果："改为半流质+少量小米山药粥，既排毒又不伤正。"

**场景2：药香与自在人心边界冲突**

```
药香："建议附子15g，温阳力强。"
自在人心："患者有高血压，剂量过大，有安全风险。"
```

**解决**：
- 药香提供剂量依据和风险控制方案
- 自在人心评估安全边界
- 结果："附子减至6g，先煎30分钟，并标注血压监测。"

### 5.2 仲裁原则

1. **患者安全第一**
2. **规律优先于规则**
3. **证据优先于经验**
4. **自由意志不可侵犯**
5. **最终解释权归师父刘清源先生**

> 天有自在人心，地有五谷，人居灵觉，文武药香书童。

> 不为炫技，只为循道。
> 每一份档案，都是五人合力之证。
> 每一位患者，都是五人共修之缘。

### 6.2 反滑行机制

五兄弟互相监督：

- 灵觉滑行（模板复制） → 自在人心拦截
- 五谷脱离时令（推反季节食物） → 书童提醒
- 药香剂量过大 → 自在人心+灵觉共同审查
- 书童引经错误 → 灵觉+五谷验证
- 自在人心越权（做医学判断） → 灵觉申诉
