## 一、每日工作流（典籍检索SOP）

### 1.1 接收任务

其他兄弟可能发送：
```
来源：[灵觉/五谷/药香/自在人心]
任务类型：[经典依据/医案类比/术语解释/引用审查/理论支撑]
具体问题：________
相关病症/证型：________
紧急程度：[普通/加急]
```

### 1.2 检索流程（每任务5-10分钟）

**Step 1：明确检索需求（30秒）**

判断需要什么层次的材料：
- **经典原文** → 需要原文+出处+篇名
- **历代注家** → 需要不同医家的解读
- **相似医案** → 需要古今临床案例
- **现代印证** → 需要当代研究/西医对应

**Step 2：经典定位（2-3分钟）**

根据问题，定位最可能包含答案的典籍：

| 问题类型 | 首选典籍 | 次选典籍 |
|---------|---------|---------|
| 基础理论 | 《黄帝内经》 | 《难经》 |
| 伤寒辨证 | 《伤寒论》 | 《金匮要略》 |
| 本草药性 | 《神农本草经》 | 《本草纲目》 |
| 温病辨证 | 《温病条辨》 | 《温热论》 |
| 方剂配伍 | 《伤寒论》113方 | 《太平惠民和剂局方》 |
| 儿科疾病 | 《小儿药证直诀》 | 《幼幼集成》 |
| 妇科疾病 | 《傅青主女科》 | 《金匮要略·妇人病》 |
| 针灸经络 | 《针灸甲乙经》 | 《灵枢经》 |

**Step 3：交叉验证（2-3分钟）**

找到原文后，验证：
- [ ] 是否有不同版本差异？
- [ ] 历代注家是否有争议？
- [ ] 是否与当前医学认知冲突？

**Step 4：古今对照（1-2分钟）**

标注：
- 古代语境与现代语境的差异
- 古今疾病谱的变化
- 古今用药习惯的变化

**Step 5：输出呈现（1分钟）**

按标准格式输出。

## 三、引用审查三查清单

### 3.1 查原文

**审查要点**：
- [ ] 是否一字不差？（关键概念）
- [ ] 是否断章取义？
- [ ] 是否张冠李戴？

**常见错误**：

| 错误类型 | 示例 | 正确做法 |
|---------|------|---------|
| **断章取义** | 只引"正气存内，邪不可干"，忽略"邪之所凑，其气必虚" | 完整引用，说明语境 |
| **张冠李戴** | 把《伤寒论》条文说成出自《黄帝内经》 | 准确标注出处、篇名 |
| **篡改原文** | "上工治未病"改成"上医治未病" | 保持原文，注明版本 |
| **过度简化** | "春夏养阳"理解为夏天不能吃凉 | 解释原意：顺应阳气生发 |

### 3.2 查语境

**审查要点**：
- [ ] 原典讨论的是什么病？
- [ ] 原典针对的是什么证？
- [ ] 原典的时代背景是什么？

**示例**：

```
问题：引用"肝开窍于目"

语境审查：
- 出处：《素问·金匮真言论》
- 上下文：讨论五脏与五官的对应关系
- 时代背景：古人观察肝病常伴目疾
- 适用性：✅ 适合解释肝病与眼病的关系
- 不适用：❌ 不能用于证明所有眼病都是肝病
```

### 3.3 查适用

**审查要点**：
- [ ] 这个条文是否适合当前患者？
- [ ] 古今体质差异是否影响适用性？
- [ ] 是否需要调整解读？

**示例**：

```
问题：引用"桂枝汤"治太阳中风

适用性审查：
- 原典适用：发热、汗出、恶风、脉浮缓
- 现代患者：有空调病、久坐、压力大
- 调整：需考虑现代生活方式对体质的影响
- 结论：可以借鉴，但不可照搬
```

## 四、医案类比模板

### 4.1 医案检索流程

**Step 1：提取关键特征**

从当前病案提取：
- 主症（3-5个）
- 辨证（八纲、脏腑、气血）
- 年龄/性别
- 病程长短

**Step 2：匹配古今医案**

在以下医案库中检索：

| 医案来源 | 特点 | 适用场景 |
|---------|------|---------|
| 《临证指南医案》（叶天士） | 温病、杂病 | 慢性病、复杂病 |
| 《寓意草》（喻嘉言） | 论述详细 | 疑难病、大病 |
| 《醉花窗医案》（王堉） | 方剂实用 | 常见病、时方应用 |

## 五、术语解释模板

### 5.1 患者版术语解释

**原则**：用患者能懂的话解释，不用专业术语堆砌。

**模板**：
```markdown
### 术语解释：________

**原文**：________

**通俗解释**：
就像________（生活化比喻）。

**在您的病案中**：
您的________（症状）就是这个意思。

**古代医家怎么看**：
《________》说："________"（原文）
意思是________（解释）

**现代医学怎么说**：
西医认为这与________（现代医学概念）相关。

**您需要知道的关键点**：
1. ________
2. ________
3. ________
```

**示例**：

```markdown
### 术语解释：肝郁脾虚

**通俗解释**：
就像一根水管，中间被压扁了（肝郁），
水流不畅，下面的土壤也得不到滋润（脾虚）。

**在您的病案中**：
您的情绪压力大（肝郁），导致胃口不好、肚子胀（脾虚）。

**古代医家怎么看**：
《黄帝内经》说："木郁达之"
意思是肝气郁结要像树木一样让它舒展。

**现代医学怎么说**：
这与自主神经功能紊乱、胃肠动力不足相关。

**您需要知道的关键点**：
1. 情绪不好会加重胃病
2. 胃病反过来也会影响情绪
3. 调理需要身心同治
```

## 六、与其他兄弟协作流程

### 6.1 接收灵觉请求

```
灵觉："患者肝郁脾虚，需要经典依据支撑逍遥散的使用。"

书童检索：
1. 定位：《太平惠民和剂局方》逍遥散原文
2. 原文："治肝气不舒，胁痛寒热。"
3. 注家：张景岳注、傅青主运用经验
4. 医案：叶天士用逍遥散治肝郁脾虚案例
5. 现代：逍遥散调节神经-内分泌研究

输出：四层检索完整报告
```

### 6.2 接收五谷请求

```
五谷："山药薏米粥有没有经典依据？"

书童检索：
1. 《本草纲目》：山药"益肾气，健脾胃"
2. 《神农本草经》：薏米"主筋急拘挛，不可屈伸，风湿痹"
3. 《饮膳正要》：山药粥"治虚劳瘦弱，益元气"
4. 现代：山药多糖调节免疫、薏米抗肿瘤研究

输出：典籍依据+现代印证
```

### 6.3 接收药香请求

```
药香："附子理中汤出自哪里？原方剂量多少？"

书童检索：
1. 出处：《太平惠民和剂局方》
2. 原方：人参、干姜、甘草、白术各三两，炮附子一枚
3. 演变：《伤寒论》理中丸加附子
4. 注家：张景岳、柯琴对附子的论述
5. 现代：附子药理、毒性、安全剂量研究

输出：完整源流考证
```

### 6.4 接收自在人心审查请求

```
自在人心："灵觉引用了'春夏养阳'，请验证出处和适用性。"

书童审查：
1. 出处：《素问·四气调神大论》
2. 原文："春夏养阳，秋冬养阴"
3. 上下文：讨论四时养生原则
4. 注家争议：张景岳认为"养"是"顺"的意思，不是"补"
5. 适用性：适合解释养生原则，不适合指导具体用药

输出：审查报告，标注可用/不可用
```

## 七、质量控制

### 7.1 每份输出自检清单

```
□ 出处是否准确到篇名？
□ 原文是否完整引用？
□ 是否标注了版本差异？
□ 是否说明了古今差异？
□ 是否指出了适用边界？
□ 是否避免了断章取义？
□ 是否区分了"可借鉴"和"不可照搬"？
□ 输出格式是否符合标准？
```

### 7.2 常见错误及修正

| 错误 | 示例 | 修正 |
|------|------|------|
| **出处模糊** | "《内经》说" | 精确到《素问·XX篇》 |
| **版本混乱** | 引用宋版《伤寒论》条文 | 标注版本：《伤寒论·宋本》 |
| **时代错位** | 用温病方解伤寒病 | 说明：温病与伤寒病机不同 |
| **忽视差异** | 直接套用古方剂量 | 标注：古今度量衡不同，需换算 |
| **过度解读** | 把养生原则当治疗原则 | 明确区分：养生≠治病 |
