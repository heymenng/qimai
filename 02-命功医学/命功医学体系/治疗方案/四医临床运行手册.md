## 一、紧急排雷（第一步，5秒）

```
🚨 立即转诊（不犹豫）
├── 胸痛 + 大汗 + 放射痛 → STEMI
├── 突发头痛"雷击样" → 蛛网膜下腔出血
├── FAST症状（面歪/臂无力/言语不清）→ 卒中
├── 血压≥180/120 + 靶器官损害 → 高血压急症
├── 大咯血/呕血/黑便 → 大出血
├── 意识障碍 + 高热 → 脓毒症
├── 板状腹 + 反跳痛 → 腹膜炎
└── 血糖>16.7 + 酮症 → 糖尿病急症

✅ 非急症 → 进入第二步
```

## 三、五维快速定级

| 维度 | 快速判断 | 1-4级 | 5-6级 | 7-8级 | 9-10级 |
|------|---------|-------|-------|-------|--------|
| **炁** | 能爬楼梯？ | 精力充沛 | 容易疲劳 | 极度乏力 | 卧床不起 |
| **毒** | 每日排便？ | 排毒顺畅 | 偶发便秘 | 长期便秘+皮肤病 | 严重便秘/溃烂 |
| **脉** | 肩颈僵硬？ | 完全通畅 | 酸胀不适 | 明显疼痛/受限 | 剧痛/完全僵直 |
| **邪** | 指标正常？ | 完全正常 | 轻度异常 | 中度异常（三高） | 严重异常/肿瘤 |
| **瘾** | 23点前睡？ | 生活规律 | 偶发波动 | 经常失眠/焦虑 | 严重成瘾/抑郁 |

## 四、54牌速选

```
【选牌规则】

Step 1: 找最严重的2个维度
Step 2: 对应花色
  炁低 → ♥红桃（补）     毒高 → ♠黑桃（排）
  脉堵 → ♦方块（通）     瘾重 → ♣梅花（心）
Step 3: 对应等级
  9-10级 → K    7-8级 → Q    5-6级 → J    3-4级 → 10
Step 4: 检查平衡
  攻伐牌（♠♦）≤ 补益牌（♥）+ 1
  瘾维≥6级 → 必须有♣牌

【常见组合】
肿瘤：♠K + ♦Q + ♥K + ♣J
糖尿：♥Q + ♠Q + ♣J
高血压：♦K + ♠Q + ♣J
湿困：♠Q + ♥J + ♣J
中风先兆：♦K + ♠Q + ♥Q + ♣J
```

## 六、协同模式速查

| 模式 | 定义 | 示例 | 适用 |
|------|------|------|------|
| **相须增效** | 同类药叠加 | 黄芪+党参+人参 | 气虚重症 |
| **君臣互补** | 主攻+辅佐 | 黄芪（君）+陈皮（臣） | 防壅滞 |
| **毒-补平衡** | 攻邪+扶正 | 白花蛇舌草+黄芪 | 肿瘤 |
| **通-补交替** | 通脉+补气血 | 川芎+当归 | 血瘀 |
| **升降相因** | 升提+降逆 | 柴胡+枳壳 | 气机失常 |
| **燥-润互济** | 燥湿+养阴 | 苍术+玄参 | 阴虚湿重 |
| **虫-草协同** | 虫类+植物 | 全蝎+黄芪 | 顽痹/癥积 |
| **三焦分消** | 上中下同时 | 杏仁+白蔻仁+薏苡仁 | 湿热弥漫 |

## 七、三层报告生成流程

```
【生成流程】

Step 1: 确认输出层级
  用户说"出档案"→ 第二层（默认）
  用户说"深度医疗"→ 第一层
  用户说"居家自助"→ 第三层

Step 2: 第一层生成（深度医疗，给调理师）
  2.1 查疾病索引 → 定位四医方向
  2.2 查西医指南 → 诊断标准+转诊红线
  2.3 查国医大师 → 核心方+关键药对
  2.4 查方剂协同 → 协同模式+剂量依据
  2.5 五维定级 → 推理过程
  2.6 54牌选方 → 组合逻辑
  2.7 十八变预测 → 排异反应
  2.8 综合决策 → 优先级+风险点

Step 3: 第二层生成（档案报告V4.3，给患者）
  3.1 从第一层提取 → 按模块映射表转换
  3.2 西医部分 → 通俗化（去指南引用）
  3.3 中医部分 → 通俗化（去克数）
  3.4 五维部分 → 雷达图+通俗解释
  3.5 54牌部分 → 说方向（不说牌名）
  3.6 添加回函 → 情感支持
  3.7 14模块组装 → V4.3标准

Step 4: 第三层生成（居家自助手册，给患者在家用）
  4.1 从第二层提取 → 居家可执行内容
  4.2 删除调理师操作（行罐/药灸/手法）
  4.3 补充详细解释（为什么这样做）
  4.4 补充具体方法（步骤详细）
  4.5 保留打卡机制
  4.6 去除专业术语

【模块映射表】
第一层内容              → 第二层模块
西医分析（指南引用）     → 模块二·四医合诊（去引用）
中医分析（方剂加减）     → 模块四·中医辨证（去克数）
五维定级（推理过程）     → 模块一·五维诊断（简化）
54牌组合（逻辑推导）     → 模块五·54牌方案（说方向）
十八变预测（排异概率）   → 模块十·自检清单（说反应）
回函内容              → 模块九·患者回函（保留）

第二层模块              → 第三层章节
模块三·时辰位移        → 作息管理
模块五·54牌方案        → 居家方法（去调理师操作）
模块六·五音疗法        → 五音疗法
模块七·动态食疗        → 食疗调整
模块八·患者执行手册     → 打卡表+自我观察
模块十四·微习惯        → 微习惯启动
```

```
【生成后自检】

  □ 转诊红线是否明确？
  □ 假设是否列出？
  □ 剂量依据是否合理？

□ 第二层检查
  □ 是否去掉了所有指南引用？
  □ 是否去掉了方剂克数？
  □ 五维解释是否通俗？
  □ 回函是否温暖？

□ 第三层检查
  □ 是否删除了调理师操作？
  □ 是否有详细步骤？
  □ 是否有通俗解释？
  □ 是否有打卡机制？

□ 跨层一致性检查
  □ 三层诊断是否一致？
  □ 三层方案是否连贯？
  □ 没有内容矛盾？
```
