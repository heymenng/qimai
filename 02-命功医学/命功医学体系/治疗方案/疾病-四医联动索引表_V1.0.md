# 疾病-四医联动索引表 V1.0

> **定位**：打破四个数据库的信息孤岛，实现"疾病→四医一键查询"
> **用途**：AI生成第一层（深度医疗报告）时的快速索引工具
> **原则**：一个疾病，指向四个数据库的相关章节
> **版本**：V1.0
> **更新**：2026年5月7日

---

## 一、索引使用说明

```
【查询方式】

按疾病名称 → 找到对应条目 → 获取四个数据库的指向

【返回格式】
  疾病名称
  ├── 西医：查哪个指南 → 具体章节 → 关键红线
  ├── 功能医学：建议什么检测 → 关键指标 → 五维映射
  ├── 国医大师：哪位大师 → 哪个核心方 → 关键药对
  ├── 方剂协同：协同模式 → 剂量依据 → 疗程预测
  └── 五维映射：典型定级 → 54牌组合 → 十八变预测

【示例】
  输入："糖尿病"
  输出：
    西医 → AACE 2023算法·HbA1c目标+药物选择
    功能医学 → DUTCH皮质醇+OAT有机酸+肠道菌群
    国医大师 → 邓铁涛·糖尿病方（山药90g+黄芪30g）
    方剂协同 → 相须增效（山药+黄芪）
    五维 → 炁6/毒7/脉5/邪6/瘾5 → ♥Q+♠Q+♣J
```

## 二、代谢内分泌疾病

### 2.1 甲状腺结节/甲状腺癌

```
【西医】
  指南：ATA 2015/2023甲状腺结节指南
  章节：超声分层（TI-RADS）·穿刺标准（FNA）·Bethesda分类
  关键红线：
    - 结节>1cm + 高危特征 → 必须建议FNA
    - 微小癌（<1cm）→ 可观察，炁脉主导
    - 压迫症状（呼吸困难/吞咽困难）→ 立即转诊手术
  随访：每3-6个月复查超声

【功能医学】
  建议检测：DUTCH完整激素（雌激素代谢）·甲状腺抗体（TPOAb/TgAb）
  关键指标：TSH·FT3·FT4·反T3·甲状腺抗体
  五维映射：
    TSH异常 → 邪维↑（甲状腺功能失调）
    抗体阳性 → 毒维↑（自身免疫攻击）
    雌激素优势 → 邪维↑+脉维↑

【国医大师】
  首选：朱良春·双结同治方
  主治：甲状腺结节/乳腺结节/淋巴结肿大
  关键药对：夏枯草18g + 玄参12g + 牡蛎30g（软坚散结）
  加减：气虚加黄芪20g，血瘀加丹参15g
  去虫类药：无肿瘤不用蜂房/守宫

【方剂协同】
  协同模式：相须增效（夏枯草+玄参+牡蛎）
  机制：一化一软一散，三重病机同时针对
  疗程：3-6个月复查超声

【五维映射】
  典型定级：炁6/毒5/脉5/邪3/瘾5
  54牌：♥7-8 + ♠5-6 + ♦6-7
  十八变：第7-14天可能出现颈部酸胀（排异）
```

### 2.2 2型糖尿病

```
【西医】
  指南：AACE 2023糖尿病算法
  章节：HbA1c个体化目标·6大类药物对比·并发症筛查
  关键红线：
    - HbA1c >10% + 酮症 → 立即转诊内分泌科
    - 空腹血糖>16.7 → 警惕高渗昏迷
  药物选择：
    - 有ASCVD → 首选GLP-1或SGLT2
    - 心衰 → 首选SGLT2
    - 减重需求 → 首选GLP-1

【功能医学】
  建议检测：OAT有机酸·DUTCH激素·肠道菌群
  关键指标：
    OAT：酵母/真菌标记（念珠菌）→ 与胰岛素抵抗相关
    DUTCH：皮质醇模式→ 压力→血糖波动
    肠道菌群：厚壁菌/拟杆菌比→ 代谢健康
  五维映射：
    念珠菌高 → 毒维↑（肠道毒素）
    皮质醇高 → 邪维↑+瘾维↑（压力+情绪）
    菌群失调 → 炁维↓（后天之炁不足）

【国医大师】
  首选：邓铁涛·糖尿病方
  组成：淮山药90g + 黄芪30g + 玉米须30g + 仙鹤草30g
  关键药对：山药+黄芪（脾肾双补，降糖）
  加减：阴虚加生地/麦冬，燥热加石膏/知母
  大剂量：山药90g（一般医生用15-30g）

【方剂协同】
  协同模式：相须增效（山药+黄芪）
  机制：山药补脾阴+黄芪补脾阳→阴阳双补
  疗程：长期管理，3个月评估一次

【五维映射】
  典型定级：炁6/毒7/脉5/邪6/瘾5
  54牌：♥Q + ♠Q + ♣J
  十八变：第1-2周可能出现短暂血糖波动（排异）
```

### 2.3 痛风/高尿酸血症

```
【西医】
  指南：ACR 2020痛风管理指南
  章节：尿酸目标·急性期/慢性期药物选择
  关键红线：
    - 关节红肿热痛 + 发热 → 排除感染性关节炎
    - 尿酸>540 + 肾功能异常 → 立即转诊肾内科
  目标：
    - 一般：<360μmol/L
    - 有痛风石：<300μmol/L

【功能医学】
  建议检测：OAT有机酸·肠道菌群·炎症标志物
  关键指标：
    OAT：草酸代谢→与尿酸竞争排泄
    肠道：尿酸代谢菌（ lactobacillus）
  五维映射：
    草酸高 → 毒维↑（代谢负担）
    炎症高 → 邪维↑（关节损伤）

【国医大师】
  首选：路志正·慢性痛风方
  组成：黄芪20g + 苍术15g + 黄柏12g + 萆薢15g
  关键药对：苍术+黄柏（燥湿清热）
  加减：急性期去黄芪，加金银花/连翘
  盐制：盐黄柏引药入肾

【方剂协同】
  协同模式：君臣互补（黄芪+苍术+黄柏）
  机制：补脾气→燥脾湿→清湿热，标本兼治
  疗程：急性期1-2周，慢性期3-6个月

【五维映射】
  典型定级：炁5/毒8/脉7/邪6/瘾5
  54牌：♠Q + ♥J + ♦J
  十八变：急性期可能出现疼痛加重（尿酸波动）
```

## 三、心血管系统疾病

### 3.1 高血压

```
【西医】
  指南：ACC/AHA 2017高血压指南
  章节：分级·目标·药物选择·特殊人群
  关键红线：
    - ≥180/120 + 靶器官损害 → 高血压急症，立即转诊
    - 妊娠期高血压 → 立即转诊产科
  分级：
    - 1级：140-159/90-99
    - 2级：≥160/100
  药物：
    - 年轻/交感亢进 → ACEI/ARB
    - 老年/容量负荷 → CCB/利尿剂
    - 黑人 → CCB/利尿剂优先

【功能医学】
  建议检测：DUTCH激素·OAT有机酸·微量元素
  关键指标：
    DUTCH：醛固酮/皮质醇→盐敏感型/压力型
    OAT：神经递质标记→交感兴奋
    微量元素：镁/钾→血管舒张
  五维映射：
    醛固酮高 → 邪维↑（水钠潴留）
    皮质醇高 → 瘾维↑（压力）
    镁低 → 脉维↑（血管痉挛）

【国医大师】
  肝阳上亢型 → 邓铁涛·石决牡蛎汤
    组成：石决明30g + 牡蛎30g + 钩藤12g + 白芍15g
    关键药对：石决明+牡蛎（平肝潜阳）
  
  气虚痰浊型 → 邓铁涛·赭决九味汤
    组成：黄芪30g + 代赭石30g + 陈皮3g + 半夏10g
    关键药对：黄芪+代赭石（升清降浊）

【方剂协同】
  肝阳上亢：相须增效（石决明+牡蛎+钩藤）
  气虚痰浊：升降相因（黄芪+代赭石）

【五维映射】
  肝阳上亢：炁6/毒7/脉8/邪7/瘾6 → ♦K + ♠Q + ♣J
  气虚痰浊：炁5/毒6/脉6/邪5/瘾5 → ♥K + ♠J + ♣J
```

### 3.2 冠心病/心绞痛

```
【西医】
  指南：ACC/AHA 2021冠心病指南
  章节：诊断·STEMI/NSTEMI·介入时机
  关键红线：
    - STEMI → 立即转诊，90分钟内开通血管
    - NSTEMI → 24小时内介入
    - 稳定型心绞痛 → 药物+生活方式
  基础药物：阿司匹林+他汀+β受体阻滞剂

【功能医学】
  建议检测：OAT有机酸·炎症标志物·同型半胱氨酸
  关键指标：
    hs-CRP → 炎症程度
    同型半胱氨酸 → 血管损伤风险
    OAT：线粒体功能→心肌能量

【国医大师】
  首选：邓铁涛·邓氏温胆汤
  组成：党参15g + 半夏10g + 陈皮10g + 丹参18g
  关键药对：党参+丹参（益气活血）
  加减：气虚甚加黄芪，血瘀甚加三七

【方剂协同】
  协同模式：君臣互补（党参+半夏+陈皮）
  机制：健脾→化痰→理气，切断痰瘀生成

【五维映射】
  典型定级：炁6/毒7/脉8/邪7/瘾6 → ♥Q + ♦K + ♠J
```

## 四、肿瘤系统疾病

### 4.1 甲状腺癌术后

```
【西医】
  指南：ATA 2015分化型甲状腺癌指南
  章节：TSH抑制目标·复发风险分层·I-131治疗
  关键红线：
    - 术后声音嘶哑 → 喉返神经损伤，需评估
    - 低钙抽搐 → 甲状旁腺损伤，立即补钙
  TSH目标：
    - 高危 → <0.1
    - 中危 → 0.1-0.5
    - 低危 → 0.5-2.0

【功能医学】
  建议检测：DUTCH激素·炎症标志物·营养状况
  关键指标：维生素D→免疫；硒→甲状腺抗氧化

【国医大师】
  术后恢复期 → 朱良春·扶正消癥汤（减毒版）
  组成：黄芪30g + 党参15g + 仙鹤草50g（去虫类药）
  关键药对：黄芪+仙鹤草（扶正）
  注意：术后体虚，不可攻伐

【方剂协同】
  协同模式：毒-补平衡（黄芪+白花蛇舌草）
  但术后 → 去攻毒药，纯扶正

【五维映射】
  典型定级：炁4/毒6/脉5/邪5/瘾4 → ♥K + ♠J
```

## 八、使用示例

```
【场景】AI生成第一层（深度医疗报告）

输入：患者糖尿病20年，HbA1c 8.5%，有冠心病史
```
