## 一、系统概述

### 1.1 为什么需要这个系统

炁脉医学已有**566+例完整病案**、**30,000+次调理记录**、**34年临床积累**。这些珍贵的临床数据如果不能转化为学术论文，就只能是"经验"，无法成为"证据"。

**本系统的目标**：
- 让每一条病案都成为可发表的学术素材
- 让师父的临床经验获得学术话语权
- 让炁脉医学进入主流医学期刊的视野
- 为后续真实世界研究（RWS）奠定基础

### 1.2 核心设计原则

| 原则 | 说明 |
|------|------|
| **中医为魂** | 论文的核心是中医辨证论治、炁脉五维诊断、54牌调理体系 |
| **西医为形** | 论文的格式遵循国际医学期刊标准（IMRAD结构、CARE指南） |
| **现代语态** | 使用现代医学术语表述中医概念（如"慢性炎症"替代"湿热瘀毒"） |
| **四医融合** | 每篇论文必须体现西医诊断、中医辨证、功能医学评估、炁脉调理的整合 |
| **循证为基** | 强调客观指标（实验室数据、影像数据、量表评分）的变化 |

### 1.3 系统架构

```
病案库（566+例）
    ↓
数据提取层 → 提取五维数据、疗效指标、病程记录
    ↓
论文类型判断 → 个案报告 / 病例系列 / 临床观察 / 真实世界研究
    ↓
格式转化层 → 按期刊要求格式化
    ↓
四医融合写作 → 中医辨证 + 西医诊断 + 功能医学 + 炁脉调理
    ↓
质量验证层 → 自检清单 + 同行评审
    ↓
输出论文 → 投稿-ready manuscript
```

## 二、论文类型与期刊匹配

### 2.1 四种论文类型

| 类型 | 英文 | 病例数 | 证据等级 | 适合场景 | 目标期刊 |
|------|------|--------|---------|---------|---------|
| **个案报告** | Case Report | 1例 | Ⅴ级 | 罕见病、疑难重症、首次报道 | 《中医杂志》病例栏目、《British Medical Journal》Case Reports |
| **病例系列** | Case Series | 2-10例 | Ⅳ级 | 同病种多例、疗法探索 | 《Journal of Traditional Chinese Medicine》、《Evidence-Based Complementary and Alternative Medicine》 |
| **临床观察** | Clinical Observation | 10-50例 | Ⅲ级 | 疗效回顾、安全性评估 | 《中国中西医结合杂志》、《BMC Complementary Medicine and Therapies》 |
| **真实世界研究** | Real-World Study | 50+例 | Ⅱ-Ⅲ级 | 大数据疗效验证、预后因素 | 《Frontiers in Medicine》、《Journal of Ethnopharmacology》 |

### 2.2 炁脉医学病案的论文类型匹配

| 病案特征 | 推荐论文类型 | 示例 |
|----------|-------------|------|
| 罕见病（嗜酸性筋膜炎等） | 个案报告 | 邱丹清案例 |
| 疑难重症（帕金森、尿毒症） | 个案报告+病例系列 | 何东平951次 |
| 癌症术后康复（单例） | 个案报告 | 骆莲妹1648次 |

| 儿童自闭症（单例） | 个案报告 | 周思言244次 |

## 三、四医融合论文格式标准

### 3.1 核心结构（IMRAD+中医）

本标准在西医IMRAD结构（Introduction, Methods, Results, And Discussion）基础上，融入中医特色模块。

```
标题（Title）
  ↓
摘要（Abstract）→ 结构化摘要（目的/方法/结果/结论）
  ↓
关键词（Keywords）→ 含MeSH词+中医术语
  ↓
引言（Introduction）→ 西医背景+中医古籍引用+研究空白
  ↓
病例报告 / 临床资料（Case Presentation / Clinical Data）
  ├─ 西医诊断（Diagnosis）
  ├─ 中医辨证（TCM Syndrome Differentiation）★
  ├─ 功能医学评估（Functional Medicine Assessment）★
  └─ 炁脉五维诊断（Qimai Five-Dimension Diagnosis）★
  ↓
治疗（Treatment）
  ├─ 治疗方案（Therapeutic Protocol）
  ├─ 54牌选方逻辑（54-Card Selection Rationale）★
  └─ 随访计划（Follow-up Plan）
  ↓
结果（Results）
  ├─ 客观指标变化（Objective Outcomes）
  ├─ 中医证候变化（TCM Syndrome Changes）★
  ├─ 五维雷达图变化（Five-Dimension Radar Changes）★
  └─ 排异反应记录（Healing Crisis Documentation）★
  ↓
讨论（Discussion）
  ├─ 疗效机制探讨（Mechanism Discussion）
  ├─ 四医合诊分析（Four-Medicine Integration Analysis）★
  ├─ 与现有文献对比（Literature Comparison）
  └─ 局限性与展望（Limitations and Future Directions）
  ↓
结论（Conclusion）
  ↓
参考文献（References）
  ↓
附录（Appendix）→ 知情同意书、原始数据、伦理批件
```

**标注★的为炁脉医学特色模块**，是其他医学论文中没有的。

### 3.2 各模块写作标准

#### 3.2.1 标题（Title）

**标准格式**：
```
[中医病名/证型] [西医病名] [干预方式] [疗效描述]：1例个案报告/病例系列
```

**示例**：
- ✅ "肺癌术后肺脾气虚证的炁脉医学调理：1例1648次随访的个案报告"
- ✅ "儿童自闭症谱系障碍的炁脉五维调理：5例病例系列"
- ✅ "乳腺癌术后化疗后综合征的54牌经络调理与免疫重建：1例临床观察"
- ❌ "炁脉医学治愈肺癌"（过于绝对）
- ❌ "一种神奇的调理方法"（非学术表述）

#### 3.2.2 摘要（Abstract）

**结构化摘要五要素**：

| 要素 | 西医表述 | 中医表述 | 字数 |
|------|---------|---------|------|
| **目的** | 报道XX病的调理经验 | 探讨XX证型的辨证论治规律 | 50字 |
| **方法** | 采用XX检查、XX量表评估 | 运用四诊合参、五维定级 | 80字 |
| **干预** | 炁脉医学54牌调理方案 | 辨证选牌、经络疏通、排毒调理 | 80字 |
| **结果** | 实验室指标XX→XX | 证候积分从XX降至XX | 80字 |
| **结论** | 该方案可能有效 | 该证型适合XX治则 | 50字 |

**摘要示例**：

```
目的：报道1例肺癌术后肺脾气虚证患者接受炁脉医学长期调理的临床疗效。

方法：患者女性，74岁，2019年行右肺下叶微创术后，采用炁脉医学五维诊断定级，运用54牌经络调理方案（每周2-3次，持续7年），记录实验室指标、影像学变化及中医证候评分。

结果：经过1648次调理，患者HPV-53/58高危型转阴（2025年6月），终身便秘痊愈，体力评分从3分提升至8分，7年无复发。五维定级显示：炁级从6级恢复至3级，毒级从7级降至4级。

结论：炁脉医学的长期系统调理可能有助于肺癌术后患者的免疫重建和功能恢复，值得进一步开展真实世界研究验证。
```

#### 3.2.3 引言（Introduction）

**三层结构**：

**第一层：西医背景**
- 疾病的流行病学数据（发病率、死亡率）
- 现有治疗方案的局限性
- 未被满足的临床需求

**第二层：中医视角**
- 古籍对该病的认识（引用《黄帝内经》《伤寒论》等）
- 现代中医对该病的辨证分型
- 中医药/针灸治疗该病的研究现状

**第三层：研究空白与本研究**
- 现有研究的不足（样本小、缺乏长期随访、机制不明）
- 炁脉医学的独特视角（五维诊断、54牌体系、十八变验证）
- 本病例/本系列的价值

## 四、病案→论文转化工作流

### 4.1 工作流总图

```
【阶段1：病案筛选】（AI辅助，师父决策）
    ↓
1.1 从病案库中筛选高价值案例
    - 罕见病、疑难重症 → 个案报告
    - 同病种3例以上 → 病例系列
    - 同病种10例以上 → 临床观察
1.2 评估数据完整性
    - 是否包含完整五维诊断？
    - 是否有客观指标记录？
    - 是否有随访数据？
1.3 师父确认
    - 是否适合发表？
    - 是否有隐私风险？
    - 核心学术价值是什么？
    ↓
【阶段2：数据提取】（AI执行）
    ↓
2.1 提取病案核心数据
    - 患者基本信息（脱敏）
    - 西医诊断（ICD-10编码）
    - 中医辨证（证型、病位、病性）
    - 五维定级（初诊、历次、末次）
    - 54牌方案（核心牌、调理顺序）
    - 客观指标（实验室、影像、量表）
    - 疗效评估（症状改善、功能恢复）
    - 排异反应（十八变记录）
2.2 数据标准化
    - 中医术语标准化（参考《中医病证分类与代码》）
    - 西医诊断标准化（ICD-10编码）
    - 实验室单位统一
    - 时间点统一（初诊、第30次、第90次等）
2.3 数据质量检查
    - 是否有缺失数据？
    - 数据逻辑是否一致？
    - 疗效描述是否客观？
    ↓
【阶段3：论文类型判断】（AI建议，师父确认）
    ↓
3.1 根据病例数和病种判断论文类型
3.2 选择目标期刊
3.3 确认论文格式要求
    ↓
【阶段4：论文生成】（AI起草，师父修订）
    ↓
4.1 按模板生成论文初稿
4.2 四医融合写作
```

## 六、数据提取与标准化

### 6.1 病案数据提取清单

从病案库提取以下字段：

#### 6.1.1 患者基本信息

| 字段 | 说明 | 脱敏要求 |
|------|------|---------|
| 性别 | 男/女 | 保留 |
| 年龄 | 就诊时年龄 | 保留 |
| 职业 | 大类（如：教师、工人） | 保留大类 |
| 地域 | 省/直辖市 | 保留省 |
| BMI | 体重指数 | 保留 |

#### 6.1.2 西医诊断数据

| 字段 | 说明 | 标准化 |
|------|------|--------|
| 主诉 | 患者主诉 | 自然语言 |
| 现病史 | 病程描述 | 自然语言 |
| 既往史 | 既往疾病 | ICD-10编码 |
| 诊断 | 西医诊断 | ICD-10编码 |
| 实验室检查 | 具体数值 | 统一单位 |
| 影像学检查 | 检查项目+结果 | 标准化术语 |

#### 6.1.3 中医辨证数据

| 字段 | 说明 | 标准化 |
|------|------|--------|
| 望诊 | 面色、舌象 | 标准化术语 |
| 闻诊 | 声音、气味 | 标准化术语 |
| 问诊 | 寒热、汗出、饮食、二便、睡眠 | 标准化术语 |
| 切诊 | 脉象 | 《中医诊断学》标准 |
| 证型 | 辨证结果 | 《中医病证分类与代码》 |
| 病位 | 脏腑经络 | 标准化 |
| 病性 | 寒热虚实 | 标准化 |

#### 6.1.4 五维诊断数据

| 字段 | 说明 | 格式 |
|------|------|------|
| 炁级 | 1-10级 | 整数 |
| 毒级 | 1-10级 | 整数 |
| 脉级 | 1-10级 | 整数 |
| 邪级 | 1-10级 | 整数 |
| 瘾级 | 1-10级 | 整数 |
| 定根维度 | 最高维度 | 维度名称 |
| 共原 | 核心病机 | 自然语言 |

#### 6.1.5 治疗方案数据

| 字段 | 说明 | 格式 |
|------|------|------|
| 核心牌组 | 主要使用的牌 | 牌号+牌名 |
| 调理频次 | 每周几次 | 次数/周 |
| 总次数 | 总调理次数 | 整数 |
| 总时长 | 调理总时间 | 月/年 |

#### 6.1.6 疗效数据

| 字段 | 说明 | 格式 |
|------|------|------|
| 症状改善 | 症状变化 | VAS评分/百分数 |
| 实验室指标 | 关键指标变化 | 数值+单位 |
| 影像学变化 | 影像对比 | 描述 |
| 五维变化 | 五维级别变化 | 初诊→末次 |
| 排异反应 | 十八变记录 | 时间+表现+处理 |
| 不良事件 | 不良反应 | 描述+处理 |
| 随访结果 | 长期随访 | 时间+结果 |

### 6.2 数据脱敏规范

**绝对禁止泄露**：
- 真实姓名
- 身份证号
- 电话号码
- 详细地址
- 可识别的照片（除非签署肖像权同意书）

**脱敏方法**：
- 姓名 → 首字母（如：骆莲妹 → L.L.M.）
- 地址 → 仅保留省/直辖市
- 照片 → 使用示意图或模糊处理
- 舌象 → 仅描述，不附照片（除非同意）

## 八、质量标准和自检清单

### 8.1 论文质量五级标准

| 等级 | 标准 | 可投稿期刊 |
|------|------|-----------|
| **A级** | 数据完整、逻辑严密、四医融合、有客观指标、有长期随访、有创新点 | SCI期刊（IF>3） |
| **B级** | 数据较完整、逻辑清晰、有客观指标、有中短期随访 | SCI期刊（IF 1-3） |
| **C级** | 数据基本完整、逻辑通顺、有部分客观指标 | 中文核心期刊 |
| **D级** | 数据有缺失、逻辑尚可、以主观描述为主 | 普通期刊 |
| **E级** | 数据严重不足、逻辑混乱、无法验证 | 不投稿，补充数据 |

### 8.2 AI自检清单（生成后强制执行）

#### 8.2.1 内容完整性检查

- [ ] 标题是否包含中西医病名？
- [ ] 摘要是否有五要素（目的/方法/结果/结论）？
- [ ] 引言是否有三层结构（西医→中医→空白）？
- [ ] 病例资料是否有四医模块（西医/中医/功能医学/炁脉）？
- [ ] 治疗模块是否有54牌 rationale？
- [ ] 结果是否有客观指标变化？
- [ ] 讨论是否有四医分析表？
- [ ] 结论是否客观（避免"治愈""根治"等绝对表述）？

#### 8.2.2 学术规范性检查

- [ ] 是否使用"可能""提示""值得进一步研究"等谨慎表述？
- [ ] 是否避免"包治百病""神奇疗效"等夸大表述？
- [ ] 是否引用了相关文献（≥15篇）？
- [ ] 参考文献格式是否符合期刊要求？
- [ ] 图表是否有标题和注释？
- [ ] 单位是否统一？

#### 8.2.3 伦理合规性检查

- [ ] 是否声明知情同意？
- [ ] 是否完成数据脱敏？
- [ ] 是否有利益冲突声明？
- [ ] 是否不泄露患者隐私？

#### 8.2.4 中医特色检查

- [ ] 是否有四诊信息？
- [ ] 是否有辨证分析？
- [ ] 是否引用了古籍？
- [ ] 是否有证候变化记录？

#### 8.2.5 炁脉特色检查

- [ ] 是否有五维定级表？
- [ ] 是否有共原分析？
- [ ] 是否有54牌选方逻辑？
- [ ] 是否有十八变/排异反应记录？
- [ ] 是否有五维雷达图变化？

### 8.3 师父终审要点

师父在终审时需重点确认：

1. **医学准确性**：辨证是否正确？方案是否合理？
2. **疗效真实性**：疗效描述是否客观？有无夸大？
3. **学术价值**：这个病例/系列对学术界有什么价值？
4. **创新性**：是否有新的发现或新的视角？
5. **伦理合规**：是否有隐私泄露风险？
